# 心力衰竭“金三角”药物规范

## 临床要点
射血分数降低型心衰的规范药物治疗常指 ACEI/ARB（或血管紧张素受体脑啡肽酶抑制剂）、β受体阻滞剂和醛固酮受体拮抗剂三类药物的联合应用，三者协同降低死亡率与再住院率，应在病情稳定后尽早启动并逐步加量至目标剂量或最大耐受剂量。

## 处理与观察重点
起始从小剂量开始，每 1-4 周评估耐受性后递增；使用前及加量期间监测血压、心率、血钾、肾功能；注意三类药物与利尿剂的配合，避免低血压与电解质紊乱；观察水肿、呼吸困难、体重变化以评估疗效。

## 注意事项
急性失代偿期应先稳定血流动力学再启动或调整三类药物；血钾过高、严重肾功能不全、症状性低血压者禁忌或慎用；β受体阻滞剂禁用于严重心动过缓、高度房室传导阻滞；不可骤然停药，调整均需在医生指导下进行。

## 检查与诊断
心力衰竭“金三角”药物规范的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
低盐低脂饮食、控制体重、戒烟限酒、规律有氧运动、保持情绪平稳，定期监测血压血脂血糖，遵医嘱服药。

## 就医指引
如出现疑似心力衰竭“金三角”药物规范的相关症状，建议及时到心血管内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对心力衰竭“金三角”药物规范相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
