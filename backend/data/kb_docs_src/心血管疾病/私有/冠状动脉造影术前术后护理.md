# 冠状动脉造影术前术后护理

## 临床要点
冠状动脉造影是诊断冠心病和评估冠状动脉病变的金标准，术前需完善凝血功能、肾功能、心电图等检查，评估过敏史与造影剂风险；向患者说明操作流程与配合要点，签署知情同意，练习床上排尿，评估穿刺部位（常用桡动脉或股动脉）。

## 处理与观察重点
术前禁食、备皮、建立静脉通道；术后加压包扎穿刺点，观察有无渗血、血肿、假性动脉瘤，监测远端肢体血运、皮温、颜色与感觉；桡动脉入路者可适当抬高患肢并定时松解压迫，股动脉入路者卧床制动、术侧下肢伸直；鼓励多次饮水促进造影剂排泄，观察尿量。

## 注意事项
观察有无造影剂相关不良反应及过敏反应；术后监测生命体征与心电图，警惕迷走反射（恶心、心率下降、血压下降）；指导患者避免剧烈咳嗽、用力，防止穿刺点出血；按时复查血常规、肾功能，做好出院宣教与复查计划。

## 预防与日常保健
