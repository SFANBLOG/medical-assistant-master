# 心房颤动的抗凝治疗

## 临床要点
房颤是卒中的重要独立危险因素，抗凝治疗是降低血栓栓塞风险的核心。决策应依据 CHA2DS2-VASc 评分评估卒中风险，同时评估出血风险（如 HAS-BLED 评分）；大多数非瓣膜性房颤患者首选新型口服抗凝药，机械瓣置换或中重度二尖瓣狭窄者选用华法林。

## 处理与观察重点
启动抗凝前核实适应证与禁忌证，按标准剂量使用并核对肾功能、年龄、体重及药物相互作用；用药期间定期评估依从性与出血风险；观察牙龈出血、皮肤瘀斑、黑便、血尿等出血征象；拟行手术或侵入性操作者需规划停药与桥接方案。

## 注意事项
出血高危或活动性出血者暂缓抗凝并处理病因；肾功能不全者按说明书调整剂量；避免与可能影响抗凝效果的药物并用；房颤合并急性冠脉综合征需抗栓时，应权衡双联或三联方案的组合与疗程；定期随访，动态重新评估获益与风险。

## 检查与诊断
心房颤动的抗凝治疗的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
低盐低脂饮食、控制体重、戒烟限酒、规律有氧运动、保持情绪平稳，定期监测血压血脂血糖，遵医嘱服药。

## 就医指引
如出现疑似心房颤动的抗凝治疗的相关症状，建议及时到心血管内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对心房颤动的抗凝治疗相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
