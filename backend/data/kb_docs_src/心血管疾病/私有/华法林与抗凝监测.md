# 华法林与抗凝监测

## 临床要点
华法林是维生素 K 拮抗剂类口服抗凝药，用于房颤卒中预防、机械瓣置换、静脉血栓栓塞症等。其疗效与出血风险受基因多态性、饮食（维生素 K 摄入）及多种药物影响，需以国际标准化比值（INR）为监测指标，一般治疗目标多设定在 2.0-3.0（机械瓣等按需调整）。

## 处理与观察重点
初始给药后定期查 INR，稳定后延长间隔（一般 2-4 周）仍需规律复查；达标与剂量调整应小步进行，避免大幅波动；评估依从性与漏服情况，了解有无合用影响华法林的药物；关注牙龈出血、皮肤瘀斑、血尿、黑便等出血征象，警惕出血性并发症。

## 注意事项
强调饮食相对稳定，富含维生素 K 的食物（如绿叶蔬菜）不可突然大量增减；避免自行加用非甾体抗炎药等增加出血风险的药物；需手术或拔牙者提前与医生协商停药与桥接；育龄期与妊娠期使用需特殊评估；INR 显著异常或发生出血时及时就医处理。

华法林与抗凝监测的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
低盐低脂饮食、控制体重、戒烟限酒、规律有氧运动、保持情绪平稳，定期监测血压血脂血糖，遵医嘱服药。

## 日常管理建议
