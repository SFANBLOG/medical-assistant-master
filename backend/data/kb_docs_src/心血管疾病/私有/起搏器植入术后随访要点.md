# 起搏器植入术后随访要点

## 临床要点
起搏器随访旨在评估起搏器工作状态、电池寿命、起搏与感知阈值，并根据病情调整参数；植入后早期（术后 4-6 周）、其后每 3-12 个月以及电池接近耗尽时加密随访，常规行心电图、起搏器程控检查，必要时动态心电图与胸片。

## 处理与观察重点
术后观察囊袋有无血肿、感染、破溃及电极移位征象（阈值升高、感知不良、起搏失夺获）；程控时核对起搏模式、频率与各项参数，关注起搏比例与自主心律；对依赖起搏器的患者重点评估失夺获风险与电池预警；指导患者识别起搏器报警及异常症状。

## 注意事项
早期患侧上肢避免过度外展、提重物以防电极移位；避免强磁场环境干扰，行磁共振检查需确认起搏器兼容性；记录起搏器型号、植入时间与厂家信息；发热、囊袋红肿疼痛等感染征象需及时处理；特殊手术或治疗前告知医生携带起搏器情况。
