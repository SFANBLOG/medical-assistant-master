# 高血压药物选择与联合用药

## 临床要点
常用降压药分五大类：钙通道阻滞剂（CCB）、血管紧张素转换酶抑制剂（ACEI）、血管紧张素受体拮抗剂（ARB）、利尿剂和β受体阻滞剂。选择依据包括血压水平、靶器官损害、合并症（糖尿病、肾病、冠心病、心衰等）及年龄。多数患者需联合用药，单片复方制剂有助于提高依从性。

## 处理与观察重点
起始治疗从标准剂量开始，根据血压反应每 2-4 周调整直至达标；联合用药原则是作用机制互补、不良反应不相叠加，如 CCB+ACEI/ARB、利尿剂+ACEI/ARB 等；对合并肾病者关注蛋白尿与肾功能，使用 ACEI/ARB 者监测血钾、肌酐。

## 注意事项
血压显著升高伴急性靶器官损害时按高血压急症处理，不宜过快降压；老年及衰弱患者可适当放宽达标目标、从小剂量起始，注意体位性低血压；妊娠期禁用 ACEI/ARB；强调生活方式干预与用药并重，规律监测家庭血压。

## 检查与诊断
高血压药物选择与联合用药的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
低盐低脂饮食、控制体重、戒烟限酒、规律有氧运动、保持情绪平稳，定期监测血压血脂血糖，遵医嘱服药。

## 就医指引
如出现疑似高血压药物选择与联合用药的相关症状，建议及时到心血管内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对高血压药物选择与联合用药相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
