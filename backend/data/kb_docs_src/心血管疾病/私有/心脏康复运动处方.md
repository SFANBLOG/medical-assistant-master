# 心脏康复运动处方

## 临床要点
心脏康复是通过运动训练、生活方式干预、心理支持和危险因素管理综合改善心血管预后的系统方案，主要适用于冠心病、心肌梗死、冠脉介入或搭桥术后、心衰稳定期等患者。运动处方遵循频率、强度、时间、类型（FITT）原则，依据心肺运动试验或六分钟步行试验结果个体化制定。

## 处理与观察重点
运动前评估血压、心率与症状，指导热身与整理活动；运动强度常用心率储备法、目标心率或自我感觉劳累程度分级法把握，以中低强度有氧运动为主，配合适量抗阻与柔韧性训练；运动全程监测，出现胸痛、明显气促、头晕、血压异常时立即停止。

## 注意事项
急性期或病情不稳定者（不稳定型心绞痛、未控制心衰、严重心律失常）暂缓运动并评估后再行；注意合并症（糖尿病、骨质疏松）对运动的限制；强调循序渐进、规律坚持，结合饮食、戒烟、心理疏导共同落实；定期评估并调整处方。

## 检查与诊断
心脏康复运动处方的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
低盐低脂饮食、控制体重、戒烟限酒、规律有氧运动、保持情绪平稳，定期监测血压血脂血糖，遵医嘱服药。

## 就医指引
如出现疑似心脏康复运动处方的相关症状，建议及时到心血管内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对心脏康复运动处方相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
