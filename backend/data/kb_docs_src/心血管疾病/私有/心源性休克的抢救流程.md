# 心源性休克的抢救流程

## 临床要点
心源性休克是心肌泵功能急性衰竭导致的低灌注状态，最常见病因是急性心肌梗死，也可见于暴发性心肌炎、严重心肌病、心衰终末期等。诊断依据为持续性低血压伴组织灌注不足表现（神志改变、皮肤湿冷、少尿、血乳酸升高）。

## 处理与观察重点
立即心电监护、建立静脉通路、吸氧，快速评估并纠正可逆诱因（心律失常、容量不足、机械并发症）；在严格血流动力学监测下谨慎液体复苏，尽早使用血管活性药物维持血压与灌注，慎用利尿扩血管以免进一步降压；尽快实施冠脉再灌注治疗是改善预后的关键；评估机械循环支持（如主动脉内球囊反搏）指征。

## 注意事项
强调团队协作与绿色通道，避免在血压未稳时反复搬动；监测中心静脉压、尿量、乳酸与意识；注意鉴别心包压塞、张力性气胸等可迅速致命但可逆的病因；复苏过程中兼顾脑、肾等重要器官保护，及时转诊至具备导管条件的中心。

心源性休克的抢救流程的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
