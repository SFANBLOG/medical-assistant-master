# 血脂异常

血脂异常指血浆中胆固醇、甘油三酯等脂质水平异常，包括总胆固醇、低密度脂蛋白胆固醇升高，高密度脂蛋白胆固醇降低等，是动脉粥样硬化的重要危险因素。

## 病因
分为原发性和继发性。原发性与遗传和饮食习惯有关；继发性可见于糖尿病、甲状腺功能减退、肾病综合征、肝胆疾病及长期使用某些药物者。高脂高糖饮食、缺乏运动、肥胖、吸烟酗酒均促进血脂异常。

## 主要症状
多数患者无任何症状，常在体检中发现。严重甘油三酯升高可诱发急性胰腺炎；长期血脂异常可逐渐导致动脉粥样硬化，出现冠心病、脑卒中等心脑血管事件时才有相应症状。

## 处理建议
坚持低脂低胆固醇饮食，减少动物内脏、油炸食品摄入，增加膳食纤维；坚持运动、控制体重、戒烟限酒。是否用药及用药强度需依据血脂水平、年龄及合并的心血管危险因素由医生评估决定。

## 就医提醒
体检发现血脂异常者，尤其合并高血压、糖尿病、肥胖或已有心脑血管疾病者，应到心内科或内分泌科就诊，评估总体心血管风险并制定个体化干预方案；服用调脂药期间应定期复查血脂、肝功能和肌酸激酶等指标。

## 检查与诊断
血脂异常的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
低盐低脂饮食、控制体重、戒烟限酒、规律有氧运动、保持情绪平稳，定期监测血压血脂血糖，遵医嘱服药。

## 就医指引
如出现疑似血脂异常的相关症状，建议及时到心血管内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对血脂异常相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
