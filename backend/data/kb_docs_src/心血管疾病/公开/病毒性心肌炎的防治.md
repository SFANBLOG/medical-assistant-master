# 病毒性心肌炎的防治

病毒性心肌炎是由病毒感染引起的心肌炎症性疾病，可发生于任何年龄，以中青年和儿童相对多见，轻者无明显症状，重者可致心力衰竭甚至猝死。

## 病因
多种病毒可引起心肌炎，常见包括柯萨奇 B 组病毒、埃可病毒等肠道病毒，以及流感病毒、腺病毒、细小病毒等。过度劳累、受凉、营养不良、免疫功能低下等因素可增加易感性，病毒感染后心肌受损并继发免疫反应。

## 主要症状
起病前 1-3 周常有发热、咽痛、鼻塞流涕等上呼吸道或腹泻等消化道感染前驱症状；随后出现乏力、胸闷、心悸、胸痛、气促，严重者可出现呼吸困难、水肿等心衰表现，少数以晕厥、心源性休克起病。

## 处理建议
急性期强调休息，避免体力活动和剧烈运动，以减轻心脏负担；在医生指导下进行对症支持及营养心肌等治疗；重症患者需住院监护。恢复期应逐步增加活动量，定期随访复查。

## 就医提醒
感冒或腹泻后出现明显乏力、胸闷、心悸、胸痛，或心电图、心肌酶异常者，应及时到心内科就诊；出现呼吸困难、晕厥、血压下降等危重表现者应立即就医。急性期及恢复期 3-6 个月内应避免剧烈运动和竞技体育。

## 检查与诊断
病毒性心肌炎的防治的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
低盐低脂饮食、控制体重、戒烟限酒、规律有氧运动、保持情绪平稳，定期监测血压血脂血糖，遵医嘱服药。

## 就医指引
