# 静脉血栓与肺栓塞预防

静脉血栓栓塞症包括深静脉血栓形成和肺栓塞，是同一疾病的不同阶段。深静脉血栓多见于下肢，血栓脱落随血流进入肺动脉即形成肺栓塞，可危及生命。

## 病因
与血流缓慢、血管内皮损伤和血液高凝状态三大因素有关。久坐不动、长期卧床、长途飞行或乘车、手术创伤、骨折、妊娠产后、恶性肿瘤、高龄及遗传性易栓症等均为危险因素。

## 主要症状
深静脉血栓表现为单侧下肢肿胀、疼痛、皮温升高、肤色发红或发紫；肺栓塞表现为突发呼吸困难、胸痛、咯血、晕厥，严重者猝死。肺栓塞症状缺乏特异性，需高度警惕。

## 处理建议
高危人群应避免久坐久卧，每隔一段时间起身活动、多饮水；术后及长期卧床者可在医生指导下使用抗凝药物，配合气压治疗、弹力袜等物理预防；长途旅行时定时活动下肢。已诊断静脉血栓者应规范抗凝治疗，切勿揉搓患肢。

## 就医提醒
单侧下肢突发肿胀疼痛，或久坐、术后、产后人群突发不明原因呼吸困难、胸痛、晕厥，应立即就医；怀疑肺栓塞时需急诊处理，避免剧烈活动以防血栓脱落加重。

## 检查与诊断
静脉血栓与肺栓塞预防的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
低盐低脂饮食、控制体重、戒烟限酒、规律有氧运动、保持情绪平稳，定期监测血压血脂血糖，遵医嘱服药。

## 就医指引

## 日常管理建议
