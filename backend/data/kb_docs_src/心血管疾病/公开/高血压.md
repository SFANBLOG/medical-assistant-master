# 高血压

高血压是最常见的慢性心血管疾病，指以体循环动脉血压持续升高为主要特征的临床综合征，长期血压控制不佳可损伤心、脑、肾等重要器官。

## 病因
高血压分为原发性与继发性两类。原发性高血压多与遗传、高盐饮食、超重肥胖、精神紧张、吸烟酗酒、缺乏运动等因素相关，占绝大多数；继发性高血压由肾脏疾病、内分泌疾病、药物等明确病因引起，占少数。

## 主要症状
多数患者早期无明显症状，常于体检时发现。部分患者可出现头晕、头痛、颈项板紧、疲劳、心悸等；血压急剧升高时可出现剧烈头痛、恶心呕吐、视物模糊，甚至意识障碍，提示高血压急症。

## 处理建议
低盐饮食（每日食盐摄入低于 5 克）、控制体重、规律有氧运动、戒烟限酒、保持情绪稳定；确诊后需在医生指导下长期规律服药，不可自行停药或增减剂量，并定期自测血压、记录数值。

## 就医提醒
家庭自测血压多次高于 140/90 mmHg，或出现持续性头痛、胸闷、视力下降、肢体麻木、言语不清等症状时，应及时到心血管内科就诊；血压显著升高伴急性症状者应立即就医。

## 检查与诊断
高血压的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
低盐低脂饮食、控制体重、戒烟限酒、规律有氧运动、保持情绪平稳，定期监测血压血脂血糖，遵医嘱服药。

## 就医指引
如出现疑似高血压的相关症状，建议及时到心血管内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对高血压相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
