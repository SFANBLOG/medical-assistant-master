# 心律失常

心律失常是指心脏冲动的起源、频率、节律或传导发生异常，可见于各种心脏病患者，也可发生于健康人。

## 病因
常见原因包括冠心病、高血压性心脏病、心肌病、心肌炎、瓣膜病、电解质紊乱（如低钾）、甲状腺功能亢进、药物影响、饮酒、过量咖啡因及精神紧张等，部分无明显病因。

## 主要症状
可无症状或仅有轻度不适。常见症状有心悸、胸闷、头晕、乏力、黑矇（眼前发黑），严重者可出现晕厥、抽搐甚至猝死。不同类型心律失常（如早搏、房颤、室速等）表现各异。

## 处理建议
明确类型后再处理。偶发良性早搏多无需特殊治疗；阵发性室上性心动过速可尝试深吸气后屏气用力等方法终止；房颤等需在医生评估下决定节律控制或心室率控制策略，必要时抗凝预防血栓。

## 就医提醒
反复心悸伴晕厥、胸闷胸痛，或心悸呈突发突止、持续时间长，或有器质性心脏病基础者，应尽早就诊，完善心电图、动态心电图等检查；晕厥后意识不清伴呼吸异常者应立即呼叫急救。

## 检查与诊断
心律失常的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
低盐低脂饮食、控制体重、戒烟限酒、规律有氧运动、保持情绪平稳，定期监测血压血脂血糖，遵医嘱服药。

## 就医指引
如出现疑似心律失常的相关症状，建议及时到心血管内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对心律失常相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
