# 心力衰竭

心力衰竭（心衰）是各种心脏疾病发展到严重阶段的临床综合征，指心脏泵血或充盈功能受损，不能满足全身组织代谢需要。

## 病因
常见病因包括冠心病心肌梗死、高血压心脏病、心肌病、心脏瓣膜病、先天性心脏病及心肌炎等。感染、心律失常、过度劳累、输液过快过多、情绪激动、妊娠等可诱发心衰急性加重。

## 主要症状
左心衰竭以呼吸困难为突出表现，早期为活动后气促，逐渐发展为夜间阵发性呼吸困难、端坐呼吸，伴咳嗽、咳粉红色泡沫痰；右心衰竭表现为下肢水肿、腹胀、食欲下降、颈静脉怒张；全心衰竭时两者并存。

## 处理建议
严格遵医嘱服药，定期称体重，短期内体重明显增加提示体液潴留；限制钠盐摄入，记录出入量；避免劳累、受凉与感染；病情稳定者可进行医生指导下的适度康复活动。

## 就医提醒
出现静息时呼吸困难、端坐呼吸、咳粉红色泡沫痰、下肢进行性水肿或体重短期内快速增加时，提示心衰加重，应及时就医；急性加重伴意识改变、血压下降者应立即呼叫急救。

## 检查与诊断
心力衰竭的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
低盐低脂饮食、控制体重、戒烟限酒、规律有氧运动、保持情绪平稳，定期监测血压血脂血糖，遵医嘱服药。

## 就医指引
如出现疑似心力衰竭的相关症状，建议及时到心血管内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对心力衰竭相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
