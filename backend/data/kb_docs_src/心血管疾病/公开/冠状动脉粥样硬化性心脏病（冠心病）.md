# 冠状动脉粥样硬化性心脏病（冠心病）

冠心病是指冠状动脉发生粥样硬化，导致管腔狭窄或阻塞，引起心肌缺血、缺氧甚至坏死的心脏病，是危害中老年人健康的主要疾病之一。

## 病因
主要危险因素包括高龄、男性、血脂异常、高血压、糖尿病、吸烟、肥胖、缺乏运动及冠心病家族史。脂质在冠状动脉内壁沉积形成粥样斑块，斑块破裂后可继发血栓形成，阻塞血管。

## 主要症状
典型表现为心前区压榨样疼痛或不适，可放射至左肩、左臂内侧、下颌，多于劳累、情绪激动时诱发，休息或含服硝酸酯类药物后数分钟内缓解，此即心绞痛；若疼痛持续超过 20 分钟不缓解，需警惕急性心肌梗死。

## 处理建议
坚持健康生活方式，控制血压、血脂、血糖，戒烟限酒，适量运动；在医生指导下规范用药，包括抗血小板、调脂、控制心率的药物等；定期复查心电图、心脏超声及相关生化指标。

## 就医提醒
心绞痛发作频率增加、程度加重、静息状态下也发作，或胸痛持续不缓解并伴大汗、呼吸困难、恶心时，应立即拨打急救电话，保持安静等待救援，切勿自行驾车就医。

冠状动脉粥样硬化性心脏病（冠心病）的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
