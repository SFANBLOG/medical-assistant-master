# 心脏骤停与心肺复苏科普

心脏骤停指心脏射血功能突然终止，导致脑等重要器官严重缺血缺氧，若得不到及时抢救，数分钟内即可发生不可逆损伤甚至死亡，是院外最凶险的急症之一。

## 病因
常见原因包括急性心肌梗死、严重心律失常（如心室颤动）、心肌病、电解质紊乱、药物中毒、溺水、窒息及严重外伤等。冠心病是导致心脏骤停最主要的病因，发病前可有也可无先兆症状。

## 主要症状
患者突然意识丧失，呼之不应，大动脉（颈动脉或股动脉）搏动消失，呼吸停止或呈叹气样濒死呼吸，面色青紫。一旦发现上述表现应立即判断并施救。

## 处理建议
立即呼叫急救电话，同时开始心肺复苏：将患者仰卧于硬质平面，双手掌根叠加按压胸骨下半部，按压深度约 5-6 厘米、频率每分钟 100-120 次，保证胸廓充分回弹，尽量减少按压中断；有条件者尽早使用自动体外除颤器（AED）进行电除颤，公共场所可主动寻找 AED。

## 就医提醒
心脏骤停救治争分夺秒，现场施救的同时应立即拨打急救电话，并持续心肺复苏直至专业救援到达；胸外按压对施救者体力消耗大，多人可轮换进行；切勿因犹豫或离开现场而延误抢救。

## 检查与诊断
心脏骤停与心肺复苏科普的确诊需要结合临床表现与辅助检查。常用检查包括：血压测量、心电图、心脏超声、动态血压/动态心电图监测、血脂血糖、心肌损伤标志物等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
低盐低脂饮食、控制体重、戒烟限酒、规律有氧运动、保持情绪平稳，定期监测血压血脂血糖，遵医嘱服药。

## 就医指引
