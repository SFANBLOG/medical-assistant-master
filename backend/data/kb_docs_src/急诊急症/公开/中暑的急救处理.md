# 中暑的急救处理

中暑是高温或高湿环境中体温调节失衡、水盐丢失及器官功能受损的一组疾病，重症（热射病）病死率高，需争分夺秒处理。

## 常见病因
在高温、高湿、通风不良或剧烈运动下长时间暴露，饮水不足者更易发生；年老体弱、婴幼儿及有慢性基础疾病者风险更高；某些药物及饮酒也可增加发病风险。

## 主要表现
先兆中暑：头晕、乏力、口渴、大汗、注意力不集中。轻症：面色潮红、恶心、心率加快、体温轻度升高。重症：高热（可达40℃以上）、皮肤干热无汗、意识模糊、抽搐或昏迷。

## 现场处置
立即将患者移至阴凉通风处，解开衣物，用凉水擦拭或用冰袋冷敷颈部、腋下、腹股沟等大血管部位，配合风扇加速散热；意识清醒者可少量多次补充含盐凉饮，避免一次性大量饮水；意识不清者勿强行喂水，取侧卧位防误吸，立即拨打急救电话。

## 就医提醒
出现高热、无汗、意识障碍或抽搐者，提示热射病，属危急情况，在持续降温的同时立即呼叫急救送医。

## 日常管理建议
针对中暑的急救处理相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
