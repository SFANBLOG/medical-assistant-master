# 急性过敏反应的应急处理

急性过敏反应是由药物、食物、昆虫蜇伤等诱发的速发型反应，重症（过敏性休克）可在数分钟内危及生命，需快速识别和处置。

## 常见病因
常见诱因包括抗生素等药物、花生、海鲜、牛奶、鸡蛋等食物，蜜蜂或胡蜂蜇伤，以及乳胶制品等；有过敏史者风险更高。

## 主要表现
轻者表现为荨麻疹、皮肤瘙痒、面部或口唇肿胀、流涕、打喷嚏；重者出现喉头水肿导致的呼吸困难、声音嘶哑、喘息、血压下降、面色苍白、心慌、意识模糊甚至昏迷。

## 现场处置
立即脱离可疑致敏原；协助患者保持舒适体位，呼吸困难者可取半卧位，意识不清者取侧卧位；如患者有既往医生开具的肾上腺素类急救药物，按医嘱使用；密切观察意识、呼吸与脉搏，并呼叫急救。切勿自行服用其他药物替代急救药。

## 就医提醒
出现呼吸困难、声音嘶哑、明显面部肿胀、血压下降或意识改变等休克表现时，属危急情况，应立即呼叫急救并尽快送医。
