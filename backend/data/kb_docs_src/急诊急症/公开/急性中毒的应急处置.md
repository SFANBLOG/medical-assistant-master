# 急性中毒的应急处置

急性中毒是指毒物经消化道、呼吸道、皮肤黏膜等途径进入人体引起急性损害，常见于误服药物、农药、化学品及一氧化碳中毒等，需快速脱离现场并送医。

## 常见病因
误服或过量服用药物，误服有机磷等农药、清洁剂消毒剂，酒精中毒，吸入一氧化碳等有害气体，食用有毒动植物，或被毒蛇、蜂等蜇咬伤。

## 主要表现
表现因毒物而异，常见恶心呕吐、腹痛腹泻、头晕头痛、呼吸困难、抽搐、意识障碍；一氧化碳中毒可见皮肤黏膜樱桃红色；有机磷中毒可见瞳孔缩小、流涎、大汗、肌肉颤动。

## 现场处置
立即脱离中毒现场：气体中毒者移至通风处，解开衣领保持气道通畅；皮肤沾染者脱去衣物、用大量清水冲洗；误服者如意识清楚且非腐蚀性毒物，可谨慎催吐，腐蚀性毒物与石油制品切勿催吐；留存可疑毒物、容器及呕吐物供医生判断；昏迷者取侧卧位防止误吸。

## 就医提醒
任何可疑急性中毒，尤其出现呼吸困难、抽搐、昏迷或婴幼儿中毒，应立即呼叫急救并尽快送医，切勿延误。

## 就医指引
如出现疑似急性中毒的应急处置的相关症状，建议及时到急诊科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
