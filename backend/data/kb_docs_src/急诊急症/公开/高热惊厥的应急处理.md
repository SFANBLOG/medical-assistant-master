# 高热惊厥（Febrile Seizure）急救指南

> **核心摘要**：高热惊厥多见于6个月至5岁儿童，由高热诱发。表现为意识丧失、肌肉强直或抽搐。 **绝大多数预后良好**
> ，但需规范现场处置并排除其他严重病因。

## 1. 什么是高热惊厥？（定义与人群）

* **高发人群**：6个月至5岁的婴幼儿。
* **诱发原因**：通常由呼吸道感染（如感冒、流感）、幼儿急疹等引起的 **体温迅速升高**所致。
* **特点**：常与发热速度、体温峰值及家族遗传倾向有关。多数情况下不会损伤大脑，预后良好。

## 2. 如何识别？（主要临床表现）

在发热过程中突然发生，家长需警惕以下特征：

* **意识障碍**：呼之不应，意识丧失。
* **肢体动作**：全身或局部肌肉强直、阵发性抽搐。
* **眼部表现**：双眼上翻、凝视或斜视。
* **其他症状**：口吐白沫、面色发青。
* **持续时间**：通常持续数十秒至数分钟，可自行停止。
* **发作后状态**：停止后可有短暂嗜睡、疲倦或烦躁。

## 3. 现场该怎么做？（紧急处置步骤）

**原则：保持冷静，防止二次伤害，记录时间。**

### ✅ 正确的做法（Do's）

1. **侧卧位**：立即将患儿平卧，头偏向一侧或置于侧卧位，防止呕吐物误吸入气管导致窒息。
2. **清理环境**：移开周围尖锐、坚硬的物体，解开衣领，保持呼吸道通畅。
3. **清理口鼻**：轻轻清除口鼻分泌物或呕吐物。
4. **记录细节**：观察并记录发作开始的时间、表现形式（如哪边手脚先抽），以便就医时告知医生。
5. **物理降温**：抽搐停止后，若体温仍高，可配合使用退热贴或温水擦拭颈部、腋窝等大血管流经处。

### ❌ 严禁的做法（Don'ts）

* **切勿强行按压**：不要用力按压孩子的肢体试图制止抽搐，这可能导致骨折或软组织损伤。
* **切勿塞入异物**：绝对不要往孩子嘴里塞勺子、毛巾、手指等，以免阻塞气道或损伤牙齿/牙龈。
* **切勿掐人中**：掐人中无法止住惊厥，反而可能造成皮肤破损感染。

## 4. 何时必须立即就医？（红色预警）⚠️

出现以下任一情况，请**立即拨打急救电话（120）**或尽快前往医院：

1. **时间长**：惊厥持续超过 **5分钟** 仍未停止。
2. **反复发作**：短时间内多次发作。
3. **意识不清**：抽搐停止后，意识长时间未恢复或持续昏迷。
4. **呼吸异常**：伴有呼吸困难、面色青紫。
5. **首次发作**：如果是第一次发生高热惊厥，务必就医以排除脑膜炎等其他疾病。
6. **年龄过小**：小于6个月的婴儿出现类似症状。

## 5. 常见问题解答（FAQ）

* **Q: 高热惊厥会烧坏脑子吗？**
    * A: 单纯性高热惊厥通常不会造成脑损伤，也不会导致癫痫。
* **Q: 下次发烧还会抽吗？**
    * A: 有复发可能，但随着年龄增长（通常5-6岁后），神经系统发育完善，发作概率会显著降低。

## 日常管理建议
针对高热惊厥的应急处理相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
