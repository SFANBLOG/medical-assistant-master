# 烫伤烧伤的现场处理

烫伤烧伤是常见的生活性损伤，正确处理可减轻损伤程度、降低感染风险，而涂抹牙膏、酱油等错误处理反而会加重伤害。

## 常见病因
热液烫伤、火焰烧伤、蒸汽烫伤、高温物体接触、化学灼伤及电烧伤，儿童和老年人更为多见。

## 主要表现
按深度分为一度（皮肤发红、疼痛）、浅二度（出现水疱、剧痛）、深二度（水疱、痛觉减退）和三度（苍白或焦痂、无痛觉）；大面积烧伤可伴口渴、尿少、心慌等休克表现。

## 现场处置
立即脱离热源，用流动凉水持续冲洗降温约15至20分钟，大面积烧伤应避免长时间冷水冲淋导致低体温；小心去除衣物，粘连部位勿强行撕脱；水疱不要挑破，用清洁纱布或保鲜膜覆盖保护创面；化学灼伤用大量清水长时间冲洗；切勿涂抹牙膏、酱油或各类药膏。同时呼叫急救。

## 就医提醒
烧伤面积较大、位于面部、颈部、关节、会阴等特殊部位，深度烧伤或化学、电烧伤，以及婴幼儿、老年人烧伤，均应尽快送医院处理。
