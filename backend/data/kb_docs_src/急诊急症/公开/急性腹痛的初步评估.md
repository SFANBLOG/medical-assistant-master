# 急性腹痛的初步评估

急性腹痛是指起病急骤的腹部疼痛，涉及消化、泌尿、妇科、心血管等多个系统，部分属外科急腹症，需尽快明确病因并决定是否手术。

## 常见病因
- 炎症性：急性阑尾炎、胆囊炎、胰腺炎、急性肠炎。
- 梗阻性：肠梗阻、胆道结石嵌顿、泌尿系结石。
- 穿孔与出血性：胃十二指肠穿孔、异位妊娠破裂、腹部外伤。
- 其他：肠系膜缺血、心肌梗死、糖尿病酮症酸中毒等也可表现为腹痛。

## 主要表现
注意疼痛的部位（脐周、右下腹、右上腹等）、性质（绞痛、胀痛、刀割样）及转移与放射情况；常伴恶心呕吐、发热、腹胀、停止排气排便或血便。疼痛部位固定并持续加重常提示病情进展。

## 现场处置
让患者卧床休息、暂停进食饮水；避免热敷、按摩或自行服用止痛药掩盖病情；观察有无高热、呕血、黑便、意识改变等；及时呼叫急救送医，途中保持呼吸道通畅、防止呕吐误吸。

## 就医提醒
腹痛持续加重、伴高热寒战、呕血黑便、腹部板硬、妊娠期腹痛，以及老年或儿童腹痛，均属需紧急就医的情况，应尽快到急诊。

## 检查与诊断
急性腹痛的初步评估的确诊需要结合临床表现与辅助检查。常用检查包括：生命体征评估、心电图、血常规与生化、床旁超声、必要时的影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
学习常见急症的家庭急救常识（如心肺复苏、止血包扎、烫伤处理），高危人群定期体检，出现急症征兆立即就医。

## 就医指引
如出现疑似急性腹痛的初步评估的相关症状，建议及时到急诊科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对急性腹痛的初步评估相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
