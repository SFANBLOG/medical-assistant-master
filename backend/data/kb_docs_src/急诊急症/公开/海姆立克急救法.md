# 海姆立克急救法

海姆立克急救法用于气道被异物完全阻塞的窒息，通过冲击腹部产生气流将异物冲出，适用于成人、儿童及自救。

## 常见病因
进食过快、边说笑边吞咽、小儿误吸小物件（如坚果、玩具零件）、醉酒或意识下降者误吸等导致的呼吸道异物梗阻。

## 主要表现
典型征象为突然剧烈呛咳、面色涨红或青紫、无法说话与呼吸、双手不自觉地抓握颈部；完全梗阻时可迅速发展为意识丧失。

## 现场处置
成人立位：施救者站于患者背后，双手环抱其腰部，一手握拳、拳眼置于脐上两横指处，另一手包住拳头，快速向上向内冲击腹部，反复进行直至异物排出或患者失去意识；患者失去意识时立即平卧，开放气道、进行心肺复苏并呼叫急救。婴儿采用拍背与胸部冲击交替法，切勿用腹部冲击。本人独处时可借助椅背等硬物进行自救腹部冲击。

## 就医提醒
经急救后异物未能排出，或患者出现意识丧失、面色青紫，应立即呼叫急救并配合心肺复苏，尽快送医。
