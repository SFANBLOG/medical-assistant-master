# 心肺复苏基础生命支持

心肺复苏是对心跳呼吸骤停患者采取的急救措施，包括胸外按压、开放气道和人工呼吸，在发病后的"黄金四分钟"内实施可明显提高存活率。

## 常见病因
急性心肌梗死、严重心律失常、窒息、溺水、电击、严重创伤、药物中毒等导致的突发心跳呼吸骤停。

## 主要表现
患者突然意识丧失、呼之不应，无正常呼吸或仅呈叹息样濒死喘息，触摸颈动脉等大动脉搏动消失。

## 现场处置
先确认现场安全，拍打双肩、大声呼喊判断意识；同时呼救并指定他人拨打急救电话、就近取用自动体外除颤器（AED）；立即将患者平卧于硬质平面，在胸骨下半部进行胸外按压，成人按压深度约5至6厘米、频率每分钟100至120次，每次按压后让胸廓充分回弹；如受过训练可进行人工呼吸，按压与通气比例约为30比2；AED到达后按语音提示使用，持续心肺复苏直至专业救援到达。

## 就医提醒
心跳呼吸骤停属极端危急情况，目击者应立即开始心肺复苏并使用AED，同时呼叫急救，任何犹豫都可能延误抢救时机。
