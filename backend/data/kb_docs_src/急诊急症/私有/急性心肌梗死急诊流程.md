# 急性心肌梗死急诊流程

急性心肌梗死（STEMI）救治的核心是尽快实现再灌注，缩短总缺血时间是预后的关键，急诊流程应围绕"时间就是心肌"来组织。

## 临床要点
典型表现为持续胸骨后压榨性疼痛伴大汗、恶心，可向左肩、后背放射；不典型表现见于老年、女性及糖尿病患者（如上腹不适、气促、晕厥）。急诊应于10分钟内完成首份心电图，对疑诊者监测心肌标志物并动态观察心电图演变。

## 处理与观察重点
确诊或高度疑诊STEMI者，在排除禁忌后尽早启动再灌注策略：具备条件的中心应尽快行急诊经皮冠状动脉介入治疗（PCI），争取将首次医疗接触至开通血管的时间控制在指南建议范围内；无条件者评估溶栓的适应证与禁忌证；同时予抗血小板、抗凝、抗缺血及镇痛等综合治疗，全程心电监护，警惕恶性心律失常与心源性休克。

## 注意事项
心电图无典型改变不能排除，需动态复查；把握并记录各抢救时间节点；与导管室、监护病房做好无缝衔接；警惕再灌注心律失常；向家属充分告知病情与风险。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
急性心肌梗死急诊流程的确诊需要结合临床表现与辅助检查。常用检查包括：生命体征评估、心电图、血常规与生化、床旁超声、必要时的影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
学习常见急症的家庭急救常识（如心肺复苏、止血包扎、烫伤处理），高危人群定期体检，出现急症征兆立即就医。

## 就医指引
如出现疑似急性心肌梗死急诊流程的相关症状，建议及时到急诊科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
