# 休克类型识别与处理

休克是组织灌注不足导致的急性循环衰竭，早期识别类型并针对性处理可显著改善预后，切忌一律按同一方案处置。

## 临床要点
按病理生理分为四类：低血容量性（失血、失液）、心源性（心肌梗死、严重心律失常、心力衰竭）、分布性（脓毒症、过敏、神经源性）和梗阻性（肺栓塞、心包填塞、张力性气胸）。共同表现有血压下降、心率增快、少尿、意识改变、肢端湿冷或温暖等，需结合病史与体征鉴别。

## 处理与观察重点
立即评估并维持气道、呼吸与循环；低血容量性与脓毒性休克早期积极液体复苏；心源性休克需控制补液、查找并处理心脏病因；梗阻性休克需尽快解除梗阻（如胸腔减压、心包穿刺）；合理使用血管活性药物；动态监测血压、乳酸、尿量、血氧等判断复苏效果，必要时转入重症监护。

## 注意事项
早期识别"代偿性休克"以避免延迟治疗；避免对心源性休克盲目快速补液；过敏性休克首选肾上腺素；疑诊感染时注意早期抗感染与感染源控制。
