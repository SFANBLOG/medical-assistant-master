# 急性脑卒中绿色通道

急性缺血性脑卒中救治具有强烈的时间依赖性，绿色通道通过优化院内流程，缩短从到院到溶栓或取栓的时间，最大限度挽救脑组织。

## 临床要点
对疑似卒中者快速进行院前与院内评估，采用卒中识别工具（如FAST：面部、手臂、言语、时间）初步筛查；急诊立即行头颅影像学检查以区分缺血与出血；明确发病时间，完善溶栓相关检查与禁忌证评估。缺血性卒中在时间窗内符合条件者可静脉溶栓，大血管闭塞者可评估机械取栓。

## 处理与观察重点
启动绿色通道：专人引导、优先检查、预置卒中团队；尽量缩短到院至影像、到院至溶栓的时间；溶栓过程中密切监测血压、神经功能与出血征象；注意气道、吞咽与防误吸管理，控制血压于指南建议范围。

## 注意事项
发病时间判断须准确，病史不明者结合影像与多模式评估；警惕溶栓后颅内出血等并发症；出血性卒中按相应流程处理（控制血压、评估手术指征）；规范记录各时间节点，持续开展质量改进。
