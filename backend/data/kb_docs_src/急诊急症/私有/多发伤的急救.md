# 多发伤的急救

多发伤指同一机械因素所致两个或以上解剖部位的重度损伤，常伴严重生理紊乱，救治应遵循"先救命后治伤"的损伤控制原则。

## 临床要点
按创伤流程系统评估：气道与颈椎保护、呼吸、循环、神经功能、全身暴露检查。重点识别张力性气胸、大量血胸、心包填塞、腹腔内出血等可致死性损伤；老年患者及使用抗凝药物者的钝性损伤需高度警惕。

## 处理与观察重点
维持气道通畅并保护颈椎，必要时气管插管；对休克者尽快建立静脉通路并控制出血，采用损伤控制性复苏策略；尽快完成床旁重点超声及影像学检查明确损伤范围；优先处理危及生命的损伤，稳定后统筹分科手术；全程动态复评，避免遗漏隐匿损伤。

## 注意事项
避免院内长时间耽搁，把握创伤救治"黄金一小时"；搬运与检查时注意颈椎保护；警惕创伤后凝血病与低体温，采取保温等措施；多学科协作并做好术前准备；完整记录病历与影像资料。

## 就医指引
如出现疑似多发伤的急救的相关症状，建议及时到急诊科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对多发伤的急救相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
