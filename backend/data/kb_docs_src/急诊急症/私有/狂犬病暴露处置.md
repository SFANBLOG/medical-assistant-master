# 狂犬病暴露处置

狂犬病暴露后处置是预防狂犬病的关键环节，规范的伤口处理与及时、足程的疫苗接种可显著降低发病风险，须按暴露分级规范实施。

## 临床要点
按暴露分级评估：Ⅰ级为接触或喂养动物、完好的皮肤被舔，清洗即可；Ⅱ级为裸露皮肤轻咬、无出血的轻微抓伤擦伤，需接种疫苗；Ⅲ级为单处或多处贯穿皮肤咬伤抓伤、破损皮肤被舔、黏膜被污染或暴露于蝙蝠，需接种疫苗并注射狂犬病被动免疫制剂。评估时兼顾伤口部位、深度与动物情况。

## 处理与观察重点
尽早进行伤口冲洗：用肥皂水（或清水）与流动水交替冲洗至少15分钟，再用生理盐水洗净、消毒，并评估清创与缝合时机；按规范程序完成疫苗全程接种；Ⅲ级暴露者尽早联合使用被动免疫制剂；对免疫功能低下者注意调整方案，记录暴露时间、部位与接种时间。

## 注意事项
冲洗前评估神经血管与肌腱损伤；被动免疫制剂与疫苗不得在同一部位注射；孕妇、儿童接种安全；同时评估破伤风风险与其他感染；做好暴露登记与健康宣教，强调全程接种的重要性。

## 预防与日常保健

## 就医指引
