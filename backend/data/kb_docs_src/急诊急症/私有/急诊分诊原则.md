# 急诊分诊原则

急诊分诊是在患者到达后迅速评估病情轻重缓急、确定就诊顺序与救治区域的过程，核心目标是在有限资源下优先救治危重患者。

## 临床要点
依据生命体征（意识、呼吸、脉搏、血压、血氧饱和度）、主诉严重程度及高危病史进行分级，常用四级或五级分诊标准：Ⅰ级为濒危，需立即抢救；Ⅱ级为危重，需在短时间内处置；Ⅲ级为紧急；Ⅳ级为次紧急；Ⅴ级为非紧急。改良早期预警评分（MEWS）、病情严重度指数（ESI）等工具可辅助判断。

## 处理与观察重点
对Ⅰ、Ⅱ级患者立即送入抢救区并启动相应流程；持续监测生命体征并动态再评估，因病情可能在短时间内恶化；对候诊患者定时巡视复评；记录分诊级别、时间及依据，确保可追溯。

## 注意事项
分诊人员应经培训上岗，具备识别危重患者的经验；避免因候诊人数多而降低分诊标准；老年、儿童、孕妇及免疫低下者的体征阈值常与常人不同，需结合主诉综合判断；对任何"看着不太对劲"的患者应提高警惕。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
急诊分诊原则的确诊需要结合临床表现与辅助检查。常用检查包括：生命体征评估、心电图、血常规与生化、床旁超声、必要时的影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
学习常见急症的家庭急救常识（如心肺复苏、止血包扎、烫伤处理），高危人群定期体检，出现急症征兆立即就医。

## 就医指引
如出现疑似急诊分诊原则的相关症状，建议及时到急诊科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对急诊分诊原则相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
