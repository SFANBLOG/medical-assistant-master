# 急诊病历书写要点

急诊病历是诊疗过程的法定记录，也是临床决策、医疗安全与质量评价的基础，须遵循及时、客观、准确、完整的原则。

## 临床要点
重点记录就诊时间与来诊方式、主诉及持续时间、现病史（重点是与急诊病情相关的经过与诱因）、既往史与过敏史；记录生命体征、意识状态及体格检查阳性与有意义的阴性体征；记录分诊级别与初步诊断印象。

## 处理与观察重点
书写应真实反映诊疗行为：记录下达的医嘱、执行的治疗与抢救过程（含心肺复苏、用药、气管插管等），关键时间节点（到院、检查、用药、抢救）应具体；记录与家属沟通内容及知情同意；病情变化、复查结果与转归（留观、收住院、离院）均应及时补记。

## 注意事项
抢救记录须在抢救结束后及时完成并注明时间，不得涂改伪造；对离院患者须记录告知内容与注意事项；签名规范；依法管理电子病历与患者隐私；注意各时间记录的一致性，避免记录与实际不符。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
急诊病历书写要点的确诊需要结合临床表现与辅助检查。常用检查包括：生命体征评估、心电图、血常规与生化、床旁超声、必要时的影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
学习常见急症的家庭急救常识（如心肺复苏、止血包扎、烫伤处理），高危人群定期体检，出现急症征兆立即就医。

## 就医指引
如出现疑似急诊病历书写要点的相关症状，建议及时到急诊科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对急诊病历书写要点相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
