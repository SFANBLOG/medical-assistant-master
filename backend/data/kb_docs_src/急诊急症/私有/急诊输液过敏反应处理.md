# 急诊输液过敏反应处理

输液过程中的过敏反应可在数分钟内迅速进展，是急诊输液观察的重点之一，规范识别与应急处理可避免严重不良事件。

## 临床要点
表现可自轻到重：皮肤潮红、瘙痒、荨麻疹、恶心；进而出现喉头水肿、支气管痉挛、呼吸困难、血压下降甚至过敏性休克。严重反应多发生在输液开始后30分钟内，但迟发者亦存在。

## 处理与观察重点
一旦疑诊，立即停止输液、更换输液器与管路，保留静脉通路；保持气道通畅并给予吸氧；对呼吸受累或循环不稳的严重反应，立即肌注肾上腺素，同时快速补液，并应用糖皮质激素、抗组胺药等辅助治疗；持续监测生命体征，观察有无症状再发。

## 注意事项
用药前询问过敏史并留观；高致敏药物开始阶段放慢滴速、加强巡视；反应评估分秒必争，勿因处理无关症状而延误；详细记录可疑药物、发生时间与处理经过，按规定报告不良事件并完善相关记录。
