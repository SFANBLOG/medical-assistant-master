# 急诊气道管理

气道管理是急危重症抢救的首要环节，目标是建立和维持有效通气与氧合，防止缺氧性损害，须快速评估并选择适宜手段。

## 临床要点
先评估气道通畅性、通气与氧合状况，判断有无窒息危险；警惕会厌炎、过敏性喉头水肿、外伤等所致困难气道。建立人工气道前应充分预给氧，备好吸引、通气及困难气道工具；快速诱导插管时需考虑患者血流动力学状态与误吸风险。

## 处理与观察重点
能自主通气者先予吸氧、体位调整及气道辅助；无效时依次选择面罩通气、声门上气道或气管插管；插管后立即确认位置（双侧呼吸音、呼气末二氧化碳、影像学），固定导管并监测氧合与通气指标；困难气道遵循"尝试次数有限、及时改换方法"的原则，避免反复操作加重损伤。

## 注意事项
注意保护颈椎、预防误吸；掌握拔管与再插管指征；记录插管条件、尝试次数与用药情况；对镇静用药者密切监测血流动力学；加强团队配合，并备好紧急外科气道方案（如环甲膜切开等）。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
急诊气道管理的确诊需要结合临床表现与辅助检查。常用检查包括：生命体征评估、心电图、血常规与生化、床旁超声、必要时的影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
学习常见急症的家庭急救常识（如心肺复苏、止血包扎、烫伤处理），高危人群定期体检，出现急症征兆立即就医。

## 就医指引
如出现疑似急诊气道管理的相关症状，建议及时到急诊科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
