# 脓毒症集束化治疗

脓毒症是宿主对感染反应失调所致的危及生命的器官功能障碍，早期识别与规范集束化治疗是降低病死率的关键。

## 临床要点
凡疑似感染合并器官功能障碍（如意识改变、呼吸增快、低血压、少尿、乳酸升高）即应考虑脓毒症；脓毒性休克指充分液体复苏后仍需血管活性药物维持血压且乳酸升高。快速序贯器官衰竭评分（qSOFA，含意识改变、呼吸≥22次/分、收缩压≤100mmHg）可用于快速预警。

## 处理与观察重点
1小时内完成关键措施：留取血培养后尽早使用广谱抗菌药物；在无明显肺水肿征象时快速静脉补液进行液体复苏；对液体复苏后仍低血压者使用血管活性药物；动态监测乳酸、感染指标与组织灌注，及时评估疗效并调整抗感染方案；积极查找并控制感染源。

## 注意事项
抗菌药物使用前应尽量留取培养，避免无谓延误；液体复苏需个体化，警惕容量负荷过重与肺水肿；注意与心源性休克等鉴别；病情重者及时转入重症监护病房。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 预防与日常保健
学习常见急症的家庭急救常识（如心肺复苏、止血包扎、烫伤处理），高危人群定期体检，出现急症征兆立即就医。

## 就医指引
如出现疑似脓毒症集束化治疗的相关症状，建议及时到急诊科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
