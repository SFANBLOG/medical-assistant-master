# 系统性红斑狼疮

系统性红斑狼疮是一种可累及全身多系统、多器官的慢性自身免疫性疾病，好发于育龄期女性，常表现为面部蝶形红斑、发热、关节痛及多脏器损害。

## 病因
病因尚不完全清楚，与遗传、雌激素水平、紫外线照射、某些药物及病毒感染等诱因相关，导致机体产生多种自身抗体，免疫复合物沉积而损伤组织器官。

## 主要症状
- 皮肤黏膜：面颊部蝶形红斑、盘状红斑、光敏感、口腔溃疡、脱发。
- 全身及关节：发热、乏力、关节肿痛。
- 脏器受累：血尿、蛋白尿、水肿（狼疮性肾炎），胸膜炎、心包炎，贫血、白细胞和血小板减少等血液系统异常。

## 处理建议
- 到风湿免疫科规范诊治，由医生制定个体化方案，常用糖皮质激素、羟氯喹、免疫抑制剂及生物制剂。
- 严格防晒，避免紫外线照射；避免感染、劳累和情绪波动。
- 病情稳定期可正常生活，但应定期复查，监测脏器功能。

## 就医提醒
出现持续面部红斑、原因不明发热伴多关节痛，或水肿、血尿等肾损害表现时，应尽早就医，以免延误治疗造成重要脏器不可逆损伤。
