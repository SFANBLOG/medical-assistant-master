# 银屑病关节炎

银屑病关节炎是与银屑病（牛皮癣）相关的一种慢性炎症性关节病，可累及关节、脊柱和肌腱附着点，皮疹与关节炎可先后或同时出现。

## 病因
与遗传、免疫异常及环境因素有关。免疫系统异常攻击皮肤和关节组织，银屑病皮肤病变与关节炎症常相互伴发、互为影响。

## 主要症状
- 皮肤：银屑病皮疹，皮肤出现红色斑块伴银白色鳞屑，好发于肘、膝、头皮。
- 关节：手指、脚趾肿胀呈"腊肠指"，单关节或不对称性大关节炎，也可累及脊柱和骶髂关节。
- 指甲：甲板凹陷、增厚、剥离，与末端关节炎症密切相关。

## 处理建议
- 皮肤科与风湿免疫科联合诊治，同时控制皮肤与关节两方面病变。
- 遵医嘱使用抗炎药、甲氨蝶呤等传统改善病情药物或生物制剂。
- 适度进行关节功能锻炼，避免外伤，注意皮肤护理、防止感染。

## 就医提醒
银屑病患者出现关节肿痛、晨僵、腊肠指或腰背痛，应尽早到风湿免疫科就诊，早期干预可防止关节破坏和畸形。
