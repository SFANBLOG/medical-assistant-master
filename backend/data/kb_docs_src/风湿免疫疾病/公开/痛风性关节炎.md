# 痛风性关节炎

痛风性关节炎是由血尿酸水平过高、尿酸盐结晶沉积于关节所致的急性炎症性关节病，典型表现为夜间突发的第一跖趾关节红、肿、热、痛。

## 病因
体内尿酸生成过多或排泄减少可导致高尿酸血症，在受凉、饮酒、高嘌呤饮食、劳累等诱因下，尿酸盐结晶析出并沉积于关节及软组织而引发炎症。

## 主要症状
- 急性发作：关节剧痛，常在夜间突然发作，第一跖趾关节最常受累，伴红、肿、灼热，触碰即痛。
- 反复发作可累及踝、膝、腕等关节，并可形成皮下痛风石、肾结石。
- 间歇期可无症状，但血尿酸仍高，长期不控制可致关节畸形和肾功能损害。

## 处理建议
- 急性期卧床休息、抬高患肢、局部冰敷，尽早遵医嘱使用消炎止痛药物。
- 急性期过后在医生指导下进行降尿酸治疗，需长期坚持、不可随意停药。
- 限制动物内脏、海鲜、浓肉汤等高嘌呤食物，戒酒，避免含糖饮料，多饮水、控制体重。

## 就医提醒
首次出现典型关节红、肿、剧痛，或反复发作、出现痛风石、怀疑肾损伤时，应及时到风湿免疫科就诊规范治疗。

## 检查与诊断
痛风性关节炎的确诊需要结合临床表现与辅助检查。常用检查包括：血沉、C反应蛋白、类风湿因子、自身抗体谱、关节影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、均衡营养、适度锻炼、避免感染与过度劳累，遵医嘱规范用药，定期复查随访。

## 就医指引
如出现疑似痛风性关节炎的相关症状，建议及时到风湿免疫科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对痛风性关节炎相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
