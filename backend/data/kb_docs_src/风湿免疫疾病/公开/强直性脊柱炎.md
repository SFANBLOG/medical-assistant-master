# 强直性脊柱炎

强直性脊柱炎是一种以中轴关节和骶髂关节慢性炎症为主的疾病，主要侵犯脊柱，严重时可致脊柱强直、驼背畸形，多见于青年男性。

## 病因
病因未明，与遗传基因HLA-B27密切相关，肠道感染等环境因素可能参与发病，导致脊柱及外周关节出现慢性炎症。

## 主要症状
- 慢性腰背痛、晨僵，活动后减轻、休息后不缓解，夜间痛明显。
- 腰背痛常持续3个月以上，多在40岁以下起病。
- 部分患者出现外周关节炎（膝、踝）、足跟痛、葡萄膜炎（眼红、眼痛、畏光），晚期脊柱僵硬、活动受限。

## 处理建议
- 早期诊断、尽早治疗，注意保持良好姿势。
- 坚持规律功能锻炼，重点是脊柱和胸廓的活动训练，游泳是理想运动。
- 遵医嘱使用非甾体抗炎药、生物制剂等控制炎症，同时戒烟。

## 就医提醒
年轻男性出现久坐或休息后加重的慢性腰背痛伴晨僵，或反复发作葡萄膜炎，应尽早就诊排查强直性脊柱炎，避免延误治疗。

## 检查与诊断
强直性脊柱炎的确诊需要结合临床表现与辅助检查。常用检查包括：血沉、C反应蛋白、类风湿因子、自身抗体谱、关节影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、均衡营养、适度锻炼、避免感染与过度劳累，遵医嘱规范用药，定期复查随访。

## 就医指引
如出现疑似强直性脊柱炎的相关症状，建议及时到风湿免疫科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
