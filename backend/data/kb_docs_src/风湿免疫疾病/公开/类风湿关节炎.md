# 类风湿关节炎

类风湿关节炎是一种以慢性、对称性多关节滑膜炎为主要表现的自身免疫性疾病，主要侵犯双手、腕、足等小关节，可导致关节破坏、畸形和功能丧失。

## 病因
确切病因尚未完全明确，目前认为与遗传易感性、环境因素（如吸烟、感染）和免疫系统异常共同作用有关。免疫系统错误攻击自身关节滑膜组织，引起持续性慢性炎症。

## 主要症状
- 对称性多关节肿痛，常见于双手近端指间关节、掌指关节和腕关节。
- 晨僵：早晨起床后关节僵硬、活动不便，持续常超过1小时。
- 关节外表现：乏力、低热、类风湿结节、肺间质病变、贫血等。

## 处理建议
- 尽早到风湿免疫科规范诊治，确诊后遵医嘱使用改善病情抗风湿药物，切勿自行停药或轻信偏方。
- 急性期适当休息、避免劳累，缓解期进行关节功能锻炼，注意保护关节。
- 戒烟，均衡营养，保持良好心态，定期复查。

## 就医提醒
出现持续数周以上的对称性关节肿痛伴晨僵，或关节明显变形、活动受限时，应及时到风湿免疫科就诊，早期治疗可显著改善预后、减少致残。
