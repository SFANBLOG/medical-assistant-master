# 干燥综合征

干燥综合征是一种以侵犯外分泌腺体为主的慢性自身免疫性疾病，主要表现为口干、眼干，可分为原发性和继发性两类，中年女性多见。

## 病因
病因尚不明确，与遗传、病毒感染（如EB病毒）和免疫异常有关。淋巴细胞浸润泪腺、唾液腺等外分泌腺体，导致腺体分泌功能下降。

## 主要症状
- 口干：唾液减少，饮水频繁，进食干食困难，易发生龋齿、腮腺反复肿大。
- 眼干：眼干涩、异物感、烧灼感、泪液减少。
- 其他：阴道干涩、皮肤干燥，部分患者出现关节痛、乏力，甚至肾小管酸中毒、肺间质病变等系统性损害。

## 处理建议
- 使用人工泪液缓解眼干，适量饮水、含服无糖酸味食物刺激唾液分泌。
- 注意口腔卫生，定期牙科检查，预防龋齿和口腔感染。
- 有系统性表现者应在风湿免疫科规范治疗，定期随访。

## 就医提醒
长期口干、眼干影响生活，或出现腮腺反复肿大、原因不明低钾、反复肺部感染时，应及时到风湿免疫科就诊明确诊断。
