# 硬皮病

硬皮病又称系统性硬化症，是一种以皮肤和内脏器官纤维化为主要特征的自身免疫性疾病，表现为皮肤变硬、变紧，并可累及肺、消化道、心脏、肾脏等。

## 病因
病因尚不完全清楚，与遗传易感性、环境因素及免疫异常有关，导致血管内皮损伤和成纤维细胞过度活化，胶原纤维过度沉积于皮肤和脏器。

## 主要症状
- 皮肤：早期手指肿胀、雷诺现象（遇冷后手指发白、发紫、发红），随后皮肤增厚、变硬、紧绑感，面部呈"面具脸"。
- 消化道：吞咽困难、反酸、烧心。
- 肺：干咳、活动后气短（肺间质纤维化、肺动脉高压）。
- 肾：高血压、蛋白尿，严重者发生硬皮病肾危象。

## 处理建议
- 在风湿免疫科规范诊治，早期识别内脏受累并给予相应治疗。
- 注意保暖，避免寒冷刺激诱发雷诺现象，戒烟。
- 定期随访监测肺、肾、心脏功能，按医嘱用药。

## 就医提醒
出现手指遇冷变白变紫、皮肤变硬伴吞咽困难或进行性气短时，应及时就诊；出现突发高血压伴头痛、少尿，警惕肾危象，需紧急就医。

## 检查与诊断
硬皮病的确诊需要结合临床表现与辅助检查。常用检查包括：血沉、C反应蛋白、类风湿因子、自身抗体谱、关节影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、均衡营养、适度锻炼、避免感染与过度劳累，遵医嘱规范用药，定期复查随访。

## 就医指引
如出现疑似硬皮病的相关症状，建议及时到风湿免疫科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对硬皮病相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
