# 白塞病

白塞病又称贝赫切特综合征，是一种以口腔、外生殖器反复溃疡和眼炎为特征的慢性全身性血管炎症性疾病，可累及全身大、中、小血管。

## 病因
病因未明，可能与遗传（如HLA-B51）、感染和免疫异常有关，引起全身血管炎和多系统损害。

## 主要症状
- 复发性口腔溃疡：每年反复发作数次以上，疼痛明显。
- 生殖器溃疡：反复发作，愈合后常留瘢痕。
- 眼部病变：葡萄膜炎、结膜炎，反复发作可致视力下降甚至失明。
- 皮肤损害：结节性红斑、毛囊炎样皮损、针刺反应阳性。
- 其他：关节炎、静脉血栓、动脉瘤等血管病变，消化道溃疡，神经系统受累。

## 处理建议
- 到风湿免疫科及相应专科（眼科、皮肤科、消化科）联合规范诊治。
- 遵医嘱控制口腔、皮肤和关节症状，眼部及内脏受累者需积极治疗。
- 保持口腔清洁，避免进食刺激性食物。

## 就医提醒
反复口腔溃疡伴生殖器溃疡、眼红、皮肤结节，或出现剧烈腹痛、视力下降、肢体肿胀等提示内脏受累的表现时，应及时就医。

## 检查与诊断
白塞病的确诊需要结合临床表现与辅助检查。常用检查包括：血沉、C反应蛋白、类风湿因子、自身抗体谱、关节影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、均衡营养、适度锻炼、避免感染与过度劳累，遵医嘱规范用药，定期复查随访。

## 就医指引
如出现疑似白塞病的相关症状，建议及时到风湿免疫科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对白塞病相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
