# 血管炎

血管炎是一组以血管壁炎症和坏死为基本病理改变的疾病的总称，可累及全身动脉、静脉和毛细血管，引起相应供血器官缺血、损伤。

## 病因
多数病因不明确，可能与遗传、感染、药物、肿瘤及自身免疫异常有关。不同血管炎类型受累血管大小不同，临床表现多样。

## 主要症状
- 全身症状：发热、乏力、消瘦、关节肌肉酸痛。
- 皮肤：紫癜、皮下结节、网状青斑、溃疡坏死。
- 器官受累：肾炎（血尿、蛋白尿）、肺部病变（咯血、结节）、周围神经病变（肢体麻木无力）、鼻窦炎、耳部炎症等，不同类型表现各异。

## 处理建议
- 血管炎表现多样、易误诊，需到风湿免疫科和相应专科详细检查，明确类型和受累范围。
- 根据病情轻重遵医嘱使用糖皮质激素、免疫抑制剂或生物制剂，需长期规范治疗和随访。
- 注意休息、加强营养，出现并发症时对症处理。

## 就医提醒
出现不明原因发热伴皮肤紫癜、进行性肾功能下降、咯血、神经受损等表现时，应尽早就医明确诊断，血管炎及时治疗可显著改善预后。

## 检查与诊断
血管炎的确诊需要结合临床表现与辅助检查。常用检查包括：血沉、C反应蛋白、类风湿因子、自身抗体谱、关节影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、均衡营养、适度锻炼、避免感染与过度劳累，遵医嘱规范用药，定期复查随访。

## 就医指引
如出现疑似血管炎的相关症状，建议及时到风湿免疫科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对血管炎相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
