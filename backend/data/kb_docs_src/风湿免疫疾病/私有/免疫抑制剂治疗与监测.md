# 免疫抑制剂治疗与监测

免疫抑制剂在风湿免疫病中用于控制疾病活动、减少激素用量，常用药物包括甲氨蝶呤、来氟米特、羟氯喹、吗替麦考酚酯、环磷酰胺、硫唑嘌呤等，需规范用药并密切监测。

## 临床要点
- 不同药物适应证各异：甲氨蝶呤为类风湿关节炎首选改善病情药；环磷酰胺用于狼疮性肾炎和血管炎的重症；吗替麦考酚酯用于狼疮性肾炎、皮肌炎等；羟氯喹广泛用于系统性红斑狼疮。
- 起效较慢，通常需数周至数月，不宜轻易更换。
- 妊娠期多数免疫抑制剂禁用（羟氯喹相对安全），育龄期患者需提前规划。

## 处理与观察重点
- 用药前及用药期间定期监测血常规、肝肾功能；甲氨蝶呤注意补充叶酸，环磷酰胺注意监测血象、尿常规并充分水化。
- 监测感染、骨髓抑制、肝损伤、间质性肺炎等不良反应。
- 评估疗效指标（关节肿痛、皮疹、蛋白尿等），及时调整方案。

## 注意事项
- 注意药物相互作用，如甲氨蝶呤与复方磺胺甲噁唑等合用会增加毒性。
- 用药期间避免接种活疫苗；计划妊娠者需按药物半衰期提前停药。

## 检查与诊断

## 预防与日常保健
规律作息、均衡营养、适度锻炼、避免感染与过度劳累，遵医嘱规范用药，定期复查随访。

## 就医指引
如出现疑似免疫抑制剂治疗与监测的相关症状，建议及时到风湿免疫科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
