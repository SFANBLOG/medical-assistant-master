# 糖皮质激素相关性骨质疏松

长期使用糖皮质激素是继发性骨质疏松最常见的原因，可导致骨量丢失、骨折风险增加，是风湿病患者常见的药物相关并发症，需积极预防和管理。

## 临床要点
- 风险与激素剂量、疗程正相关，小剂量及大剂量均可致骨量丢失，骨折风险在治疗早期（最初3-6个月）即开始增加。
- 主要机制为抑制成骨细胞活性、促进骨吸收及影响钙代谢。
- 所有长期（预计3个月以上）使用糖皮质激素者均应评估骨质疏松风险。

## 处理与观察重点
- 使用最小有效剂量和最短疗程，尽早减量或停用；鼓励功能锻炼、戒烟、限制饮酒。
- 常规补充钙剂与维生素D；中高骨折风险者加用抗骨吸收或促骨形成药物。
- 定期行双能X线骨密度检测，监测脊柱和髋部骨折风险，注意椎体骨折的识别。

## 注意事项
- 注意与其他继发性骨质疏松的病因（性腺功能减退、甲亢等）鉴别。
- 已发生脆性骨折者应尽快干预，降低再次骨折风险。
