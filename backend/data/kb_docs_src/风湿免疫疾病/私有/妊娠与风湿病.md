# 妊娠与风湿病

风湿病多发于育龄期女性，妊娠与风湿病相互影响：多数自身免疫病在妊娠期病情可变化，部分药物对胎儿有影响，需多学科协作做好孕前评估和孕期管理。

## 临床要点
- 孕前应进行病情评估：将疾病控制在稳定/缓解状态后再计划妊娠，及时停用致畸药物。
- 甲氨蝶呤、来氟米特、吗替麦考酚酯、环磷酰胺等有致畸风险，需提前停药（来氟米特需洗脱）；羟氯喹、糖皮质激素（泼尼松相对安全）、硫唑嘌呤在部分情况下可继续使用。
- 抗SSA/SSB抗体阳性者，胎儿有发生先天性心脏传导阻滞风险，需产科超声监测；抗磷脂抗体阳性者注意血栓与不良妊娠结局的预防。

## 处理与观察重点
- 孕期病情活动（尤其狼疮、狼疮性肾炎）可增加流产、早产、子痫前期等风险，应加强风湿科与产科联合随访。
- 产后为疾病复发高峰，需警惕并适时调整治疗。

## 注意事项
- 哺乳期用药需评估药物向乳汁的转运和安全性。
- 建立风湿科、产科、新生儿科多学科团队，实施个体化全程管理。

## 检查与诊断
妊娠与风湿病的确诊需要结合临床表现与辅助检查。常用检查包括：血沉、C反应蛋白、类风湿因子、自身抗体谱、关节影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、均衡营养、适度锻炼、避免感染与过度劳累，遵医嘱规范用药，定期复查随访。

## 就医指引
如出现疑似妊娠与风湿病的相关症状，建议及时到风湿免疫科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对妊娠与风湿病相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
