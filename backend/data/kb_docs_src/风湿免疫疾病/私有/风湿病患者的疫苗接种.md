# 风湿病患者的疫苗接种

风湿病患者因疾病本身和免疫抑制治疗，感染风险增加，疫苗接种是重要的预防措施，但需根据用药情况合理选择疫苗种类与接种时机。

## 临床要点
- 推荐接种灭活疫苗（如流感、肺炎球菌、新冠疫苗、乙肝疫苗），风湿病患者获益明确。
- 正在使用大剂量糖皮质激素、免疫抑制剂或生物制剂的患者，对活疫苗（麻疹、腮腺炎、风疹、水痘、带状疱疹活疫苗、卡介苗）应避免使用或延迟接种。
- 重组/灭活带状疱疹疫苗（非活疫苗）可用于多数风湿病患者，接种前需评估。

## 处理与观察重点
- 接种时机尽量选择在疾病稳定期；使用利妥昔单抗等耗竭B细胞的药物者，疫苗接种应安排在下一疗程前或停药数月后，以提高免疫应答。
- 接种后注意观察有无发热、局部反应及疾病活动变化。

## 注意事项
- 家属可正常接种灭活及活疫苗（对患者构成传播风险的活疫苗除外，如口服脊灰活疫苗）。
- 疫苗免疫应答可能降低，不能因此否定接种获益。

## 检查与诊断
风湿病患者的疫苗接种的确诊需要结合临床表现与辅助检查。常用检查包括：血沉、C反应蛋白、类风湿因子、自身抗体谱、关节影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、均衡营养、适度锻炼、避免感染与过度劳累，遵医嘱规范用药，定期复查随访。

## 就医指引
如出现疑似风湿病患者的疫苗接种的相关症状，建议及时到风湿免疫科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对风湿病患者的疫苗接种相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
