# 糖皮质激素的规范使用

糖皮质激素是风湿免疫病治疗的基础药物之一，具有强大的抗炎和免疫抑制作用，但长期大剂量使用不良反应多，需规范、个体化使用。

## 临床要点
- 掌握适应证：系统性红斑狼疮、血管炎、多发性肌炎/皮肌炎、类风湿关节炎严重活动期等。
- 遵循"小剂量起始、按病情调整、病情控制后逐渐减量"的原则，尽可能使用能控制病情的最低有效剂量。
- 短疗程冲击治疗适用于狼疮危象、严重脏器受累等急重症。

## 处理与观察重点
- 密切监测感染、血糖升高、血压升高、消化道溃疡、骨质疏松、股骨头坏死、精神症状等不良反应。
- 长期使用者常规补充钙剂和维生素D，预防骨质疏松。
- 减量与停药需缓慢进行，避免骤停导致肾上腺皮质功能不全或病情反跳。

## 注意事项
- 联合免疫抑制剂有助于激素减量，减少累积剂量。
- 用药前评估并处理感染、血糖、血压等基础问题，用药期间按时复诊随访。
