# 生物制剂使用规范

生物制剂通过靶向阻断炎症通路治疗风湿免疫病，具有起效快、疗效好的特点，包括肿瘤坏死因子抑制剂、IL-6受体拮抗剂、B细胞靶向药物等，使用需规范筛查与监测。

## 临床要点
- 明确适应证：多用于传统改善病情抗风湿药疗效不佳或不耐受的中重度类风湿关节炎、强直性脊柱炎、银屑病关节炎等。
- 用药前筛查结核（胸片、T-SPOT/PPD）、肝炎病毒、HIV等感染指标，评估有无恶性肿瘤、充血性心力衰竭等禁忌。
- 可与甲氨蝶呤等联合使用增强疗效；疗效不佳、继发失效或出现不良反应时可考虑换用不同作用机制的药物。

## 处理与观察重点
- 用药期间警惕感染（尤其结核、严重细菌和机会性感染）、注射部位反应、过敏反应。
- 定期监测血常规、肝肾功能、感染指标，长期用药注意肿瘤和心脏事件风险。
- 择期手术或出现严重感染时，按药物半衰期暂时停用生物制剂。

## 注意事项
- 活疫苗（如卡介苗、带状疱疹活疫苗）禁忌于使用生物制剂期间，接种灭活疫苗相对安全。
- 妊娠期用药需个体化评估，多数生物制剂不推荐或需权衡利弊。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
生物制剂使用规范的确诊需要结合临床表现与辅助检查。常用检查包括：血沉、C反应蛋白、类风湿因子、自身抗体谱、关节影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、均衡营养、适度锻炼、避免感染与过度劳累，遵医嘱规范用药，定期复查随访。

## 就医指引
如出现疑似生物制剂使用规范的相关症状，建议及时到风湿免疫科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
