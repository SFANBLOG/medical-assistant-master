# 风湿病合并感染的处理

感染是风湿病患者常见并发症和重要死因之一，疾病本身免疫功能紊乱与免疫抑制治疗均增加感染风险，需及时识别、规范治疗，并权衡抗感染与抗风湿治疗。

## 临床要点
- 风湿病发热或病情活动加重时，需与合并感染鉴别：病原学检查、感染标志物（降钙素原、CRP）、影像学等有助于鉴别。
- 免疫抑制治疗（激素、免疫抑制剂、生物制剂）增加细菌、病毒、结核、真菌及机会性感染风险，用药前应完成结核、乙肝等筛查。
- 感染高风险患者考虑预防性用药，如肺孢子菌肺炎的预防。

## 处理与观察重点
- 疑似感染时尽早明确病原，经验性抗感染应覆盖常见病原并关注耐药。
- 根据感染严重程度适当调整或暂停免疫抑制治疗，重症感染时优先控制感染，病情允许再逐步恢复抗风湿治疗。
- 密切监测生命体征、血象和器官功能，警惕脓毒症。

## 注意事项
- 感染控制后需评估是否调整原风湿病治疗方案（如减少激素剂量），预防复发。
- 加强疫苗接种和卫生宣教，减少感染发生。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
风湿病合并感染的处理的确诊需要结合临床表现与辅助检查。常用检查包括：血沉、C反应蛋白、类风湿因子、自身抗体谱、关节影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、均衡营养、适度锻炼、避免感染与过度劳累，遵医嘱规范用药，定期复查随访。

## 就医指引
如出现疑似风湿病合并感染的处理的相关症状，建议及时到风湿免疫科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
