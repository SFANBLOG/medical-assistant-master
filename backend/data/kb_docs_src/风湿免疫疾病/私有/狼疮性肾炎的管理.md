# 狼疮性肾炎的管理

狼疮性肾炎是系统性红斑狼疮常见且严重的并发症，是导致狼疮患者肾功能衰竭和死亡的重要原因，需早发现、早治疗、规范化管理。

## 临床要点
- 确诊狼疮后应常规筛查尿常规、肾功能、血压；活动期狼疮患者建议行肾脏活检明确病理分型（I-VI型），以指导治疗。
- 蛋白尿、血尿、高血压、肾功能下降提示肾脏受累；治疗以糖皮质激素联合免疫抑制剂为主，重症（增生性肾炎）可选用环磷酰胺或吗替麦考酚酯诱导，缓解后维持治疗。
- 治疗目标：达到临床缓解、减少复发、保护肾功能。

## 处理与观察重点
- 定期复查尿蛋白定量、肾功能、血清补体和抗dsDNA抗体，评估疾病活动与疗效。
- 控制血压和蛋白尿，合理使用ACEI/ARB类药物，监测电解质和酸碱平衡。
- 避免肾毒性药物、感染和非甾体抗炎药等诱因，妊娠期注意肾功能评估。

## 注意事项
- 诱导与维持治疗周期较长，需坚持随访，不可随意停药。
- 出现肾功能快速恶化、少尿时警惕急性肾损伤，及时评估和处理。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
狼疮性肾炎的管理的确诊需要结合临床表现与辅助检查。常用检查包括：血沉、C反应蛋白、类风湿因子、自身抗体谱、关节影像学检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、均衡营养、适度锻炼、避免感染与过度劳累，遵医嘱规范用药，定期复查随访。

## 就医指引
如出现疑似狼疮性肾炎的管理的相关症状，建议及时到风湿免疫科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对狼疮性肾炎的管理相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
