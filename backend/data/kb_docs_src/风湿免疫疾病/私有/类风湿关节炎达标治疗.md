# 类风湿关节炎达标治疗

达标治疗是当前类风湿关节炎的核心治疗策略，即通过积极、规范的治疗尽早达到临床缓解或低疾病活动度，以阻止关节破坏、改善长期预后。

## 临床要点
- 以疾病活动度评分（如DAS28、CDAI、SDAI）等工具定期评估病情，设定明确的治疗目标（缓解或低疾病活动度）。
- 确诊后尽早使用传统改善病情抗风湿药（如甲氨蝶呤），疗效不佳者联合用药或及时升级为生物制剂/靶向药。
- 每1-3个月评估一次，未达标时调整方案，直至达标。

## 处理与观察重点
- 评估关节肿痛数、晨僵、急性期反应物（ESR、CRP）及患者整体评价，结合影像学监测关节破坏进展。
- 关注共病（心血管疾病、感染、骨质疏松）和药物不良反应。
- 达标后仍需规律随访、监测复发，维持期可适当延长复查间隔。

## 注意事项
- 达标治疗强调医患共同决策，患者教育与依从性是关键。
- 不应仅凭症状缓解即停药，需在医生指导下逐步调整，防止复发。

## 就医指引
如出现疑似类风湿关节炎达标治疗的相关症状，建议及时到风湿免疫科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对类风湿关节炎达标治疗相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
