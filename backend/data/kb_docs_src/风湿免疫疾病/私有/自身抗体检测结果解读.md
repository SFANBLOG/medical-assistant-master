# 自身抗体检测结果解读

自身抗体检测是风湿免疫病诊断与评估的重要工具，但结果解读需结合临床表现，不能仅凭单一抗体阳性或阴性作出诊断。

## 临床要点
- 抗核抗体（ANA）：是多种系统性自身免疫病的筛查指标，阳性可见于系统性红斑狼疮、干燥综合征、硬皮病等，也可出现于感染、药物及部分健康老年人，需进一步行特异性抗体检测。
- 抗dsDNA抗体：对狼疮诊断特异性较高，滴度与疾病活动性相关，可用于病情监测。
- 抗Sm抗体：狼疮高度特异。
- 抗SSA/SSB抗体：与干燥综合征、狼疮相关，可致新生儿狼疮。
- 类风湿因子（RF）与抗CCP抗体：抗CCP对类风湿关节炎特异性高，有助于早期诊断；RF可见于其他疾病及部分健康者。
- 抗中性粒细胞胞质抗体（ANCA）：与ANCA相关性血管炎密切相关。
- 抗磷脂抗体：与血栓、复发性流产相关，用于抗磷脂综合征的诊断。

## 处理与观察重点
- 抗体结果需与临床表现、受累器官和病程综合分析，动态监测疾病活动性。
- 对阳性结果应解释其意义，避免造成不必要焦虑；高度疑似患者即使抗体阴性也应结合临床追踪随访。

## 注意事项
- 不同实验室的参考范围与检测方法存在差异，结果判读应结合本实验室标准。
- 免疫球蛋白输注等治疗可能干扰检测结果，需结合临床反复复查。
