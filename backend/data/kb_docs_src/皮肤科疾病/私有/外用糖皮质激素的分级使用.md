# 外用糖皮质激素的分级使用

外用糖皮质激素是皮肤科最常用的药物之一，合理分级、足量足疗程并规避不良反应是临床运用的重点。

## 临床要点
按抗炎强度可分为超强、强、中、弱四级（对应Ⅰ—Ⅶ类）。弱效激素适用于面部、眼睑、腋下、腹股沟等薄嫩部位及婴幼儿；中效激素用于躯干四肢的多数皮炎湿疹；强效激素用于手足、肘膝等角化增厚部位；超强效激素仅短期用于顽固厚皮损。应在医生指导下选择强度，避免自行长期使用。

## 处理与观察重点
采用阶梯疗法：急性期选用适当强度激素迅速控制，缓解后逐步降级并配合保湿剂维持。每日1-2次薄涂于皮损，避免大面积长期使用。用药2周无效或出现依赖者应重新评估诊断。观察局部皮肤萎缩、毛细血管扩张、色素改变、继发感染及激素依赖等不良反应。

## 注意事项
面部、褶皱部位慎用强效激素；妊娠期、哺乳期及儿童用药需评估利弊；真菌、病毒、细菌等感染性皮肤病禁用或需与抗感染药物联用；停用应逐步减量，不可骤停以免反跳。
