# 光疗与生物制剂

光疗与生物制剂是中重度皮肤病（如银屑病、特应性皮炎）的重要治疗手段，需评估适应证、禁忌证并规范监测。

## 临床要点
光疗主要包括窄谱中波紫外线（NB-UVB）和补骨脂素联合长波紫外线（PUVA），适用于泛发性银屑病、特应性皮炎等，需按个体情况计算累积剂量。生物制剂包括TNF-α抑制剂、IL-17/IL-23抑制剂、IL-4/IL-13通路抑制剂等，靶向性强，适用于对传统治疗反应不佳的中重度患者。

## 处理与观察重点
光疗前评估患者皮肤类型、光敏史及基础疾病，治疗中记录累积剂量并观察红斑、灼伤、水疱等反应；定期随访，长期光疗注意光老化及皮肤肿瘤风险。生物制剂治疗前筛查结核、乙肝、丙肝等潜伏感染，治疗中观察注射部位反应、过敏及机会性感染，定期复查血常规、肝肾功能及炎症指标。

## 注意事项
对光敏感者、有皮肤肿瘤病史或使用光敏药物者慎用光疗；生物制剂治疗期间不建议接种活疫苗，出现严重感染需暂停用药；育龄期、妊娠哺乳期患者需权衡利弊；用药转换与联合治疗需评估免疫抑制叠加风险。

## 检查与诊断
光疗与生物制剂的确诊需要结合临床表现与辅助检查。常用检查包括：皮肤专科视诊、真菌镜检、过敏原检测、皮肤病理活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
保持皮肤清洁保湿、避免过度搔抓与日晒，选择温和护肤品，注意个人物品不共用，出现皮疹及时就诊。

## 就医指引
如出现疑似光疗与生物制剂的相关症状，建议及时到皮肤科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
