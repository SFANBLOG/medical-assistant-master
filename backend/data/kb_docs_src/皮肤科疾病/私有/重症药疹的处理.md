# 重症药疹的处理

重症药疹（如Stevens-Johnson综合征、中毒性表皮坏死松解症、DRESS综合征等）病情凶险、可危及生命，需早期识别、及时停药并多学科协作处理。

## 临床要点
常见重症药疹包括SJS/TEN、DRESS综合征及急性泛发性发疹性脓疱病等，常由磺胺类、别嘌醇、抗癫痫药、非甾体抗炎药等诱发。SJS/TEN以表皮广泛松解、黏膜受累为特征；DRESS以皮疹伴发热、淋巴结肿大、内脏器官受累和嗜酸性粒细胞增多为特征。早期发现高危皮损和全身症状是救治关键。

## 处理与观察重点
立即停用可疑药物并记录完整用药史；评估皮损面积、黏膜及内脏受累程度；转入监护条件完善的科室，做好创面护理，防治感染、水电解质紊乱和多器官功能不全；严重病例可考虑糖皮质激素、静脉注射免疫球蛋白等（需个体化权衡）。定期监测血常规、肝肾功能、电解质及感染指标，警惕并发症。

## 注意事项
严格避免再次使用可疑及结构类似药物，并完善药物过敏史记录；SJS/TEN急性期避免使用可能加重表皮松解的药物；密切观察病情演变，早期识别脓毒症、呼吸衰竭等危象；与皮肤科、重症医学科、眼科等多学科协作。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
重症药疹的处理的确诊需要结合临床表现与辅助检查。常用检查包括：皮肤专科视诊、真菌镜检、过敏原检测、皮肤病理活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
保持皮肤清洁保湿、避免过度搔抓与日晒，选择温和护肤品，注意个人物品不共用，出现皮疹及时就诊。

## 就医指引
如出现疑似重症药疹的处理的相关症状，建议及时到皮肤科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
