# 银屑病的系统治疗

中重度银屑病常需系统治疗，应依据病情严重程度、共病及患者意愿个体化选择方案并定期监测。

## 临床要点
系统治疗适用于中重度（如PASI、BSA达到相应标准）、外用及光疗反应不佳或伴关节受累者。主要选择包括甲氨蝶呤、环孢素、阿维A及生物制剂（TNF-α抑制剂、IL-17/IL-23抑制剂等）。生物制剂疗效确切、靶向性强，但需严格筛选适应证并评估结核、肝炎等潜伏感染。

## 处理与观察重点
治疗前完成基线评估（血常规、肝肾功能、血脂、感染筛查等）。甲氨蝶呤注意肝毒性和骨髓抑制，需补充叶酸并定期复查；环孢素监测血压和肾功能；阿维A育龄期患者需严格避孕，并监测血脂、肝酶；生物制剂治疗中观察注射部位反应、感染及过敏表现。

## 注意事项
系统治疗宜阶梯或联合使用，避免多种免疫抑制剂叠加；合并心血管疾病、代谢综合征者需综合管理；治疗期间避免接种活疫苗；育龄期患者需关注妊娠哺乳安全性。

银屑病的系统治疗的确诊需要结合临床表现与辅助检查。常用检查包括：皮肤专科视诊、真菌镜检、过敏原检测、皮肤病理活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
保持皮肤清洁保湿、避免过度搔抓与日晒，选择温和护肤品，注意个人物品不共用，出现皮疹及时就诊。

## 就医指引
如出现疑似银屑病的系统治疗的相关症状，建议及时到皮肤科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对银屑病的系统治疗相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
