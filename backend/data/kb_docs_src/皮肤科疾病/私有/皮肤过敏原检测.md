# 皮肤过敏原检测

过敏原检测用于辅助诊断过敏性皮肤病（如特应性皮炎、荨麻疹）的诱因，应结合病史选择方法并正确解读结果。

## 临床要点
常用方法包括点刺试验和特异性IgE检测（针对Ⅰ型速发型过敏反应）以及斑贴试验（针对迟发型接触性过敏）。点刺试验快速、敏感，适用于吸入性和食物过敏原筛查；斑贴试验用于化妆品、金属、外用药等接触性过敏的检测。检测方法的选择需依据病史和临床表现。

## 处理与观察重点
检测前需停用抗组胺药（点刺试验一般停药数天至一周）及部分可能影响结果的药物；操作规范并设阳性、阴性对照；点刺试验观察15-20分钟并记录风团大小；斑贴试验在贴敷48小时及72小时等时间点判读。结果解读需结合临床，阳性不等同于致病，阴性也不能完全排除。

## 注意事项
急性期、严重皮肤病及全身状态不佳者暂缓检测；点刺试验有诱发严重过敏的风险，须在具备急救条件的医疗机构进行；避免过度检查，减少对低临床相关性过敏原的广泛筛查。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
皮肤过敏原检测的确诊需要结合临床表现与辅助检查。常用检查包括：皮肤专科视诊、真菌镜检、过敏原检测、皮肤病理活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
保持皮肤清洁保湿、避免过度搔抓与日晒，选择温和护肤品，注意个人物品不共用，出现皮疹及时就诊。

## 就医指引
如出现疑似皮肤过敏原检测的相关症状，建议及时到皮肤科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
