# 皮肤护理与保湿

皮肤屏障维护是皮肤病治疗和预防复发的基础，规范保湿与正确护肤对湿疹、银屑病等多种疾病具有重要意义。

## 临床要点
皮肤屏障主要由角质层及皮脂膜构成，受损后水分丢失增加，易诱发或加重炎症性皮肤病。保湿剂通过封闭、湿润和补充天然保湿因子发挥作用，按成分可分为封闭剂（如凡士林）、湿润剂（如甘油、尿素）等。日常护肤遵循清洁-保湿-防晒的基本原则，选择合适的剂型和产品。

## 处理与观察重点
干性及湿疹皮肤应足量多次涂抹保湿剂，沐浴后3分钟内使用效果更佳；选择温和、低刺激、无香料的清洁与保湿产品，避免过度清洗和热水烫洗；针对不同肤质和季节调整产品类型；注意观察使用后是否出现刺激、过敏等反应并及时调整。

## 注意事项
外用药与保湿剂应错开时间使用，一般先用药再保湿或遵医嘱；婴幼儿、老年人及敏感性皮肤需选择更温和的产品；保湿剂不能替代药物治疗，活动期皮损仍应按方案用药；对成分过敏者需查看产品成分表，谨慎选择。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
皮肤护理与保湿的确诊需要结合临床表现与辅助检查。常用检查包括：皮肤专科视诊、真菌镜检、过敏原检测、皮肤病理活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
保持皮肤清洁保湿、避免过度搔抓与日晒，选择温和护肤品，注意个人物品不共用，出现皮疹及时就诊。

## 就医指引
如出现疑似皮肤护理与保湿的相关症状，建议及时到皮肤科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
