# 皮肤色素痣与黑色素瘤筛查

色素痣是常见的良性皮肤肿瘤，绝大多数无需处理；但需警惕极少数痣恶变为黑色素瘤，早期识别与筛查尤为重要。

## 病因
色素痣由黑色素细胞局部聚集而成，多与遗传和日晒等有关；黑色素瘤的发生与紫外线长期过度暴露、皮肤白皙、家族史、多发痣及不典型痣等危险因素相关。

## 主要症状
- 色素痣多呈圆形、边界清楚、颜色均匀，大小长期稳定
- 需警惕"ABCDE"征象：不对称、边缘不规则、颜色不均匀、直径大于6毫米、进行性增大或变化
- 痣出现出血、溃疡、瘙痒、疼痛或周围出现卫星状皮损时需警惕
- 黑色素瘤可发生于原有痣上，也可新发

## 处理建议
- 避免过度日晒，外出做好防晒（遮阳、衣物、防晒霜）
- 不建议随意点痣或反复摩擦、刺激痣体
- 定期自我检查皮肤，注意背部、头皮等不易观察部位
- 有黑色素瘤家族史或较多不典型痣者应定期到皮肤科筛查

## 就医提醒
痣出现快速增大、颜色形状改变、出血溃疡、不对称或不规则边缘等任一可疑征象，或新出现异常黑斑者，应及时就医，必要时行皮肤镜检查或病理活检。

## 预防与日常保健
