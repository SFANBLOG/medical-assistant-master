# 真菌性皮肤感染

真菌性皮肤感染是由致病性真菌侵犯皮肤、毛发和甲引起的疾病，统称浅部真菌病，如体癣、股癣、手癣、头癣、甲癣等。

## 病因
由皮肤癣菌（如毛癣菌、小孢子菌）和念珠菌等真菌感染引起；温暖潮湿环境、多汗、贴身衣物透气差、共用毛巾拖鞋、宠物携带以及机体免疫力下降等均为易感因素。

## 主要症状
- 皮肤感染：圆形或多环形红斑、脱屑，边界清楚，伴瘙痒
- 毛发感染：头皮脱屑、脱发斑、断发（头癣）
- 甲感染：甲板增厚、变黄、浑浊、凹凸不平（甲癣）
- 皮肤褶皱部位可表现为浸渍、红斑、糜烂

## 处理建议
- 外用抗真菌药膏，需足疗程用药以防复发
- 保持皮肤清洁干燥，勤换衣物鞋袜，避免局部闷热
- 头癣、甲癣或皮损广泛者可在医生指导下口服抗真菌药物
- 不与他人共用毛巾、拖鞋、梳子，并做好个人物品消毒

## 就医提醒
自行用药无效、皮损范围扩大，或头癣发生在儿童、甲癣影响日常生活者，应及时到皮肤科就诊，确诊后规范治疗。

真菌性皮肤感染的确诊需要结合临床表现与辅助检查。常用检查包括：皮肤专科视诊、真菌镜检、过敏原检测、皮肤病理活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
保持皮肤清洁保湿、避免过度搔抓与日晒，选择温和护肤品，注意个人物品不共用，出现皮疹及时就诊。

## 就医指引
如出现疑似真菌性皮肤感染的相关症状，建议及时到皮肤科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
