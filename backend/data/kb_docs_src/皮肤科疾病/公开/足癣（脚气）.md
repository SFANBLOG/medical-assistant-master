# 足癣（脚气）

足癣俗称"脚气"，是皮肤癣菌感染足部皮肤引起的常见真菌性皮肤病，在温暖潮湿地区高发，易反复发作。

## 病因
由红色毛癣菌等皮肤癣菌感染引起，真菌在温暖潮湿环境下繁殖迅速；共用拖鞋、毛巾、脚盆，或赤足行走于公共浴室、泳池等场所均可造成传播。

## 主要症状
- 趾间浸渍、发白、脱屑，伴瘙痒
- 足底、足缘出现红斑、水疱或角化增厚、脱屑
- 瘙痒明显，搔抓后可继发细菌感染
- 常与甲癣（灰指甲）并存，可累及手部形成手癣

## 处理建议
- 外用抗真菌药膏，需坚持足疗程用药，症状消失后仍应继续一段时间以防复发
- 保持足部清洁干燥，勤换鞋袜，选择透气性好的鞋袜
- 不与他人共用拖鞋、毛巾、洗脚盆
- 感染较重或反复发作者可在医生指导下口服抗真菌药物

## 就医提醒
自行用药多周无效、皮损红肿渗液伴疼痛（疑有继发感染），或合并糖尿病等基础疾病者，应及时就医，避免延误治疗。
