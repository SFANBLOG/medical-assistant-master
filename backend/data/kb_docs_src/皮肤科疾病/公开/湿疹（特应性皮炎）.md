# 湿疹（特应性皮炎）

湿疹是一种由多因素引起的慢性炎症性皮肤病，特应性皮炎是其最常见的类型，常伴皮肤屏障功能障碍与免疫异常，婴幼儿和儿童多见。

## 病因
与遗传过敏体质、皮肤屏障受损、免疫反应失调及环境因素（气候变化、过敏原、刺激物等）有关，常于婴幼儿期起病，可伴哮喘、过敏性鼻炎等特应性疾病史。

## 主要症状
- 皮肤干燥、剧烈瘙痒
- 红斑、丘疹、小水疱，抓破后可渗出、结痂
- 慢性期皮肤增厚、呈苔藓样变
- 好发于面颊、肘窝、腘窝、颈部及手足等部位

## 处理建议
- 坚持保湿：每日多次使用润肤剂，修复皮肤屏障
- 避免诱因：减少搔抓、热水烫洗及刺激性洗护用品
- 急性期在医生指导下外用糖皮质激素药膏，瘙痒明显时口服抗组胺药
- 穿宽松棉质衣物，保持环境凉爽，避免出汗闷热

## 就医提醒
皮疹泛发、瘙痒剧烈影响睡眠，或出现皮肤感染表现（红肿、脓疱、渗液增多）时，应及时到皮肤科就诊，不宜自行长期使用激素药膏。

## 检查与诊断
湿疹（特应性皮炎）的确诊需要结合临床表现与辅助检查。常用检查包括：皮肤专科视诊、真菌镜检、过敏原检测、皮肤病理活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
保持皮肤清洁保湿、避免过度搔抓与日晒，选择温和护肤品，注意个人物品不共用，出现皮疹及时就诊。

## 就医指引
如出现疑似湿疹（特应性皮炎）的相关症状，建议及时到皮肤科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对湿疹（特应性皮炎）相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
