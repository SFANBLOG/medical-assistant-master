# 带状疱疹

带状疱疹俗称"缠腰龙""蛇缠腰"，是由潜伏在体内的水痘-带状疱疹病毒再激活引起的急性感染性皮肤病。

## 病因
初次感染该病毒多表现为水痘，痊愈后病毒潜伏于神经节内；当机体免疫力下降（如劳累、衰老、疾病、使用免疫抑制剂）时，病毒沿神经再激活，引起神经炎和皮肤损害。

## 主要症状
- 发疹前常先有局部皮肤灼痛、刺痛或麻木感
- 沿单侧神经分布出现成簇红斑、水疱，通常不超过身体中线
- 伴明显神经痛，年龄越大疼痛越剧烈、持续时间越长
- 好发于胸背、腰腹、头面及四肢

## 处理建议
- 发病早期（72小时内）在医生指导下使用抗病毒药物可缩短病程、减轻神经痛
- 保持皮损清洁干燥，避免搔抓，防止继发感染
- 神经痛明显者可遵医嘱使用止痛药物
- 注意休息，提高机体免疫力

## 就医提醒
皮疹位于眼周或头面部、免疫功能低下者、皮疹广泛或伴发热，以及神经痛持续超过1个月者，应及时就医，预防并发症和后遗神经痛。

## 检查与诊断
带状疱疹的确诊需要结合临床表现与辅助检查。常用检查包括：皮肤专科视诊、真菌镜检、过敏原检测、皮肤病理活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
保持皮肤清洁保湿、避免过度搔抓与日晒，选择温和护肤品，注意个人物品不共用，出现皮疹及时就诊。

## 就医指引
如出现疑似带状疱疹的相关症状，建议及时到皮肤科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对带状疱疹相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
