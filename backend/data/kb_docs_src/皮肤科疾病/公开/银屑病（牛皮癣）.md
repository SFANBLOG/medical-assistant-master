# 银屑病（牛皮癣）

银屑病俗称"牛皮癣"，是一种由免疫系统异常介导的慢性炎症性皮肤病，病程慢性、易反复发作，但不具有传染性。

## 病因
确切病因尚未完全明确，目前认为与遗传易感性、免疫紊乱及环境因素（感染、精神应激、药物、吸烟饮酒等）共同作用有关，并非真菌感染或卫生问题所致。

## 主要症状
- 边界清楚的红斑上覆银白色鳞屑
- 刮除鳞屑后可见薄膜现象及点状出血
- 好发于头皮、肘膝伸侧、腰骶部，也可累及指甲和关节
- 部分患者伴关节疼痛（银屑病关节炎）

## 处理建议
- 外用保湿剂、糖皮质激素、维生素D3衍生物等药物控制皮损
- 中重度患者在医生指导下接受光疗或系统性治疗
- 避免搔抓、外伤和过度紧张，戒烟限酒
- 保持皮肤湿润，规律作息

## 就医提醒
皮损范围广泛、常规治疗无效，或出现关节肿痛、发热等表现时，应及时就诊，由专科医生制定个体化治疗方案。
