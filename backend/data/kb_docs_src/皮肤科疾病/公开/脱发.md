# 脱发

脱发是常见的毛发问题，包括雄激素性脱发、斑秃、休止期脱发等多种类型，病因和处理各不相同，需先明确类型再针对性治疗。

## 病因
雄激素性脱发与遗传和雄激素作用有关；斑秃多与自身免疫、精神应激相关；休止期脱发常见于产后、大病、节食减肥或精神压力之后；此外药物、头皮疾病、营养不良等也可引起脱发。

## 主要症状
- 雄激素性脱发：前额发际线后退、头顶毛发稀疏
- 斑秃：头皮出现圆形、边界清楚的脱发斑
- 休止期脱发：全头弥漫性掉发增多，洗头、梳头时明显
- 头皮红肿、瘢痕或短时间内大量脱发时应重视

## 处理建议
- 均衡饮食，保证蛋白质、铁、锌等营养素摄入
- 规律作息，减轻精神压力，避免过度烫染
- 雄激素性脱发可在医生指导下使用米诺地尔外用及口服药物
- 梳洗动作轻柔，避免牵拉性脱发

## 就医提醒
短时间内出现大量脱发、脱发斑不断扩大，或伴头皮瘙痒、红斑、疼痛及全身症状者，应到皮肤科就诊，明确脱发类型后再规范治疗。

## 检查与诊断
脱发的确诊需要结合临床表现与辅助检查。常用检查包括：皮肤专科视诊、真菌镜检、过敏原检测、皮肤病理活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
保持皮肤清洁保湿、避免过度搔抓与日晒，选择温和护肤品，注意个人物品不共用，出现皮疹及时就诊。

## 就医指引
如出现疑似脱发的相关症状，建议及时到皮肤科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对脱发相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
