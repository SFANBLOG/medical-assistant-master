# 痤疮（青春痘）

痤疮是一种累及毛囊皮脂腺单位的慢性炎症性皮肤病，多发于青春期，常表现为粉刺、丘疹、脓疱，严重时可形成结节和囊肿，影响外观和心理。

## 病因
主要与雄激素水平升高致皮脂分泌增多、毛囊口角化异常、痤疮丙酸杆菌繁殖及炎症反应有关；遗传、高糖高脂饮食、精神压力及化妆品使用不当等可加重病情。

## 主要症状
- 粉刺：开放粉刺（黑头）与闭合粉刺（白头）
- 炎性丘疹、脓疱
- 严重者可出现结节、囊肿，愈后遗留瘢痕
- 好发于面颊、额部、下颌及胸背部

## 处理建议
- 温和清洁面部，避免过度搓洗和挤压
- 使用非致粉刺性护肤品，保持规律作息和清淡饮食
- 轻中度痤疮可在医生指导下使用外用维A酸类、过氧化苯甲酰等药物
- 中重度痤疮应尽早就诊，规范治疗可减少留疤

## 就医提醒
面部出现大量结节、囊肿、脓疱，自行用药无效或留有明显色素沉着和瘢痕者，建议到皮肤科就诊；切勿自行挤压面部危险三角区皮损。

## 检查与诊断
痤疮（青春痘）的确诊需要结合临床表现与辅助检查。常用检查包括：皮肤专科视诊、真菌镜检、过敏原检测、皮肤病理活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
保持皮肤清洁保湿、避免过度搔抓与日晒，选择温和护肤品，注意个人物品不共用，出现皮疹及时就诊。

## 就医指引
如出现疑似痤疮（青春痘）的相关症状，建议及时到皮肤科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对痤疮（青春痘）相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
