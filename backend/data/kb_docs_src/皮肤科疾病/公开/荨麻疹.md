# 荨麻疹

荨麻疹俗称"风疹块"，是皮肤黏膜因血管通透性增加而出现的局限性水肿反应，表现为骤然出现的瘙痒性风团，单个风团多在24小时内消退。

## 病因
病因多样，常见诱因包括食物（鱼虾、蛋奶等）、药物（抗生素、解热镇痛药等）、感染、昆虫叮咬、物理因素（冷热、压力、日晒）以及精神紧张等，部分病例难以找到确切原因。

## 主要症状
- 皮肤出现大小不等的红色或苍白色风团，常成批出现
- 剧烈瘙痒，可有烧灼感
- 单个风团数小时内自行消退，不留痕迹
- 累及黏膜时可出现口唇、眼睑肿胀（血管性水肿）

## 处理建议
- 寻找并尽量避免可疑诱因
- 口服抗组胺药可缓解瘙痒和风团
- 避免搔抓，可冷敷止痒
- 多数急性荨麻疹在数天至数周内缓解

## 就医提醒
若出现喉头水肿、呼吸困难、胸闷、腹痛、头晕或血压下降等表现，提示可能为严重过敏反应，应立即急诊就医。

## 检查与诊断
荨麻疹的确诊需要结合临床表现与辅助检查。常用检查包括：皮肤专科视诊、真菌镜检、过敏原检测、皮肤病理活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
保持皮肤清洁保湿、避免过度搔抓与日晒，选择温和护肤品，注意个人物品不共用，出现皮疹及时就诊。

## 就医指引
如出现疑似荨麻疹的相关症状，建议及时到皮肤科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对荨麻疹相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
