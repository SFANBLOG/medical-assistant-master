# 消化性溃疡

消化性溃疡主要指发生在胃和十二指肠的慢性溃疡，因溃疡面与胃酸、胃蛋白酶的消化作用有关而得名，是常见的消化系统疾病。

## 病因
胃酸和胃蛋白酶对黏膜的损伤超过黏膜防御修复能力是根本机制。主要病因包括幽门螺杆菌感染、长期服用阿司匹林等非甾体抗炎药，吸烟、饮酒、精神紧张、不规律进食等也会增加发病风险。十二指肠溃疡以酸分泌增多为主，胃溃疡则多见于胃黏膜屏障受损。

## 主要症状
典型表现为慢性、周期性、节律性的上腹痛。胃溃疡疼痛多在餐后出现，十二指肠溃疡疼痛多在空腹或夜间发生，进食后可缓解。可伴反酸、嗳气、恶心、腹胀等。部分患者可无症状，而以出血、穿孔等并发症为首发表现。

## 处理建议
- 确诊患者应规范治疗，根除幽门螺杆菌，抑酸疗程要足，不可自行随意停药。
- 尽量停用或调整非甾体抗炎药，必要时加用胃黏膜保护剂。
- 规律进餐，细嚼慢咽，避免辛辣、浓茶、咖啡等刺激，戒烟限酒，保持情绪稳定。
- 定期复查，观察溃疡愈合情况，防止复发和并发症。

## 就医提醒
出现呕血、黑便、剧烈上腹痛、大汗、头晕甚至晕厥时，可能提示出血或穿孔，应立即就医。久治不愈或反复发作的溃疡，应警惕恶变可能，及时复查胃镜并活检。

## 检查与诊断
消化性溃疡的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、肝功能、腹部超声、胃镜/肠镜、幽门螺杆菌检测、大便潜血等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似消化性溃疡的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
