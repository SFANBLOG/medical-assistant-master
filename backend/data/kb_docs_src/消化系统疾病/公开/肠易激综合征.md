# 肠易激综合征

肠易激综合征是一种常见的功能性肠病，以腹痛伴排便习惯改变为主要特征，但并无器质性病变，任何年龄均可发病，青年女性相对多见。

## 病因
病因尚未完全明确，目前认为与肠道动力异常、内脏高敏感、肠道菌群失调、脑-肠轴功能紊乱、精神心理因素及感染后肠功能改变等有关。紧张、焦虑、生活不规律、饮食不当常诱发或加重症状。

## 主要症状
反复发作的腹痛或腹部不适，排便后常可缓解，发作与排便次数或粪便性状改变相关。按排便习惯可分为腹泻型、便秘型和混合型：腹泻型粪便稀烂、次数增多；便秘型排便困难、粪质干硬；常伴腹胀、排气增多，症状在劳累或情绪波动时加重。

## 处理建议
- 调整饮食，避免产气食物（如豆类、洋葱、碳酸饮料）、高脂食物和乳制品（乳糖不耐受者），规律进餐。
- 保持规律作息，适度运动，学会管理压力，必要时寻求心理疏导。
- 腹泻型可短期在医生指导下使用调节肠功能的药物，便秘型注意增加膳食纤维和饮水。
- 症状顽固者可在医生指导下尝试低发漫（低FODMAP）饮食。

## 就医提醒
出现便血、体重明显下降、发热、夜间被痛醒、贫血或40岁以上新发症状时，应警惕器质性疾病，及时就医。诊断肠易激综合征需排除炎症性肠病、肿瘤等，建议在专科医生评估后治疗，不要长期自行用药。

## 检查与诊断
肠易激综合征的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、肝功能、腹部超声、胃镜/肠镜、幽门螺杆菌检测、大便潜血等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似肠易激综合征的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
