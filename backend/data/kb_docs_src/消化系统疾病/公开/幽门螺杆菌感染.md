# 幽门螺杆菌感染

幽门螺杆菌是一种定植于胃黏膜的革兰阴性微需氧菌，感染后可引起慢性胃炎、消化性溃疡，并与胃癌、胃黏膜相关淋巴组织淋巴瘤的发生有关，已被世界卫生组织列为Ⅰ类致癌物。

## 病因
幽门螺杆菌主要经口-口、粪-口途径传播，共餐、口对口喂食、进食不洁饮食是常见感染方式。我国感染率较高，儿童期感染多见，家庭内聚集现象明显。感染后是否发病与细菌毒力、宿主免疫及环境因素有关。

## 主要症状
多数感染者没有明显症状，部分可出现上腹胀痛、嗳气、反酸、口臭等非特异表现。感染者患慢性胃炎、消化性溃疡的风险明显升高，部分患者以溃疡出血、缺铁性贫血等为首发表现。

## 处理建议
- 确诊感染者是否根除治疗，应由医生综合评估，符合指征者建议规范根除。
- 根除方案需联合多种药物足疗程使用，必须按时按量服药，不可随意中断，否则易导致耐药。
- 治疗结束后按医嘱停药复查，一般通过呼气试验确认是否根除成功。
- 家庭成员若同患感染，可考虑同时检查处理；注意分餐制、使用公筷、做好手卫生，减少再感染。

## 就医提醒
有消化不良症状、消化性溃疡病史、胃黏膜萎缩或肠化、胃癌家族史等人群，应及时检测幽门螺杆菌。服药期间若出现严重皮疹、明显肝功能异常等不良反应，应及时复诊。根除失败者应间隔一段时间后，在专科指导下更换方案再治疗。
