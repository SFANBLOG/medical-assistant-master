# 脂肪肝

脂肪肝是指肝细胞内脂肪蓄积过多的一种病理状态，按病因可分为酒精性脂肪肝和非酒精性脂肪肝，后者更为常见，已成为我国最常见的慢性肝病之一。

## 病因
长期过量饮酒是酒精性脂肪肝的主要原因；非酒精性脂肪肝多与超重、肥胖、血脂异常、糖尿病、高脂高糖饮食、久坐少动等代谢因素有关。遗传易感性、某些药物及快速减重也会促进脂肪肝发生。

## 主要症状
多数患者早期没有明显症状，常在体检时偶然发现。部分患者可有乏力、右上腹轻度胀满或隐痛、食欲减退等。病情进展至脂肪性肝炎甚至肝硬化时，可出现黄疸、腹水、消化道出血等表现。

## 处理建议
- 控制饮食总量，减少高脂、高糖及油炸食品，增加蔬菜、全谷物和优质蛋白摄入。
- 坚持规律有氧运动，逐步减轻体重，减重速度不宜过快，避免饥饿疗法和极低碳水饮食。
- 严格限酒，酒精性脂肪肝须完全戒酒。
- 积极管理血脂、血糖，遵医嘱用药；不自行滥用保肝药。

## 就医提醒
体检发现脂肪肝后，应进一步评估肝功能、血脂血糖及肝纤维化程度。出现明显乏力、黄疸、腹胀或肝功能异常持续加重时，应及时到消化科或肝病科就诊，必要时行肝脏弹性检查或肝穿刺活检。

## 检查与诊断
脂肪肝的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、肝功能、腹部超声、胃镜/肠镜、幽门螺杆菌检测、大便潜血等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似脂肪肝的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
