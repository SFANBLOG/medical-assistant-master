# 胆囊结石与胆囊炎

胆囊结石是胆囊内形成结石的常见疾病，胆结石阻塞或刺激胆囊可引起胆囊炎。二者关系密切，发病率随年龄增长而升高，女性多于男性。

## 病因
胆囊结石的形成与胆汁成分比例失调、胆固醇过饱和、胆囊排空障碍等因素有关。肥胖、快速减重、高脂饮食、长期素食、妊娠、糖尿病、胆道感染及家族史均增加发病风险。结石堵塞胆囊管或嵌顿后，胆汁淤积、细菌感染即可诱发急性胆囊炎。

## 主要症状
多数胆囊结石无症状，仅在体检时发现。急性胆囊炎典型表现为右上腹或上腹持续性疼痛，可向右肩背部放射，伴恶心、呕吐、发热，进食油腻后加重；Murphy征阳性。部分患者以胆绞痛（阵发性右上腹剧痛）反复发作为表现。

## 处理建议
- 无症状结石一般无需特殊处理，定期随访，注意饮食清淡、规律进餐。
- 有症状的胆囊结石或胆囊炎患者，应控制急性感染后由医生评估是否手术，腹腔镜胆囊切除是常用术式。
- 急性发作期禁食油腻，由医生判断是否需要禁食补液、使用解痉镇痛和抗生素。
- 控制体重但避免快速减重，规律三餐，避免长期禁食和暴饮暴食。

## 就医提醒
出现持续右上腹痛、发热、黄疸或尿色加深时，提示可能合并胆管结石、胆管炎或胰腺炎，应立即就医。反复发作胆绞痛的结石患者应尽早就诊评估手术指征，不宜长期拖延。

## 检查与诊断
胆囊结石与胆囊炎的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、肝功能、腹部超声、胃镜/肠镜、幽门螺杆菌检测、大便潜血等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似胆囊结石与胆囊炎的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
