# 慢性胃炎

慢性胃炎是由多种病因引起的胃黏膜慢性炎症，是最常见的消化系统疾病之一，多见于成人，随年龄增长发病率升高。

## 病因
幽门螺杆菌感染是最主要的病因，其次包括长期服用阿司匹林、布洛芬等非甾体抗炎药，长期饮酒、吸烟，进食过于辛辣、生冷等刺激性食物，以及胆汁反流、精神压力大等。多种因素常共同作用，导致胃黏膜反复损伤与修复。

## 主要症状
多数患者无明显症状，部分患者可有上腹隐痛、饱胀不适、嗳气、反酸、食欲减退、恶心等非特异性表现。症状缺乏典型性，与胃黏膜的炎症程度不一定平行。少数伴糜烂者可能出现黑便或少量呕血。

## 处理建议
- 明确幽门螺杆菌感染者，应在医生指导下规范根除治疗。
- 规律饮食，少食多餐，避免过饥过饱，戒烟限酒，减少辛辣刺激食物。
- 若长期服用伤胃药物，应咨询医生是否调整或加用胃黏膜保护剂。
- 症状明显者可短期使用抑酸药、胃黏膜保护剂缓解不适，用药前咨询医生。

## 就医提醒
出现反复上腹不适、食欲明显下降、进行性消瘦、黑便、贫血或呕血时，应及时就医。年龄较大者及有胃癌家族史者，应遵医嘱定期复查胃镜，必要时进行胃黏膜活检病理检查。

## 检查与诊断
慢性胃炎的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、肝功能、腹部超声、胃镜/肠镜、幽门螺杆菌检测、大便潜血等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似慢性胃炎的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
