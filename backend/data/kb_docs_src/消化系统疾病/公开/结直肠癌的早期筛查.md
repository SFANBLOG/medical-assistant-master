# 结直肠癌的早期筛查

结直肠癌是常见的消化道恶性肿瘤，多数由结直肠腺瘤性息肉经多年演变而来，早期发现和切除癌前病变可显著降低发病率和死亡率，是目前最适宜筛查的癌症之一。

## 病因
发病与遗传、年龄、饮食和生活方式等因素有关。高脂高蛋白、低膳食纤维饮食，红肉及加工肉摄入过多，肥胖、缺乏运动、吸烟饮酒等均增加风险；家族性腺瘤性息肉病、林奇综合征等遗传因素和炎症性肠病也属于高危因素。

## 主要症状
早期常无明显症状。随病变进展可出现排便习惯改变（腹泻、便秘交替）、便血或黑便、粪便变细、里急后重、腹痛腹胀、贫血、乏力、消瘦等。出现上述表现时往往已非早期，凸显定期筛查的重要性。

## 处理建议
- 一般风险人群建议从45岁起接受筛查，首选粪便隐血试验或粪便免疫化学检测，阳性者再行结肠镜检查。
- 结肠镜检查是发现和切除息肉的金标准，建议高风险人群每5-10年复查一次，具体间隔遵医嘱。
- 有结直肠癌或腺瘤家族史、炎症性肠病者应更早、更频繁筛查。
- 日常保持均衡饮食，增加膳食纤维，减少红肉加工肉，规律运动、控制体重、戒烟限酒。

## 就医提醒
出现便血、排便习惯持续改变、不明原因贫血或消瘦时，应及时就医，不要因忌讳而拖延。既往发现过腺瘤性息肉者，务必按医嘱定期复查，切勿因无症状而中断随访。
