# 便秘的防治

便秘是一种常见症状，指排便次数减少、粪便干硬、排出费力或排便不尽感。病程超过半年为慢性便秘，老年人、女性及长期卧床者多见。

## 病因
可分器质性和功能性两大类。功能性便秘多与膳食纤维摄入不足、饮水少、缺乏运动、久坐、刻意憋便、排便习惯不良有关，也与精神紧张、生活不规律相关；部分与胃肠动力减弱、盆底功能异常有关。器质性便秘见于肠梗阻、肿瘤、甲状腺功能减退、糖尿病及某些药物影响等。

## 主要症状
排便次数每周少于3次，粪便干硬呈羊粪状，排便费力、需用力屏气，可伴肛门坠胀、腹胀、食欲下降。长期用力排便可诱发痔疮、肛裂，出现便后滴血或肛门疼痛。

## 处理建议
- 增加膳食纤维摄入，多吃蔬菜、水果、粗粮，每日充足饮水。
- 规律运动，特别是腹部锻炼和适度有氧运动，促进肠蠕动。
- 养成定时排便的习惯，有便意及时排便，不长时间如厕。
- 适当腹部按摩，避免长期依赖刺激性泻药；确需用药时应在医生指导下选用温和的通便药物。

## 就医提醒
便秘同时出现便血、体重下降、贫血、腹痛进行性加重，或40岁以上新发便秘、排便习惯明显改变者，应及时就医排除肠道肿瘤等疾病。长期依赖泻药排便的人，应到消化科规范诊治。

## 检查与诊断
便秘的防治的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、肝功能、腹部超声、胃镜/肠镜、幽门螺杆菌检测、大便潜血等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似便秘的防治的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
