# 胃食管反流病

胃食管反流病是指胃内容物反流入食管、口腔或气道引起不适症状和并发症的疾病，典型表现为反酸、烧心，是常见的慢性消化系统疾病，发病率随年龄增长而升高。

## 病因
食管下括约肌功能减弱、一过性松弛增多是主要机制，导致胃酸、胃蛋白酶反流损伤食管黏膜。肥胖、妊娠、暴饮暴食、高脂饮食、吸烟饮酒、咖啡浓茶、睡前进食、长期服用某些药物以及食管裂孔疝等均易诱发或加重反流。

## 主要症状
典型症状为烧心（胸骨后烧灼感）和反酸，多在餐后、平卧或弯腰时加重。还可出现非典型症状，如胸痛、咽部异物感、慢性咳嗽、声音嘶哑、反流性哮喘等，部分患者以咽喉症状为主，易误诊。

## 处理建议
- 调整生活方式是基础：睡前2-3小时不进食，睡时抬高床头，控制体重，避免高脂、甜食、咖啡、浓茶、酒精及过饱饮食。
- 症状明显者可在医生指导下使用抑酸药物，初始疗程一般较长，不可随意停药复发。
- 避免穿过紧衣物、弯腰搬重物，减轻腹压。
- 长期治疗者应遵医嘱定期评估，调整维持方案。

## 就医提醒
胸骨后疼痛明显者应警惕心绞痛等心脏疾病，及时就医鉴别。出现吞咽困难、吞咽疼痛、呕血、黑便、消瘦等警报症状时，应尽快就诊并考虑胃镜检查。长期反流未规范治疗者，应警惕食管炎、食管狭窄及巴雷特食管等并发症。

胃食管反流病的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、肝功能、腹部超声、胃镜/肠镜、幽门螺杆菌检测、大便潜血等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
