# 急性胃肠炎

急性胃肠炎是胃肠黏膜的急性炎症，多由感染引起，夏秋季节高发，各年龄段均可发病，儿童和老年人症状常较重。

## 病因
多因进食被病毒、细菌或其毒素污染的食物、不洁饮水所致，常见病原体包括诺如病毒、轮状病毒、沙门菌、致泻性大肠埃希菌等。进食生冷、不洁、变质食物，餐具不卫生，手卫生不佳是常见诱因。少数与药物、化学物质刺激有关。

## 主要症状
起病较急，表现为恶心、呕吐、腹痛、腹泻，腹泻可为水样便或稀便，可伴发热、乏力。频繁呕吐或腹泻严重者，可致脱水、电解质紊乱，出现口干、尿少、眼窝凹陷、精神萎靡等表现。

## 处理建议
- 多数为自限性，注意休息，暂停刺激性食物，给予清淡易消化饮食，如粥、面条。
- 及时补充水分和电解质，可少量多次饮用口服补液盐，这是防治脱水的关键。
- 腹泻明显时避免盲目使用止泻药，尤其是伴发热时；一般不建议自行使用抗生素。
- 注意个人卫生，勤洗手，处理粪便后及时消毒，避免传染家人。

## 就医提醒
出现持续高热、剧烈腹痛、血便、频繁呕吐不能进食进水、明显口渴尿少等脱水征象，或老人、婴幼儿、孕妇及有基础疾病者，应尽快就医。出现意识模糊、抽搐等表现时需紧急救治。

## 检查与诊断
急性胃肠炎的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、肝功能、腹部超声、胃镜/肠镜、幽门螺杆菌检测、大便潜血等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似急性胃肠炎的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
