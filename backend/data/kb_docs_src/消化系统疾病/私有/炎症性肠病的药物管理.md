# 炎症性肠病的药物管理

炎症性肠病包括溃疡性结肠炎和克罗恩病，为慢性复发性肠道炎症性疾病。药物治疗目标是诱导缓解、维持缓解、减少复发、改善生活质量，并避免并发症。

## 临床要点
- 溃疡性结肠炎多以黏膜炎症为主，局限直肠者可用局部制剂，广泛病变需系统用药；克罗恩病可累及全消化道，常伴瘘管、狭窄。
- 常用药物包括氨基水杨酸类、糖皮质激素、免疫抑制剂（硫唑嘌呤、甲氨蝶呤）、生物制剂（抗肿瘤坏死因子制剂等）及小分子药物。
- 病情评估应结合症状、内镜、影像及实验室炎症指标，确定疾病活动度后分层治疗。

## 处理与观察重点
- 诱导期药物（如激素）不宜长期维持，需按方案递减，避免依赖；及时评估是否升级为免疫抑制剂或生物制剂。
- 用药期间定期监测血常规、肝肾功能，硫唑嘌呤应检测硫嘌呤甲基转移酶活性或血药浓度，防范骨髓抑制。
- 生物制剂注意输注反应、感染风险（结核、乙肝病毒激活），治疗前需完成相应筛查。
- 关注营养状况，必要时肠内营养支持；监测骨密度，预防激素相关骨质疏松。

## 注意事项
- 不随意停药或减量，维持治疗要长期坚持，定期专科随访。
- 出现发热、腹痛加重、便血增多、梗阻或瘘管征象时，及时复查并警惕手术干预指征。
- 合并妊娠者应在专科与产科共同管理下调整用药。

炎症性肠病的药物管理的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、肝功能、腹部超声、胃镜/肠镜、幽门螺杆菌检测、大便潜血等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似炎症性肠病的药物管理的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
