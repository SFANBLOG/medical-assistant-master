# 消化内镜诊疗围手术期护理

消化内镜诊疗包括胃镜、结肠镜、内镜黏膜切除术、内镜黏膜下剥离术、内镜逆行胰胆管造影等，规范的围手术期护理对减少并发症、保障安全至关重要。

## 临床要点
- 术前评估：核对适应证与禁忌证，评估心肺功能、凝血状态、抗凝抗血小板药物使用情况，了解过敏史。
- 术前准备：胃镜需空腹，结肠镜按方案进行肠道准备，评估肠道清洁度；内镜逆行胰胆管造影等复杂操作需知情同意并备好急救条件。
- 镇静与监护：静脉麻醉或镇静者全程监测血压、心率、血氧饱和度，注意呼吸抑制和反流误吸风险。

## 处理与观察重点
- 术后禁食时间依操作类型而定：单纯检查者咽喉麻醉消退后进食；切除或治疗术后按医嘱禁食、逐步过渡流质饮食。
- 观察有无腹痛、腹胀、呕血、黑便、发热等出血穿孔征兆；内镜逆行胰胆管造影术后重点观察有无腹痛、黄疸加重和淀粉酶升高等胰腺炎表现。
- 创面切除术后嘱患者避免剧烈活动，观察排粪颜色，出现血便或黑便及时报告。
- 做好出院指导：告知复诊时间、饮食注意事项及紧急就诊指征。

## 注意事项
- 恢复抗凝抗血小板药物需与相关专科协调，权衡出血与血栓风险。
- 老年、心肺疾病及出血风险高者加强监护，操作后延长观察时间。
- 严格无菌操作，预防内镜相关感染，按规范消毒复用器械。
