# 肝癌高危人群筛查

肝细胞癌是我国常见恶性肿瘤，多数发生于慢性肝病基础上，早期多无症状。对高危人群开展规律筛查，有助于早诊早治、改善预后。

## 临床要点
- 高危人群主要包括：慢性乙型或丙型肝炎感染者及携带者、各种病因所致肝硬化、长期酗酒者、非酒精性脂肪性肝炎、家族中有肝癌患者，以及因其他原因导致的肝纤维化者。
- 主要筛查手段为血清甲胎蛋白检测联合腹部超声；甲胎蛋白阴性或超声可疑者，进一步行增强CT、增强磁共振或超声造影明确。
- 筛查目标不仅是检出肿瘤，还包括监测肝硬化进展与食管胃底静脉曲张等门静脉高压表现。

## 处理与观察重点
- 高危人群建议每6个月进行一次筛查，肝硬化者随访更应规范，不因一时结果正常而中断。
- 对超声发现结节、甲胎蛋白进行性升高或影像特征不典型者，缩短随访间隔或升级影像学检查。
- 确诊者应结合肿瘤分期、肝功能与全身状况，由多学科团队制定个体化方案，包括手术切除、消融、介入、靶向及免疫治疗等。

## 注意事项
- 筛查结果的解释需结合肝病基础，甲胎蛋白轻度升高不等于确诊，正常也不能完全排除。
- 强化病因管理：抗病毒治疗、戒酒、代谢干预是降低肝癌风险的根本措施。
- 对筛查依从性差的高危患者做好健康教育，落实长期随访制度。

## 检查与诊断
肝癌高危人群筛查的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、肝功能、腹部超声、胃镜/肠镜、幽门螺杆菌检测、大便潜血等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似肝癌高危人群筛查的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
