# 肝硬化并发症的防治

肝硬化是各种慢性肝病进展的终末阶段，其预后主要取决于并发症的发生与控制。常见并发症包括腹水、食管胃底静脉曲张破裂出血、肝性脑病、自发性细菌性腹膜炎、肝肾综合征及肝细胞癌。

## 临床要点
- 按病因管理：乙肝、丙肝患者积极抗病毒治疗，酒精性肝病严格戒酒，非酒精性脂肪性肝病控制代谢因素。
- 定期评估肝功能分级、肝纤维化进展及门静脉高压程度；常规监测甲胎蛋白和影像学以筛查肝癌。
- 认识并发症预警：腹胀、体重骤增提示腹水；行为异常、性格改变、扑翼样震颤提示肝性脑病。

## 处理与观察重点
- 腹水：限盐利尿、合理使用白蛋白，大量腹水评估放腹水联合白蛋白；预防自发性细菌性腹膜炎。
- 静脉曲张出血：一级预防与二级预防结合，套扎及非选择性β受体阻滞剂规范应用。
- 肝性脑病：寻找并纠正诱因（感染、消化道出血、便秘、电解质紊乱、镇静药），乳果糖保持排便通畅，限制蛋白应在营养师指导下个体化。
- 肝肾综合征：识别诱因，规范使用特利加压素类血管活性药物联合白蛋白，评估肝移植时机。

## 注意事项
- 避免滥用有损肝脏药物和保健品，慎用非甾体抗炎药、氨基糖苷类及造影剂。
- 有腹水者注意腹围、体重、尿量记录；发热、腹痛时及时检查排除自发性细菌性腹膜炎。
- 终末期患者应尽早评估肝移植，并进行多学科综合管理。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
肝硬化并发症的防治的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、肝功能、腹部超声、胃镜/肠镜、幽门螺杆菌检测、大便潜血等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似肝硬化并发症的防治的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
