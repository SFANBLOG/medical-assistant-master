# 肠梗阻的鉴别与处理

肠梗阻指肠内容物通过障碍，是常见急腹症。可分为机械性、动力性（麻痹性、假性）和血运性肠梗阻，处理关键在于鉴别病因、判断绞窄与否、决定保守或手术治疗。

## 临床要点
- 典型表现为腹痛、呕吐、腹胀、停止排气排便，但早期或不全梗阻排气排便未必完全停止。
- 机械性梗阻常见病因：成人多为术后粘连、肿瘤、疝嵌顿；儿童以肠套叠、肠扭转多见。腹股沟区查体不可遗漏。
- 绞窄性肠梗阻警示：持续剧烈腹痛、腹膜炎体征、发热、心率增快、血性腹水或影像提示肠壁缺血坏死、气腹等。

## 处理与观察重点
- 胃肠减压、禁食水、纠正水电解质紊乱和酸碱失衡、抗感染，是保守治疗的基础。
- 明确机械性梗阻者及时行立位腹部平片、CT等检查，判断梗阻部位、程度及有无缺血。
- 动态观察腹痛、腹胀、肠鸣音、体温及腹部体征变化，反复评估是否发生绞窄。
- 保守治疗无效、怀疑绞窄、肿瘤或嵌顿疝所致者，及时手术或介入干预，避免延误。

## 注意事项
- 老年人新发肠梗阻应警惕肿瘤，即使症状较轻也要完成肠镜或影像评估。
- 麻痹性肠梗阻应寻找并处理原发病，如感染、电解质紊乱、药物因素。
- 术后粘连性肠梗阻保守治疗期间需密切监测，短期不缓解者及时复查。

## 检查与诊断
肠梗阻的鉴别与处理的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、肝功能、腹部超声、胃镜/肠镜、幽门螺杆菌检测、大便潜血等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似肠梗阻的鉴别与处理的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
