# 幽门螺杆菌根除方案

幽门螺杆菌感染与慢性胃炎、消化性溃疡、胃黏膜萎缩及胃癌相关，规范根除可改善预后。选择方案时应结合当地耐药率、患者用药史和药物过敏史个体化处理。

## 临床要点
- 推荐含铋剂四联方案：质子泵抑制剂、铋剂联合两种抗菌药物，疗程10-14天，覆盖一线根除。
- 常用抗菌药物包括阿莫西林、克拉霉素、甲硝唑、四环素、呋喃唑酮、左氧氟沙星等，应避免选用耐药率高的单药组合。
- 青霉素过敏者选用含四环素或甲硝唑等替代组合；曾用大环内酯类者避免重复选用克拉霉素。
- 治疗前应告知患者可能出现口苦、黑便（铋剂）、腹部不适等反应，提高依从性。

## 处理与观察重点
- 严格按时按量服药，强调不可漏服或提前停药，否则易致根除失败和继发耐药。
- 服药期间及停药后注意监测过敏反应、腹泻、肝肾功能等不良反应。
- 根除结束后至少停药质子泵抑制剂和抗菌药物4周以上，再行尿素呼气试验确认根除效果。
- 首次根除失败者间隔3-6个月，依据药敏试验或换用不同抗菌药物组合再治疗。

## 注意事项
- 儿童、孕妇及哺乳期妇女根除治疗需严格把握指征，个体化决策。
- 家庭内共餐者建议分餐或使用公筷，减少交叉感染；是否家庭成员同治应结合实际情况沟通。
- 反复治疗失败者建议评估药敏，避免随意加量或延长疗程。
