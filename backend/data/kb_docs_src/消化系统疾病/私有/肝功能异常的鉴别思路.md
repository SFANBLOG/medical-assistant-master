# 肝功能异常的鉴别思路

肝功能异常指血清转氨酶、胆红素、碱性磷酸酶、白蛋白及凝血功能等指标异常，临床十分常见。鉴别的核心是区分肝细胞损伤、胆汁淤积与混合性病变，并寻找可治疗病因。

## 临床要点
- 先判断损伤类型：转氨酶显著升高为主提示肝细胞损伤；碱性磷酸酶、谷氨酰转肽酶升高为主提示胆汁淤积；结合胆红素与肝脏合成功能评估病情严重程度。
- 常见病因包括病毒性肝炎、酒精性肝病、非酒精性脂肪性肝病、药物性肝损伤、自身免疫性肝病、胆汁淤积性疾病及遗传代谢病。
- 详细询问用药史、饮酒史、输血史、旅行史及家族史，查病毒标志物、自身抗体、铜蓝蛋白、铁蛋白等明确病因。

## 处理与观察重点
- 排查急性重型倾向：黄疸进行性加深、凝血酶原时间延长、肝性脑病表现提示肝衰竭，需紧急评估。
- 药物性肝损伤应及时停用可疑药物并按规范评估；自身免疫性肝病评估糖皮质激素及免疫抑制剂使用指征。
- 观察病情演变：转氨酶下降伴胆红素升高需警惕胆酶分离，评估预后与转归。
- 定期随访肝功能和影像学，评估肝纤维化程度，必要时行肝脏穿刺活检明确诊断。

## 注意事项
- 避免盲目使用保肝降酶药物而延误病因诊断，病因治疗是根本。
- 慎用具有潜在肝毒性的药物和保健品，尤其是肝功能已受损者。
- 转诊不明确者应提交多学科讨论，警惕隐匿的肝硬化或肝癌基础。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）
