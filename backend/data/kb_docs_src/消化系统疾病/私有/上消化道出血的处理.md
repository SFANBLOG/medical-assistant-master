# 上消化道出血的处理

上消化道出血指屈氏韧带以上消化道（食管、胃、十二指肠）的出血，是消化科常见急症。处理关键在于快速评估血流动力学、明确出血部位与病因、及时止血。

## 临床要点
- 先评估生命体征和失血量：血压下降、心率增快、少尿提示失血量大，需优先复苏，不宜先做无谓检查。
- 常见病因依次为消化性溃疡、食管胃底静脉曲张破裂、急性胃黏膜病变、肿瘤及贲门黏膜撕裂等；病史和体格检查有助于初步定位。
- 查血常规、凝血功能、肝肾功能、血型，必要时交叉配血；肝硬化者警惕静脉曲张破裂出血。

## 处理与观察重点
- 建立静脉通道，补液扩容，必要时输注红细胞，维持重要脏器灌注；纠正凝血障碍。
- 尽早给予质子泵抑制剂；疑似静脉曲张破裂者按规范使用降门脉压药物和预防性抗生素。
- 循环稳定后尽快行急诊内镜检查，明确出血灶并实施内镜下止血，如注射、电凝、止血夹或套扎等。
- 密切监测血压、心率、尿量、血红蛋白变化及有无再出血征象（反复呕血、黑便、头晕冷汗）。

## 注意事项
- 内镜止血后仍有活动性出血或内镜失败者，及时评估介入或手术干预。
- 高龄、合并心肺疾病者补液输血需监测心功能，避免输液过快导致肺水肿。
- 停用或调整抗凝抗血小板药物应结合出血与血栓风险权衡，并由专科共同决策。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似上消化道出血的处理的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
