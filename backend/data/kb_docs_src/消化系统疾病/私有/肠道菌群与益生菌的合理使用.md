# 肠道菌群与益生菌的合理使用

肠道菌群参与消化、免疫、代谢及神经调节，菌群失衡与多种疾病相关。益生菌作为改善菌群的干预手段应用广泛，但应严格把握适应证，避免滥用。

## 临床要点
- 益生菌指给予足量时对宿主有益的活性微生物，常见菌株包括乳酸杆菌、双歧杆菌、布拉氏酵母菌等；不同菌株作用具有特异性。
- 证据较为充分的适应证包括抗生素相关性腹泻的预防、感染性腹泻的辅助治疗、肠易激综合征部分症状改善及炎症性肠病维持缓解的辅助等。
- 益生菌不能替代病因治疗，应用前应评估获益与个体情况，注意制剂质量与活菌数量。

## 处理与观察重点
- 选择有循证依据的菌株和合适剂量，与抗生素合用时注意间隔服用，避免活性受损。
- 注意保存条件，观察疗效时限，症状无改善时应重新评估诊断而非无限期延长使用。
- 免疫功能低下、重症、中心静脉置管及肠道黏膜屏障严重受损患者慎用，警惕菌血症、真菌血症等罕见感染风险。
- 关注可能出现的腹胀、排气增多等轻微不良反应，一般可自行缓解。

## 注意事项
- 不可用益生菌替代规范抗感染、抑酸或抗炎治疗，明确目标后再选用。
- 儿童、孕妇等特殊人群使用前咨询专科意见。
- 对粪菌移植等更深入干预应严格限定于规范评估的难治性适应证，并在具备条件的中心开展。

## 预防与日常保健
规律三餐、细嚼慢咽、避免过饱与刺激性食物，戒烟限酒，注意饮食卫生，保持作息规律，避免长期精神紧张。

## 就医指引
如出现疑似肠道菌群与益生菌的合理使用的相关症状，建议及时到消化内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
