# 泌尿系结石成分分析与预防

结石成分分析是复发预防的关键依据，不同成分结石的预防策略差异明显。

## 临床要点
- 常见成分：草酸钙结石最多见，其次为磷酸钙、尿酸、磷酸铵镁（感染性结石）、胱氨酸结石。
- 通过红外光谱或化学法分析结石成分，并结合代谢评估（24 小时尿钙、尿酸、枸橼酸、尿量等）查找病因。

## 处理与观察重点
- 草酸钙结石：充分饮水、限制钠盐和动物蛋白、避免高草酸食物，必要时补充枸橼酸盐。
- 尿酸结石：碱化尿液、限制嘌呤摄入，必要时使用降尿酸药物。
- 感染性结石：控制感染、尽早完整取石并加强随访。
- 胱氨酸结石：大量饮水并碱化尿液，必要时使用青霉胺等药物。

## 注意事项
预防措施需根据结石成分与代谢结果个体化制定，长期随访并定期复查影像与尿液指标，评估复发风险。合并高钙血症等代谢异常时应进一步排查甲状旁腺功能等相关病因。
