# 肾穿刺活检适应证

肾穿刺活检是明确肾实质疾病病理类型、指导治疗和判断预后的重要手段，需严格把握适应证与禁忌证。

## 临床要点
- 适应证：不明原因的肾病综合征、持续性蛋白尿、不明原因血尿伴肾功能异常、急进性肾小球肾炎、系统性疾病（如狼疮）累及肾脏、移植肾的鉴别诊断及治疗方案调整。
- 相对禁忌证：明显出血倾向、严重未控制的高血压、孤立肾或肾萎缩、活动性肾感染、重度肾积水、妊娠等。

## 处理与观察重点
- 术前评估凝血功能、血小板计数、血压和肾功能，停用抗凝及抗血小板药物。
- 超声引导下穿刺，术后严格卧床休息并密切观察生命体征、尿色和腰痛。
- 警惕术后并发症：肉眼血尿、肾周血肿、动静脉瘘等，多数可保守处理。

## 注意事项
标本需送光镜、免疫荧光和电镜检查，以提高诊断价值。穿刺结果须结合临床与实验室资料综合解读，不应机械照搬病理结论。

## 检查与诊断
肾穿刺活检适应证的确诊需要结合临床表现与辅助检查。常用检查包括：尿常规、尿蛋白定量、肾功能、泌尿系超声、尿培养、肾穿刺活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
多饮水、不憋尿、注意个人卫生，避免滥用药物（尤其止痛药、抗生素），定期体检查尿常规与肾功能。

## 就医指引
如出现疑似肾穿刺活检适应证的相关症状，建议及时到肾内科、泌尿外科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对肾穿刺活检适应证相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
