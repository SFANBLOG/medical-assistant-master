# 腹膜透析护理要点

腹膜透析利用腹膜作为半透膜进行溶质与水分的交换，以居家治疗为主，对规范操作和无菌观念要求较高。

## 临床要点
- 确认导管出口处无感染、无渗漏，导管固定良好，隧道无压痛。
- 按处方执行透析液交换，记录出入量、超滤量和体重。

## 处理与观察重点
- 严格无菌操作，换液前后洗手、戴口罩，检查透析液是否澄清、有无絮状物。
- 观察引流液性状、超滤量变化及腹膜炎早期表现（腹痛、引流液浑浊、发热）。
- 定期评估透析充分性、残余肾功能、营养状态与腹透液蛋白质丢失情况。

## 注意事项
出口处及隧道感染是腹膜炎的重要诱因，需每日护理并观察有无红肿、分泌物。出现腹痛伴引流液浑浊时，应尽快留取标本送检并联系透析中心，切勿自行处理。定期返院随访调整处方。

腹膜透析护理要点的确诊需要结合临床表现与辅助检查。常用检查包括：尿常规、尿蛋白定量、肾功能、泌尿系超声、尿培养、肾穿刺活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
