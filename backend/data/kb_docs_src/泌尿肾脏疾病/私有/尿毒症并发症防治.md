# 尿毒症并发症防治

尿毒症（终末期肾病）常合并多系统并发症，积极防治可显著改善预后与生活质量。

## 临床要点
- 常见并发症：肾性贫血、钙磷代谢紊乱与继发性甲状旁腺功能亢进、代谢性酸中毒、高血压与心血管疾病、营养不良、尿毒症性脑病、出血倾向。
- 高钾血症属急症，可诱发心律失常甚至猝死。

## 处理与观察重点
- 肾性贫血：补充促红细胞生成素和铁剂，监测血红蛋白及相关铁指标。
- 钙磷代谢：限制磷摄入、使用磷结合剂，必要时调整活性维生素 D 及钙剂，监测血钙、血磷及甲状旁腺激素。
- 代谢性酸中毒：补充碱剂，维持碳酸氢盐水平正常。
- 高钾血症：紧急处理包括静脉钙剂稳定心肌、促进钾向细胞内转移的药物等，并及时启动透析。
- 控制血压、加强营养支持，必要时行肾脏替代治疗。

## 注意事项
并发症防治需在透析或综合管理框架下系统推进，定期监测相关指标并个体化调整方案，防止矫枉过正（如过度补钙致高钙血症、过度补铁致铁过载）。

## 检查与诊断
尿毒症并发症防治的确诊需要结合临床表现与辅助检查。常用检查包括：尿常规、尿蛋白定量、肾功能、泌尿系超声、尿培养、肾穿刺活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
多饮水、不憋尿、注意个人卫生，避免滥用药物（尤其止痛药、抗生素），定期体检查尿常规与肾功能。

## 就医指引
如出现疑似尿毒症并发症防治的相关症状，建议及时到肾内科、泌尿外科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
