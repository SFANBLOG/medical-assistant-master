# 急性肾损伤的处理

急性肾损伤（AKI）是肾功能在短时间内急剧下降的临床综合征，按 KDIGO 标准进行分期，处理重在纠正诱因和防治并发症。

## 临床要点
- 分型判断：肾前性（血容量不足、心排血量下降）、肾性（急性肾小管坏死、肾小球疾病、间质性肾炎、血管性）、肾后性（尿路梗阻）。
- 快速评估容量状态，区分低血容量与容量过负荷。

## 处理与观察重点
- 纠正诱因：补液扩容或利尿减容、停用肾毒性药物、解除尿路梗阻、控制感染与脓毒症。
- 监测每日尿量、血肌酐、血钾、血酸碱度，警惕高钾血症、代谢性酸中毒和肺水肿。
- 严格液体管理，维持出入量平衡，保证足够热量与营养支持。
- 达到透析指征（严重高钾、严重酸中毒、容量过负荷、尿毒症症状）时及时行肾脏替代治疗。

## 注意事项
避免非必要的造影检查等肾毒性操作，如必须使用需充分评估并预防性处理。利尿剂仅用于容量过负荷，不应常规用于少尿期的盲目冲刷。恢复期需随访肾功能是否完全恢复。

## 检查与诊断
急性肾损伤的处理的确诊需要结合临床表现与辅助检查。常用检查包括：尿常规、尿蛋白定量、肾功能、泌尿系超声、尿培养、肾穿刺活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
多饮水、不憋尿、注意个人卫生，避免滥用药物（尤其止痛药、抗生素），定期体检查尿常规与肾功能。

## 就医指引
如出现疑似急性肾损伤的处理的相关症状，建议及时到肾内科、泌尿外科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
