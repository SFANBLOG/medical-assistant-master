# 前列腺特异性抗原（PSA）解读

PSA 是前列腺癌筛查与随访的重要血清标志物，但特异性有限，需结合多项参数和临床信息综合判断。

## 临床要点
- 血清总 PSA 正常参考值一般为 4 ng/mL 以下，但不同年龄有对应参考范围，需注意实验室差异。
- 结合游离 PSA 比值、PSA 密度、PSA 速率等参数可提高特异性；前列腺炎、尿潴留、导尿、射精及直肠指诊均可致 PSA 一过性升高。

## 处理与观察重点
- PSA 升高时需复查确认，综合评估症状、直肠指诊、家族史，并结合年龄与患者意愿决定是否进一步影像学检查或穿刺活检。
- 前列腺癌治疗后需定期监测 PSA，判断疗效与是否生化复发。
- 使用 5α-还原酶抑制剂可使 PSA 下降约一半，解读时应按校正系数调整。

## 注意事项
避免在急性前列腺炎或导尿后立即采血。PSA 并非恶性肿瘤的绝对诊断指标，单次升高不必过度恐慌，应系统性评估。

## 预防与日常保健

## 就医指引

## 日常管理建议
