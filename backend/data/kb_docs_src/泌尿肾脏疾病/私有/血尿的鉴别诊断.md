# 血尿的鉴别诊断

血尿按来源可分为肾小球性血尿和非肾小球性血尿，是泌尿系统及全身疾病的重要信号，鉴别思路应系统有序。

## 临床要点
- 尿沉渣镜检红细胞形态：变形红细胞为主提示肾小球源性；均一红细胞提示泌尿系统结石、肿瘤、感染等。
- 肉眼血尿颜色：鲜红伴血块多提示下尿路出血；洗肉水样、无血块提示上尿路或肾小球病变。
- 结合蛋白尿、管型、水肿、高血压判断是否合并肾实质疾病。
- 追问药物（抗凝药、环磷酰胺等）、运动、外伤及家族史。

## 处理与观察重点
- 分步检查：尿常规加尿红细胞形态、尿蛋白定量、泌尿系超声、尿细胞学，必要时行 CT 尿路成像或膀胱镜。
- 反复或持续血尿即使初查阴性也需密切随访；年龄大、吸烟者需警惕泌尿系肿瘤。
- 肾小球源性血尿需评估肾功能并考虑肾内科进一步诊治。

## 注意事项
勿因血尿间歇出现而放松警惕；抗凝药所致血尿需权衡出血与血栓风险，由专科调整。血尿伴发热、腰痛者在排除感染与结石后仍需随访复查。

## 检查与诊断
血尿的鉴别诊断的确诊需要结合临床表现与辅助检查。常用检查包括：尿常规、尿蛋白定量、肾功能、泌尿系超声、尿培养、肾穿刺活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
多饮水、不憋尿、注意个人卫生，避免滥用药物（尤其止痛药、抗生素），定期体检查尿常规与肾功能。

## 就医指引
如出现疑似血尿的鉴别诊断的相关症状，建议及时到肾内科、泌尿外科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
