# 肾病综合征的激素治疗

糖皮质激素是原发性肾病综合征的基础治疗，需遵循足量、缓慢减量、长期维持的原则，并根据病理类型个体化选择。

## 临床要点
- 用药前明确适应证，并排除活动性感染、严重高血压、血糖异常等禁忌情况。
- 常用泼尼松等中效糖皮质激素，起始足量、足疗程后缓慢减量，防止复发。
- 微小病变型肾病对激素多敏感；膜性肾病、局灶节段性肾小球硬化等常需延长疗程或联合免疫抑制剂。

## 处理与观察重点
- 监测蛋白尿、血浆白蛋白、血脂及肾功能变化，评估疗效。
- 密切观察激素不良反应：血糖升高、血压升高、感染、骨质疏松、消化道症状、精神异常等。
- 注意防治感染、血栓栓塞等并发症，必要时预防性抗凝。

## 注意事项
减量或停药必须在医生指导下进行，切忌自行快速减药或停药。激素依赖或抵抗者需重新评估病理类型并调整免疫抑制方案。

肾病综合征的激素治疗的确诊需要结合临床表现与辅助检查。常用检查包括：尿常规、尿蛋白定量、肾功能、泌尿系超声、尿培养、肾穿刺活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
多饮水、不憋尿、注意个人卫生，避免滥用药物（尤其止痛药、抗生素），定期体检查尿常规与肾功能。

## 就医指引
如出现疑似肾病综合征的激素治疗的相关症状，建议及时到肾内科、泌尿外科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对肾病综合征的激素治疗相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
