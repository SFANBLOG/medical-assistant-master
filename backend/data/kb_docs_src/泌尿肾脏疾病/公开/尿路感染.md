# 尿路感染

尿路感染是病原体（主要是细菌）侵入泌尿系统引起的炎症，按部位分为下尿路感染（膀胱炎、尿道炎）和上尿路感染（肾盂肾炎），女性发病率高于男性。

## 病因
以大肠埃希菌最常见。女性尿道短而直的解剖结构、性活动、妊娠、尿路梗阻、留置导尿管、糖尿病及免疫力低下等均为易感因素。

## 主要症状
- 下尿路感染：尿频、尿急、尿痛，排尿不尽感，耻骨上不适，部分可见血尿。
- 上尿路感染：在上述基础上出现腰痛、发热、寒战、恶心呕吐。

## 处理建议
在医生指导下规范使用抗生素并足疗程完成治疗，切忌自行停药。多饮水、勤排尿，注意会阴部清洁。反复发作者需排查尿路结构异常、结石等诱因。

## 就医提醒
出现高热寒战、腰痛、意识改变，或孕妇、儿童、老年人患尿路感染时，应尽早就医。抗菌药物需遵医嘱使用，避免滥用。

## 检查与诊断
尿路感染的确诊需要结合临床表现与辅助检查。常用检查包括：尿常规、尿蛋白定量、肾功能、泌尿系超声、尿培养、肾穿刺活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
多饮水、不憋尿、注意个人卫生，避免滥用药物（尤其止痛药、抗生素），定期体检查尿常规与肾功能。

## 就医指引
如出现疑似尿路感染的相关症状，建议及时到肾内科、泌尿外科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
