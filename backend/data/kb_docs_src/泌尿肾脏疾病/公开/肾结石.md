# 肾结石

肾结石是尿液中的矿物质和盐类在肾脏内结晶、聚集形成的固体块状物，常见类型包括草酸钙结石、磷酸钙结石、尿酸结石和胱氨酸结石等。

## 病因
代谢异常（如高钙尿、高尿酸尿）、饮水不足、长期高盐高蛋白饮食、尿路梗阻或反复感染等均可促进结石形成。高温环境出汗多、久坐不动及某些药物也会增加患病风险。

## 主要症状
- 腰部或腹部剧烈绞痛，可向会阴部放射。
- 肉眼血尿或镜下血尿。
- 恶心、呕吐、尿频、尿急。
- 合并感染时可出现发热、寒战。

## 处理建议
多饮水，使每日尿量保持在 2000 毫升以上，适度运动，限制高盐、高嘌呤食物。急性绞痛时可使用非甾体抗炎药等止痛，并按医嘱选择排石药物或体外冲击波碎石、内镜手术等治疗，定期复查观察结石变化。

## 就医提醒
出现剧烈腰痛、持续血尿、发热寒战或单侧腰部胀痛伴恶心呕吐时，应及时就医；反复发作的结石应进一步查找代谢病因。

## 检查与诊断
肾结石的确诊需要结合临床表现与辅助检查。常用检查包括：尿常规、尿蛋白定量、肾功能、泌尿系超声、尿培养、肾穿刺活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
多饮水、不憋尿、注意个人卫生，避免滥用药物（尤其止痛药、抗生素），定期体检查尿常规与肾功能。

## 就医指引
如出现疑似肾结石的相关症状，建议及时到肾内科、泌尿外科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对肾结石相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
