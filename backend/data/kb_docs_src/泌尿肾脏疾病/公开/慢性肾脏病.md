# 慢性肾脏病

慢性肾脏病是指各种原因导致肾脏结构或功能损害持续超过 3 个月，表现为肾小球滤过率下降或尿检异常。该病起病隐匿，早期常无明显症状。

## 病因
常见病因包括糖尿病、高血压、慢性肾小球肾炎、间质性肾炎、多囊肾等，长期滥用止痛药、高尿酸血症及反复尿路感染也可损伤肾脏。

## 主要症状
早期多无症状，随病情进展可出现乏力、食欲减退、水肿、夜尿增多、泡沫尿、贫血、皮肤瘙痒等；晚期可出现恶心呕吐、气促、少尿。

## 处理建议
控制血压、血糖，限盐并保证优质蛋白摄入，戒烟限酒，避免使用肾毒性药物。定期监测血肌酐、尿蛋白和血压，按分期进行规范管理。

## 就医提醒
糖尿病患者、高血压患者应每年筛查尿常规和肾功能；出现水肿加重、尿量明显减少、呼吸困难、意识模糊时需尽快就医。

## 检查与诊断
慢性肾脏病的确诊需要结合临床表现与辅助检查。常用检查包括：尿常规、尿蛋白定量、肾功能、泌尿系超声、尿培养、肾穿刺活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
多饮水、不憋尿、注意个人卫生，避免滥用药物（尤其止痛药、抗生素），定期体检查尿常规与肾功能。

## 就医指引
如出现疑似慢性肾脏病的相关症状，建议及时到肾内科、泌尿外科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对慢性肾脏病相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
