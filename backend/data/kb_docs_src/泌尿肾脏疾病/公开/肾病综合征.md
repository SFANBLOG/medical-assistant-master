# 肾病综合征

肾病综合征是一组以大量蛋白尿、低白蛋白血症、水肿和高脂血症为特征的临床综合征，可由多种肾小球疾病引起，分为原发性和继发性两类。

## 病因
原发性肾病综合征与肾小球病变（如微小病变型肾病、膜性肾病等）有关；继发性可见于糖尿病肾病、狼疮性肾炎、过敏性紫癜及病毒感染等。

## 主要症状
- 大量泡沫尿。
- 明显水肿，多先起于眼睑、颜面，后蔓延全身，严重时出现胸腹水。
- 易疲劳、食欲减退，血液中白蛋白降低、血脂升高。

## 处理建议
在肾脏专科医生指导下规范治疗，常需糖皮质激素和（或）免疫抑制剂，应严格遵医嘱调整用药，不可自行增减。饮食上适量优质蛋白、限盐，注意防治感染。

## 就医提醒
出现全身水肿、尿量明显减少、发热感染或血栓表现（如单侧下肢肿胀疼痛）时应及时就医。本病需长期随访管理。

## 预防与日常保健
