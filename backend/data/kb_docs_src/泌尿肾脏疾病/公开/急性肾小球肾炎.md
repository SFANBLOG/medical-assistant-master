# 急性肾小球肾炎

急性肾小球肾炎是以血尿、蛋白尿、水肿和高血压为主要表现的肾小球急性炎症，多见于儿童和青少年，常继发于链球菌感染。

## 病因
多由 A 组乙型溶血性链球菌感染（如咽炎、扁桃体炎、皮肤脓疱疮）后 1-3 周发生，是免疫反应损伤肾小球所致；也可由病毒感染、药物等诱发。

## 主要症状
- 肉眼血尿，尿液呈洗肉水样或浓茶色。
- 晨起眼睑、颜面水肿，可累及下肢。
- 血压升高、尿量减少，部分伴乏力、食欲下降。

## 处理建议
急性期需卧床休息，限盐、限水，控制血压，并在医生指导下对症治疗。绝大多数患者可痊愈，儿童预后较好。链球菌感染需规范抗感染治疗。

## 就医提醒
出现肉眼血尿、眼睑水肿、血压升高、尿量明显减少时应及时就医；急性期应规律随访尿常规和肾功能直至恢复。

## 检查与诊断
急性肾小球肾炎的确诊需要结合临床表现与辅助检查。常用检查包括：尿常规、尿蛋白定量、肾功能、泌尿系超声、尿培养、肾穿刺活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
多饮水、不憋尿、注意个人卫生，避免滥用药物（尤其止痛药、抗生素），定期体检查尿常规与肾功能。

## 就医指引
如出现疑似急性肾小球肾炎的相关症状，建议及时到肾内科、泌尿外科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对急性肾小球肾炎相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
