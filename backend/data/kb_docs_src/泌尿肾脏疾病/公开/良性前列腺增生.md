# 良性前列腺增生

良性前列腺增生是男性随年龄增长常见的前列腺良性增大，可压迫尿道引起排尿障碍，多发生于 50 岁以上男性。

## 病因
与年龄增长和雄激素水平有关。睾丸功能正常是发病的基础，老年男性体内激素代谢变化促使前列腺间质和腺体增生。

## 主要症状
- 排尿期：尿线细、无力，排尿费力、间断。
- 储尿期：尿频、尿急、夜尿增多。
- 排尿后：尿不尽感、尿后滴沥，严重者可出现尿潴留、血尿。

## 处理建议
轻中度者可先调整生活方式，避免憋尿、饮酒和辛辣刺激食物，减少睡前饮水；可在医生指导下使用 α 受体阻滞剂、5α-还原酶抑制剂等药物。症状明显或出现并发症时，考虑微创或手术治疗。

## 就医提醒
出现急性尿潴留、反复尿路感染、血尿、肾积水或肾功能损害时应及时就诊，定期随访评估前列腺体积和残余尿量。

## 检查与诊断
良性前列腺增生的确诊需要结合临床表现与辅助检查。常用检查包括：尿常规、尿蛋白定量、肾功能、泌尿系超声、尿培养、肾穿刺活检等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
多饮水、不憋尿、注意个人卫生，避免滥用药物（尤其止痛药、抗生素），定期体检查尿常规与肾功能。

## 就医指引
如出现疑似良性前列腺增生的相关症状，建议及时到肾内科、泌尿外科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
