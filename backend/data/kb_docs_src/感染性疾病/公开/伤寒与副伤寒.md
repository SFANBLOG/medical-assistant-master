# 伤寒与副伤寒

伤寒和副伤寒是由伤寒沙门菌及副伤寒沙门菌引起的急性肠道传染病，以持续发热、相对缓脉、肝脾肿大、玫瑰疹和白细胞减少为主要表现。

## 病因
病原菌存在于患者或带菌者的粪便中，经污染的水、食物、日常生活接触及苍蝇等传播，夏秋季多见，卫生条件较差的地区更容易流行。

## 主要症状
潜伏期约1～2周，起病缓慢，体温阶梯样上升并持续高热，可伴乏力、食欲减退、腹胀、便秘或腹泻，可有相对缓脉和肝脾肿大，部分患者胸腹部出现淡红色玫瑰疹。

## 处理建议
确诊后应住院或居家隔离治疗，隔离至症状消失且粪便培养连续两次阴性。在医生指导下规范使用抗菌药物并保证足够疗程，以防复发和慢性带菌。注意饮食卫生，多饮水，卧床休息。

## 就医提醒
持续高热伴乏力、腹胀者应及时就医，尤其曾到过疫区或有不洁饮食史者。出现黑便、剧烈腹痛等提示肠出血、肠穿孔的表现时需紧急处理。
