# 乙型肝炎

乙型肝炎（简称乙肝）是由乙型肝炎病毒（HBV）引起的肝脏炎症性疾病，可呈急性或慢性经过。我国曾是乙肝中高流行地区，广泛接种乙肝疫苗后感染率已显著下降。

## 病因
乙肝病毒主要经血液、母婴和性接触传播，如共用注射器、不洁注射、输血及血制品、母婴垂直传播等。日常工作、学习、共餐或拥抱一般不传播乙肝病毒。

## 主要症状
急性感染可出现乏力、食欲减退、恶心、呕吐、右上腹不适、尿黄、皮肤巩膜黄染等，部分患者无症状。慢性感染者多无明显不适，但病毒持续存在，长期可进展为肝纤维化、肝硬化甚至肝癌。

## 处理建议
急性乙肝多数可自行恢复，注意休息、清淡饮食、禁酒。慢性乙肝需在专科医生评估后决定是否抗病毒治疗，常用药物包括核苷（酸）类似物和干扰素类等。疑似感染者应检测乙肝两对半、HBV DNA和肝功能。

## 就医提醒
出现持续乏力、明显黄疸、腹胀、牙龈出血或不明原因消瘦，应及时到感染科或肝病科就诊；明确诊断者需定期复查肝功能、病毒载量及影像学检查，并遵医嘱随访。

## 检查与诊断
乙型肝炎的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、炎症标志物（CRP/PCT）、病原学检查（培养、抗原/抗体检测、核酸）等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似乙型肝炎的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对乙型肝炎相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
