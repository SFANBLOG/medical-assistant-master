# 水痘

水痘是由水痘-带状疱疹病毒引起的急性传染病，多见于儿童，传染性极强，病后可获得持久免疫，但病毒可潜伏体内，成年后可能引起带状疱疹。

## 病因
主要通过呼吸道飞沫和直接接触水痘疱疹液传播，也可经被污染的用具间接传播。冬春季节高发，未接种疫苗者普遍易感。

## 主要症状
发热伴全身分批出现的斑疹、丘疹、疱疹和结痂，皮疹以躯干为多、向心性分布，可累及头皮和口腔黏膜，伴瘙痒，整个病程约2周。

## 处理建议
患儿居家隔离至全部疱疹结痂干燥，注意剪短指甲、避免抓挠以防继发感染，勤换衣物、保持皮肤清洁。瘙痒明显时可外用炉甘石洗剂等止痒，发热对症处理。密切接触者可在医生评估下接种疫苗或使用抗病毒药物预防。

## 就医提醒
出现持续高热、皮疹感染化脓、精神差、呼吸急促，或成人、孕妇、免疫力低下者患水痘时病情往往较重，应及时就医。

## 检查与诊断
水痘的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、炎症标志物（CRP/PCT）、病原学检查（培养、抗原/抗体检测、核酸）等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似水痘的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对水痘相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
