# 登革热

登革热是由登革病毒引起的急性蚊媒传染病，经伊蚊叮咬传播，主要流行于热带和亚热带地区，夏秋雨季高发。

## 病因
登革病毒有4个血清型，由埃及伊蚊和白纹伊蚊传播。人群普遍易感，感染后对同型病毒有持久免疫，但二次感染不同血清型可能增加重症风险。

## 主要症状
潜伏期3～14天，典型表现为突起高热、剧烈头痛、眼眶痛、肌肉关节痛，伴皮疹、出血倾向（皮下出血点、牙龈出血、鼻出血）和淋巴结肿大。发热后期体温下降时需警惕重症（休克、严重出血、多器官损伤）。

## 处理建议
目前无特效抗病毒药物，以对症支持治疗为主，注意休息、多饮水、监测体温。高热以物理降温为主，慎用可能增加出血风险的解热药物。居所安装纱窗、使用蚊帐和驱蚊剂，清除室内外积水孳生地。

## 就医提醒
发热后体温骤降时出现血压下降、烦躁、少尿、频繁呕吐、腹痛加剧或明显出血，应立即就医。疫区或流行季节的发热患者应及时就诊筛查。

## 检查与诊断
登革热的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、炎症标志物（CRP/PCT）、病原学检查（培养、抗原/抗体检测、核酸）等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似登革热的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对登革热相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
