# 艾滋病防控知识

艾滋病（AIDS）是由人类免疫缺陷病毒（HIV）感染引起的慢性传染病，病毒破坏机体免疫系统，若不治疗可发展为各种机会性感染和肿瘤。艾滋病目前尚不能治愈，但可以有效控制。

## 病因
HIV主要经性接触、血液及母婴三种途径传播。握手、拥抱、共餐、共用办公用品、蚊虫叮咬等日常接触不会传播。

## 主要症状
感染初期可有发热、咽痛、皮疹、淋巴结肿大等类似感冒的症状，多在2～4周后自行缓解，随后进入无症状潜伏期。随着免疫力下降，可出现长期发热、腹泻、体重下降、反复感染等。

## 处理建议
预防是核心：坚持正确使用安全套、避免不洁注射、不共用针具、阻断母婴传播。有高危暴露者应尽早（72小时内）进行暴露后预防用药。确诊后尽早启动抗反转录病毒治疗，坚持规律服药可抑制病毒复制、延长寿命并显著降低传播风险。

## 就医提醒
有高危行为或怀疑暴露者，应到疾控中心或定点医院进行咨询检测；窗口期检测可能为阴性，需按医生建议复测。确诊者应到定点医疗机构规范随访治疗。

## 检查与诊断
艾滋病防控知识的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、炎症标志物（CRP/PCT）、病原学检查（培养、抗原/抗体检测、核酸）等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似艾滋病防控知识的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对艾滋病防控知识相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
