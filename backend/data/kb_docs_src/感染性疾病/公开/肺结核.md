# 肺结核

肺结核是由结核分枝杆菌引起的慢性呼吸道传染病，主要通过空气飞沫传播，是最常见的结核病类型。

## 病因
活动性肺结核患者咳嗽、打喷嚏或大声说话时排出含菌飞沫，健康人吸入后可能感染。机体免疫力低下者（如糖尿病、HIV感染、长期使用免疫抑制剂者）更易发病。

## 主要症状
咳嗽、咳痰超过2周，可伴痰中带血、午后低热、盗汗、乏力、食欲减退、消瘦等全身症状。部分患者起病隐匿，症状不典型，容易被忽视。

## 处理建议
一旦确诊，应到结核病定点医疗机构接受规范抗结核治疗，疗程通常6个月以上，遵循早期、联合、适量、规律、全程的原则。治疗期间注意休息、加强营养，传染性患者在治疗初期注意呼吸道隔离。

## 就医提醒
咳嗽咳痰超过2周，或伴咯血、低热盗汗、消瘦等症状者，应及时到呼吸科或结核病防治机构行胸部影像和痰菌等相关检查。

肺结核的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、炎症标志物（CRP/PCT）、病原学检查（培养、抗原/抗体检测、核酸）等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似肺结核的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对肺结核相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
