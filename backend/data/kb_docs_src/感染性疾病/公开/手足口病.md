# 手足口病

手足口病是由肠道病毒引起的儿童常见传染病，多发生于5岁以下婴幼儿，以发热和手、足、口、臀等部位皮疹为特征。

## 病因
主要由肠道病毒71型（EV71）、柯萨奇病毒A16型等引起，经消化道、呼吸道飞沫及接触传播，春夏季节高发，托幼机构容易聚集发病。

## 主要症状
发热，口腔黏膜可见疱疹或溃疡（可致咽痛、拒食），手、足、臀部出现斑丘疹或疱疹，皮疹一般不痛不痒。多数为轻症，病程约1周自愈；少数重症可发生脑炎、脑膜炎、肺水肿等。

## 处理建议
轻症居家隔离至皮疹结痂后约1周，注意休息、清淡流质饮食、多饮水。口腔溃疡可用温凉水漱口缓解疼痛，发热给予对症处理。患儿用具、玩具需消毒，照护者勤洗手。

## 就医提醒
出现持续高热不退、精神萎靡、嗜睡、惊跳、肢体抖动、呕吐、呼吸急促等提示重症表现，应立即就医，尤其发病后3～5天内需密切观察。
