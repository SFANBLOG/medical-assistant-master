# 疫苗接种规范

预防接种是控制传染病最经济有效的手段，规范接种流程、保证疫苗质量和接种安全是基层医疗工作的基本要求。

## 临床要点
- 严格执行疫苗冷链管理，全程保持规定温度并做好温度监测记录，保证疫苗有效性。
- 接种前核对疫苗品种、批号、效期和受种者信息，掌握接种禁忌证（如发热、急性疾病、既往严重过敏史、特定疫苗对免疫功能低下者的限制等）。
- 按国家免疫规划程序和各疫苗说明书推荐的程序、剂量、部位规范接种。

## 处理与观察重点
- 接种后留观至少30分钟，配备急救药品和设备，警惕过敏性休克等急性不良反应。
- 规范记录接种信息，登记疑似预防接种异常反应（AEFI）并按规定上报。
- 对推迟接种者制定补种计划，做好疫苗可预防疾病的查漏补种。

## 注意事项
- 严格区分禁忌与暂缓：发热等急性期暂缓，有明确禁忌者不予接种并书面告知。
- 疫苗开启后按规定时限使用，剩余活疫苗按规定处置。
- 加强知情告知和健康教育，提高接种意愿和依从性。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
疫苗接种规范的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、炎症标志物（CRP/PCT）、病原学检查（培养、抗原/抗体检测、核酸）等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似疫苗接种规范的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对疫苗接种规范相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
