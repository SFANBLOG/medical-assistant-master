# 发热待查的诊断思路

发热待查指持续发热超过3周、体温多次超过38.3℃，经常规初步检查未能明确病因的病例，是临床诊断难点之一。

## 临床要点
- 完整采集热程、热型、伴随症状及流行病学史（疫区旅居、动物接触、不洁饮食、职业暴露），并仔细询问是否自行使用抗菌药物或退热药。
- 常见病因归类：感染性疾病、结缔组织病、肿瘤、其他（药物热、隐匿性脓肿等），感染仍占首位。
- 全面系统体检，重点关注皮疹、淋巴结、肝脾肿大、心脏杂音、关节及口腔黏膜表现。

## 处理与观察重点
- 分层检查：先行无创常规（血尿常规、肝肾功能、血培养、胸腹部影像），再有针对性地行血清学、微生物学及增强影像等检查。
- 必要时在抗感染治疗前重复留取血培养，考虑淋巴结、皮肤、骨髓等活检明确诊断。
- 观察期谨慎使用抗菌药物和退热药，以免掩盖热型、影响培养结果。

## 注意事项
- 避免以"试治"代替诊断，广谱抗菌药物试用无效时应及时停用并重新评估。
- 警惕药物热，注意停药后发热是否消退。
- 长期不明原因发热应组织多学科会诊，动态复查、耐心随访。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
发热待查的诊断思路的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、炎症标志物（CRP/PCT）、病原学检查（培养、抗原/抗体检测、核酸）等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似发热待查的诊断思路的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
