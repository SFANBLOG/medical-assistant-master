# 多重耐药菌的防控

多重耐药菌（MDRO）感染已成为医院感染控制的重点和难点，采取接触隔离、手卫生、环境清洁与抗菌药物管理相结合的综合策略是防控关键。

## 临床要点
- 常见多重耐药菌包括耐甲氧西林金黄色葡萄球菌（MRSA）、耐碳青霉烯类肠杆菌（CRE）、产超广谱β-内酰胺酶（ESBL）肠杆菌等。
- 对高危患者（长期住院、反复使用广谱抗菌药物、侵入性操作、免疫低下）主动进行筛查。
- 严格执行接触隔离，做好标识，规范配置患者物品，减少人员流动。

## 处理与观察重点
- 落实手卫生，接触患者前后及接触环境后严格执行洗手或使用速干手消毒剂。
- 加强环境和物表清洁消毒，患者物品专用，转科转院时书面交接并注明耐药菌情况。
- 治疗依据药敏结果，联合用药等复杂方案由感染科或药学会诊评估。

## 注意事项
- 及时上报医院感染管理部门，建立监测台账和预警机制，发现聚集性传播立即启动调查。
- 向患者及家属做好隔离目的宣教，避免恐慌，保障心理支持。
- 定期汇总分析菌株分布和耐药趋势，指导经验性用药，遏制耐药扩散。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
多重耐药菌的防控的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、炎症标志物（CRP/PCT）、病原学检查（培养、抗原/抗体检测、核酸）等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似多重耐药菌的防控的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
