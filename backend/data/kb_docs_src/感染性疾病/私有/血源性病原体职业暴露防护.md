# 血源性病原体职业暴露防护

血源性病原体（如乙型肝炎病毒、丙型肝炎病毒、HIV）职业暴露是医护人员面临的重要职业风险，规范防护和暴露后处理可显著降低感染风险。

## 临床要点
- 遵循标准预防原则，接触血液、体液、黏膜及破损皮肤时规范佩戴手套、口罩、护目镜等防护用品。
- 规范操作锐器，禁止回套针帽，使用安全型锐器装置，锐器使用后立即投入锐器盒。
- 暴露发生后尽快评估暴露源及暴露者免疫状态，采集基线血标本。

## 处理与观察重点
- 局部处理：在伤口旁轻轻挤压排出血液（近心端向远心端），用流动水和肥皂液冲洗，再用碘伏或乙醇消毒。
- 暴露后预防：乙肝可依据暴露者抗体状态接种疫苗和/或注射乙肝免疫球蛋白；HIV暴露应尽早（2小时内启动，最迟不超过72小时）开始暴露后预防用药；丙肝暂无疫苗，需随访检测。
- 按规定上报登记，并分别于暴露后相应时间点复查相关血清学指标。

## 注意事项
- 任何血液体液接触暴露均不得隐瞒，及时报告并登记，纳入职业暴露档案。
- 加强防护用品使用培训和锐器伤上报制度，倡导安全操作文化。
- 保护患者隐私，HIV暴露后预防用药需由专业人员评估指导。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似血源性病原体职业暴露防护的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
