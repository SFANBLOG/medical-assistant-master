# 乙肝母婴阻断方案

乙肝母婴垂直传播是慢性乙肝的重要来源，通过规范筛查、孕期管理、新生儿免疫等综合措施，可显著降低母婴传播率。

## 临床要点
- 所有孕妇孕期应筛查乙肝表面抗原（HBsAg）；HBsAg阳性者进一步检测乙肝e抗原（HBeAg）和HBV DNA。
- 高病毒载量孕妇（HBV DNA达到一定阈值）可在孕晚期（约24～28周起）由专科医师评估后启动抗病毒治疗，分娩后结合情况决定停药或继续治疗。
- 分娩方式本身不作为阻断母婴传播的主要手段，重点在于新生儿联合免疫。

## 处理与观察重点
- 新生儿出生后12小时内尽早完成乙肝疫苗和乙肝免疫球蛋白联合免疫，并按0、1、6月龄程序完成全程疫苗接种。
- 监测孕期抗病毒治疗孕妇的肝功能、病毒载量及用药安全性。
- 产后随访：新生儿完成全程免疫后1～2个月检测HBsAg和乙肝表面抗体，评估阻断效果。

## 注意事项
- 母乳喂养：母亲规范抗病毒治疗且新生儿完成联合免疫者可正常哺乳，但乳头破损出血时暂停。
- 避免因母婴阻断过度干预，抗病毒药物选择需兼顾疗效与妊娠期安全性。
- 做好健康教育，消除乙肝歧视，告知随访管理流程。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
乙肝母婴阻断方案的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、炎症标志物（CRP/PCT）、病原学检查（培养、抗原/抗体检测、核酸）等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似乙肝母婴阻断方案的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
