# 脓毒症的早期识别

脓毒症是机体对感染反应失调所致的危及生命的器官功能障碍，早期识别和规范处理是降低病死率的关键。

## 临床要点
- 感染患者出现SOFA评分较基线上升≥2分即可诊断脓毒症；床旁快速评估（qSOFA）出现意识改变、呼吸增快（≥22次/分）、收缩压≤100mmHg中任两项即应高度警惕。
- 关注高危人群：老年人、免疫功能低下、糖尿病、肿瘤、留置导管及术后患者。
- 识别感染、炎症反应、器官功能障碍三大要素，警惕脓毒性休克（充分液体复苏后仍需血管活性药物维持血压）。

## 处理与观察重点
- 一旦疑诊，立即启动"1小时集束化"措施：查血乳酸、留取血培养、尽早给予广谱抗菌药物并开始液体复苏。
- 动态监测生命体征、乳酸、尿量、意识状态和灌注指标，评估液体反应性。
- 持续寻找并控制感染源（引流、清创、拔除导管等）。

## 注意事项
- 不能仅以是否发热判断病情，低体温、低血压、意识改变可能是脓毒症的早期线索。
- 液体复苏需个体化，警惕液体过负荷，尤其心肾功能不全者。
- 抗菌药物应在留取培养后尽快使用，不得因等待标本而延误时机。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
脓毒症的早期识别的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、炎症标志物（CRP/PCT）、病原学检查（培养、抗原/抗体检测、核酸）等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似脓毒症的早期识别的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
