# 抗菌药物的合理使用

抗菌药物是临床最常用的药物类别之一，不合理使用可导致治疗失败、不良反应和耐药菌扩散，规范合理用药是临床基本功。

## 临床要点
- 明确病原学诊断是合理用药的基础，用药前尽可能采集标本送细菌培养和药敏试验。
- 严格掌握适应证：有细菌感染证据（临床表现、实验室指标）方可使用，病毒性感染不常规使用抗菌药物。
- 遵循能窄不广、能单一不联合、能口服不静脉的原则，尽量根据药敏结果选择敏感抗菌药物。

## 处理与观察重点
- 按规范疗程用药，避免过早停药导致复发或耐药。
- 用药48～72小时评估疗效（体温、症状变化），无效时复查并调整方案。
- 监测药物不良反应（皮疹、肝肾功能损害、二重感染）及特殊人群（肝肾功能不全、孕妇、儿童）的用药安全。

## 注意事项
- 抗菌药物不得作为常规预防用药滥用，围手术期预防用药有严格指征和时限。
- 避免频繁更换药物、盲目联合用药和超疗程用药。
- 发现耐药菌感染时按防控要求管理并及时上报。

## 检查与诊断
抗菌药物的合理使用的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、炎症标志物（CRP/PCT）、病原学检查（培养、抗原/抗体检测、核酸）等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似抗菌药物的合理使用的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对抗菌药物的合理使用相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
