# 感染性腹泻的补液原则

补液是感染性腹泻治疗的核心，及时纠正和预防脱水、电解质紊乱是降低病死率的关键。

## 临床要点
- 评估脱水程度（轻、中、重度）是补液的前提，依据精神状态、口渴、皮肤弹性、眼窝凹陷、尿量等综合判断。
- 轻中度脱水首选口服补液盐（ORS），按随失随补原则少量多次口服；重度脱水或剧烈呕吐、休克者需静脉补液。
- 根据丢失量和生理需要量估算补液量，注意补充钾、钠等电解质，纠正酸碱失衡。

## 处理与观察重点
- 口服补液盐按说明书正确配制，避免过浓或过稀，腹泻停止后即可停用。
- 密切监测生命体征、尿量、尿比重和意识状态，评估补液效果；儿童需动态称重。
- 观察有无并发症：持续呕吐、腹胀、高钠或低钠血症、肾前性肾功能损害等。

## 注意事项
- 单纯感染性腹泻应避免滥用止泻药，尤其伴发热和黏液脓血便者。
- 静脉补液遵循先盐后糖、先快后慢、见尿补钾的原则，老年人和心肾功能不全者注意控制速度。
- 继续饮食：能进食者尽早恢复喂养，母乳喂养儿继续哺乳，防止营养不良。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似感染性腹泻的补液原则的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
