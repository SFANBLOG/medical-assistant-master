# 结核病的规范治疗

结核病规范治疗是治愈患者、防止耐药和传播的关键，应遵循统一化疗方案并实行全程督导管理。

## 临床要点
- 治疗原则：早期、联合、适量、规律、全程。初治敏感肺结核多采用2个月强化期加4个月巩固期方案，常用药物包括异烟肼、利福平、吡嗪酰胺、乙胺丁醇等。
- 治疗前评估：完善痰检、胸部影像、肝肾功能及药物敏感性试验，明确初治或复治，排查合并症（HIV、糖尿病、肝病等）。
- 耐药结核需根据药敏和个体情况制定个体化方案，疗程明显延长。

## 处理与观察重点
- 强化期每月查痰，监测痰菌阴转情况；定期复查胸部影像和肝功能。
- 观察药物不良反应：利福平相关肝损害、异烟肼周围神经炎、吡嗪酰胺高尿酸血症、乙胺丁醇视神经损害等，及时处理。
- 落实直接面视下督导服药（DOTS），提高依从性，防止中断和漏服。

## 注意事项
- 治疗中断或失败病例应分析原因，及时评估耐药可能并送药敏试验。
- 传染性患者在有效治疗初期注意呼吸道隔离，落实咳嗽礼仪。
- 加强与疾控机构对接，落实病例登记、追踪和转归管理。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
结核病的规范治疗的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、炎症标志物（CRP/PCT）、病原学检查（培养、抗原/抗体检测、核酸）等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
勤洗手、保持环境通风、接种疫苗、注意饮食与饮水卫生，流行季节减少人群聚集，出现症状及时就医。

## 就医指引
如出现疑似结核病的规范治疗的相关症状，建议及时到感染科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
