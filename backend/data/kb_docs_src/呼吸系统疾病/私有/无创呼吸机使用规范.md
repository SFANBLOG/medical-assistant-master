# 无创呼吸机使用规范

无创正压通气（NIPPV）是急慢性呼吸衰竭的重要治疗手段，规范使用可显著改善预后、减少气管插管需求。

## 临床要点
适应证包括慢阻肺急性加重伴呼吸性酸中毒、急性心源性肺水肿、术后及拔管后呼吸衰竭等；相对禁忌证有意识障碍、严重低氧需高浓度氧疗、气道分泌物多且排痰能力差、上气道阻塞、血流动力学不稳定及面部创伤等。

## 处理与观察重点
选择合适的鼻罩或口鼻面罩，保证良好密封与舒适度。根据血气分析与临床反应调整模式和参数（潮气量、压力、氧浓度），目标是缓解呼吸困难、改善通气。开始后 1-2 小时复查血气评估疗效，若无效或恶化应及时调整或改行有创通气。

## 注意事项
密切监测人机同步性、漏气、腹胀、皮肤压伤和眼部刺激。无创通气失败预警征象（动脉血气 pH 持续下降、意识恶化、血流动力学不稳定）出现时应果断气管插管。呼吸机及管路规范清洁消毒，防止院内感染。

## 预防与日常保健

## 就医指引
