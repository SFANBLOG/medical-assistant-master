# 支气管镜检查前后护理

支气管镜检查是呼吸科常用诊疗手段，规范的前后护理是保证检查安全、提高患者配合度的关键。

## 临床要点
术前评估适应证与禁忌证（严重心肺功能不全、难以纠正的出血倾向、近期大咯血等），完善凝血功能、心电图、血气分析等检查。向患者解释检查流程并签署知情同意，术前禁食禁水 4-6 小时。术后常见并发症为咽喉不适、咯血、气胸、发热、低氧血症等。

## 处理与观察重点
术中配合医生监测生命体征和血氧饱和度，备好抢救物品。术后观察咯血情况（少量痰中带血多为正常）、气促、胸痛等，麻醉未完全消退前禁食禁水约 2 小时，防止误吸。行活检者注意出血倾向，嘱患者咯血量增多或呼吸困难时立即报告。

## 注意事项
老年及心肺基础差者应严格评估并加强术中监护。严格无菌操作，内镜及附件规范清洗消毒，防止交叉感染。登记病理送检与随访安排，提醒患者按约定复诊取报告。
