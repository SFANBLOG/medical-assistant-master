# 呼吸道传染病医院感染防控

呼吸道传染病通过飞沫、气溶胶和接触传播，院内防控的核心是"早发现、早隔离、早报告"和落实标准预防。

## 临床要点
门诊分诊时进行体温筛查与呼吸道症状询问，疑似患者发放口罩并引导至发热门诊或独立诊室。按传播途径采取飞沫隔离与接触隔离；空气传播疾病（如肺结核、水痘、麻疹）需在负压病房收治。医务人员严格执行手卫生，规范佩戴口罩、护目镜或面屏及隔离衣。

## 处理与观察重点
疑似或确诊患者单间隔离或集中安置，限制活动范围。加强环境物表清洁消毒与通风，做好医疗废物规范处置。按规定进行传染病网络直报，对密切接触者登记随访。对病区患者开展呼吸道卫生及咳嗽礼仪教育。

## 注意事项
按指南合理选用防护用品，避免过度防护造成浪费。加强针刺伤、黏膜暴露等职业暴露后的处置与流行病学调查。定期开展培训演练，提高全员防控意识，防止院内聚集性疫情发生。
