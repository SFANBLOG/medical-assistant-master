# 肺功能检测判读要点

肺功能检测是诊断和评估呼吸系统疾病（尤其阻塞性、限制性通气功能障碍）的重要客观指标，判读需结合质量控制与临床资料。

## 临床要点
核心指标包括用力肺活量（FVC）、第 1 秒用力呼气容积（FEV1）、FEV1/FVC 比值、肺总量（TLC）等。FEV1/FVC 下降提示阻塞性通气功能障碍（常见于慢阻肺、哮喘）；TLC 下降伴 FVC 下降提示限制性通气障碍（常见于间质性肺病、胸廓畸形等）。

## 处理与观察重点
先评估曲线质量（起始是否有力、呼气时间是否充分、重复性是否达标），不合格图形结果不可靠。慢阻肺诊断以吸入支气管扩张剂后 FEV1/FVC 低于 70% 为准，并按 FEV1 占预计值百分比进行分级。支气管舒张试验或激发试验用于哮喘评估，反应阳性标准需按规范界定。

## 注意事项
判读需结合预计值方程、种族、性别、年龄和身高体重。检测前需按规范停用相关药物（如短效支气管扩张剂停药时间要足够）。严重咯血、不稳定心绞痛、气胸及近期大手术者不宜行用力肺功能检测。随访评估疗效时尽量使用同一设备、同一预计值体系。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
肺功能检测判读要点的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、C反应蛋白等炎症指标、胸部影像学检查（X线/CT）、肺功能检查、血气分析、痰培养及药敏等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
戒烟、避免吸入粉尘与有害气体，流感季节接种疫苗，注意保暖、避免受凉，勤洗手、保持室内通风，规律运动增强体质。

## 就医指引
如出现疑似肺功能检测判读要点的相关症状，建议及时到呼吸内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
