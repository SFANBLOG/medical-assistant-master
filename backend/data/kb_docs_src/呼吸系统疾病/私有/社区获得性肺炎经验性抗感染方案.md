# 社区获得性肺炎经验性抗感染方案

社区获得性肺炎（CAP）的抗感染治疗常需在病原学结果回报前经验性用药，应结合患者年龄、基础疾病、病情严重度及本地耐药情况进行选择。

## 临床要点
轻中度 CAP 门诊患者可选用大环内酯类、多西环素或呼吸喹诺酮类单药，或 β 内酰胺类联合大环内酯类；住院非重症患者推荐 β 内酰胺类联合大环内酯类，或呼吸喹诺酮类单药。重症患者推荐 β 内酰胺类联合大环内酯类或联合喹诺酮类，必要时加用抗病毒药物。

## 处理与观察重点
用药前常规留取痰培养、血培养及肺炎支原体、衣原体、流感病毒等病原学检测，尽早使用第一剂抗菌药物。48-72 小时评估临床反应，根据病原学结果及时调整为目标治疗。

## 注意事项
参考本地耐药监测数据，警惕耐药肺炎链球菌和耐大环内酯类支原体。老年或存在误吸风险者需覆盖厌氧菌；肾功能不全者按肌酐清除率调整剂量。明确病原后应降阶梯，避免不必要联合用药，疗程一般控制在 5-7 天。

## 检查与诊断
社区获得性肺炎经验性抗感染方案的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、C反应蛋白等炎症指标、胸部影像学检查（X线/CT）、肺功能检查、血气分析、痰培养及药敏等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
戒烟、避免吸入粉尘与有害气体，流感季节接种疫苗，注意保暖、避免受凉，勤洗手、保持室内通风，规律运动增强体质。

## 就医指引
如出现疑似社区获得性肺炎经验性抗感染方案的相关症状，建议及时到呼吸内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
