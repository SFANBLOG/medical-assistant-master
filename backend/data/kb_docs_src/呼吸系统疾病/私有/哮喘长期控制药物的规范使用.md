# 哮喘长期控制药物的规范使用

哮喘治疗强调"评估—调整—监测"的长期管理，控制药物是维持气道炎症缓解、预防急性发作的基础。

## 临床要点
控制药物以吸入性糖皮质激素为核心，常联合长效β2受体激动剂、白三烯调节剂、长效抗胆碱能药物等；急性发作期使用短效支气管扩张剂等缓解药物。无论控制药物还是缓解药物，均应强调吸入装置的规范操作和依从性。

## 处理与观察重点
按哮喘控制水平分级调整方案：控制良好者维持，部分控制者升级，失控者升级并复核依从性与吸入技术。每 1-3 个月评估一次，达到良好控制并维持 3 个月以上可考虑降级，逐步调整。定期评估肺功能和哮喘控制问卷，动态监测用药效果。

## 注意事项
首次处方或更换吸入装置时应现场演示并回示，确认患者掌握方法。切勿在未评估的情况下长期依赖缓解药物而忽视控制药物。妊娠期、老年患者及哮喘慢阻肺重叠者需个体化调整。注意吸入性糖皮质激素相关不良反应（如口腔念珠菌感染、声音嘶哑），嘱患者用后漱口。
