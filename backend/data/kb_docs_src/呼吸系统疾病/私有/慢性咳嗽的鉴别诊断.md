# 慢性咳嗽的鉴别诊断

慢性咳嗽指成人咳嗽持续超过 8 周且 X 线胸片无明显异常者，病因复杂，需系统鉴别。

## 临床要点
常见病因依次为上气道咳嗽综合征（鼻后滴流综合征）、咳嗽变异性哮喘、胃食管反流性咳嗽、嗜酸粒细胞性支气管炎。此外还需考虑慢性支气管炎、支气管扩张症、血管紧张素转换酶抑制剂相关咳嗽、慢性感染（结核、真菌等）、肺癌及心因性咳嗽。

## 处理与观察重点
病史重点询问咳嗽发生时间、性质、诱因（冷空气、运动、体位）及伴随症状（鼻塞、反酸、咳痰、咯血）和用药史。结合鼻咽镜、肺功能及支气管激发试验、诱导痰细胞学、食管 pH 监测、胸部 CT 等检查逐步明确，必要时行诊断性治疗观察。

## 注意事项
咳嗽变异性哮喘可无喘息，以夜间干咳为主；嗜酸粒细胞性支气管炎需靠诱导痰细胞学确诊。诊断性治疗应设定明确观察时限，治疗无效或出现咯血、消瘦等警示征象时，应及时行胸部影像及支气管镜检查以排查占位性病变。

## 检查与诊断
慢性咳嗽的鉴别诊断的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、C反应蛋白等炎症指标、胸部影像学检查（X线/CT）、肺功能检查、血气分析、痰培养及药敏等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
戒烟、避免吸入粉尘与有害气体，流感季节接种疫苗，注意保暖、避免受凉，勤洗手、保持室内通风，规律运动增强体质。

## 就医指引
如出现疑似慢性咳嗽的鉴别诊断的相关症状，建议及时到呼吸内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对慢性咳嗽的鉴别诊断相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
