# 支气管哮喘

支气管哮喘是一种以慢性气道炎症为特征的异质性疾病，常表现为反复发作的喘息、气急、胸闷和咳嗽，多见于儿童和青年，规范管理下多数患者可良好控制。

## 病因
哮喘的发病与遗传易感性及环境因素有关。常见诱发因素包括：尘螨、花粉、霉菌、动物毛屑等过敏原；冷空气、烟雾、刺激性气体；上呼吸道感染；运动、情绪波动及某些药物（如阿司匹林）等。

## 主要症状
典型表现为反复发作的喘息、气急、胸闷和咳嗽，多在夜间或凌晨加重，常伴呼气相哮鸣音。发作时患者自觉胸部紧迫感，严重者出现端坐呼吸、口唇发绀、说话不成句等表现。

## 处理建议
规范用药是控制哮喘的关键，需长期规律使用吸入性糖皮质激素等控制药物，急性发作时按需使用缓解药物（如短效支气管扩张剂）。患者应了解并尽量回避诱发因素，正确掌握吸入装置使用方法，在医生指导下制定书面哮喘行动计划，家中备好急救药物，学会识别哮喘加重的早期信号。

## 就医提醒
出现严重呼吸困难、说话困难、口唇发绀或意识改变，使用缓解药物后症状不缓解或加重，属于哮喘危重发作，应立即拨打急救电话就医。

## 检查与诊断
支气管哮喘的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、C反应蛋白等炎症指标、胸部影像学检查（X线/CT）、肺功能检查、血气分析、痰培养及药敏等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
戒烟、避免吸入粉尘与有害气体，流感季节接种疫苗，注意保暖、避免受凉，勤洗手、保持室内通风，规律运动增强体质。

## 就医指引
