# 急性上呼吸道感染

急性上呼吸道感染是鼻腔、咽或喉部急性炎症的总称，俗称"感冒"，是最常见的感染性疾病之一，多数由病毒引起，具有自限性。

## 病因
绝大多数由病毒引起，常见有鼻病毒、冠状病毒、副流感病毒、呼吸道合胞病毒、腺病毒等，少数为细菌直接感染或继发细菌感染。受凉、疲劳、淋雨及免疫力下降时更易发病。

## 主要症状
起病较急，常见打喷嚏、鼻塞、流清水样鼻涕、咽干咽痒或咽痛，可伴咳嗽、声音嘶哑。一般无高热，可有低热、头痛、全身不适。普通感冒一般 5-7 天可痊愈。

## 处理建议
以对症处理为主，注意休息、多饮水、保持室内空气流通。鼻塞、咽痛、发热等可用对症药物缓解；若出现脓涕、脓痰、高热不退等提示继发细菌感染时，需在医生指导下使用抗菌药物。勤洗手、注意咳嗽礼仪，避免传染他人。

## 就医提醒
若发热超过 3 天、症状进行性加重，或出现剧烈头痛、胸痛、呼吸困难，以及婴幼儿、老年人及有基础疾病者症状较重时，应及时就医。

## 检查与诊断
急性上呼吸道感染的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、C反应蛋白等炎症指标、胸部影像学检查（X线/CT）、肺功能检查、血气分析、痰培养及药敏等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
戒烟、避免吸入粉尘与有害气体，流感季节接种疫苗，注意保暖、避免受凉，勤洗手、保持室内通风，规律运动增强体质。

## 就医指引
如出现疑似急性上呼吸道感染的相关症状，建议及时到呼吸内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对急性上呼吸道感染相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
