# 慢性阻塞性肺疾病

慢性阻塞性肺疾病（简称慢阻肺）是一种常见的、可预防和可治疗的慢性气道疾病，以持续气流受限为特征，与有害气体或颗粒的长期暴露有关，吸烟是最主要的危险因素。

## 病因
吸烟是慢阻肺最主要的病因；此外，长期接触职业性粉尘和化学物质、室内外空气污染、反复呼吸道感染，以及少数遗传因素（如α1-抗胰蛋白酶缺乏）也可致病。

## 主要症状
以慢性咳嗽、咳痰和进行性加重的呼吸困难为核心表现。早期仅在活动后气短，随病情进展，平地行走甚至休息时也可气促。急性加重期症状明显加重，可伴发热、痰量增多或脓痰。

## 处理建议
戒烟是延缓肺功能下降最有效的措施。治疗以吸入支气管扩张剂为主的规律用药为基础，可明显改善症状、减少急性加重。肺康复训练、营养支持以及接种流感疫苗和肺炎疫苗有助于稳定病情。部分患者可在医生指导下居家使用家用无创呼吸机。

## 就医提醒
呼吸困难突然明显加重、痰量骤增或出现脓痰、发热、口唇发绀或意识模糊时，提示急性加重，应及时就医；重症患者需住院甚至接受无创或机械通气治疗。

## 检查与诊断
慢性阻塞性肺疾病的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、C反应蛋白等炎症指标、胸部影像学检查（X线/CT）、肺功能检查、血气分析、痰培养及药敏等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
戒烟、避免吸入粉尘与有害气体，流感季节接种疫苗，注意保暖、避免受凉，勤洗手、保持室内通风，规律运动增强体质。

## 就医指引
如出现疑似慢性阻塞性肺疾病的相关症状，建议及时到呼吸内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
