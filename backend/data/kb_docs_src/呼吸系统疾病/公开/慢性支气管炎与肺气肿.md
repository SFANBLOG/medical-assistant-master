# 慢性支气管炎与肺气肿

慢性支气管炎与肺气肿是慢性气道疾病谱中的常见类型，两者常并存，共同构成慢性阻塞性肺疾病的主要病理基础。

## 病因
吸烟是最主要的危险因素，长期接触粉尘、有害气体和空气污染，反复呼吸道感染，以及呼吸道防御功能下降等均与发病有关。多在中年以后发病，病程漫长。

## 主要症状
慢性支气管炎以慢性咳嗽、咳痰为主，每年发作持续三个月以上、连续两年以上；肺气肿以进行性加重的活动后气促为主要表现，可伴桶状胸、呼吸音减弱。两者均可出现急性加重，症状在短期内明显加重。

## 处理建议
戒烟是延缓病情进展的关键。急性期按医嘱使用抗感染、化痰、平喘等药物；缓解期注意保暖、预防感冒，接种流感疫苗和肺炎疫苗。坚持康复锻炼和营养支持，学会有效排痰方法，并定期进行肺功能检查评估病情。

## 就医提醒
若出现呼吸困难明显加重、咳大量脓痰、发热、咯血，或出现口唇发绀、下肢水肿等表现，提示病情加重或出现并发症，应及时就医。

## 检查与诊断
慢性支气管炎与肺气肿的确诊需要结合临床表现与辅助检查。常用检查包括：血常规、C反应蛋白等炎症指标、胸部影像学检查（X线/CT）、肺功能检查、血气分析、痰培养及药敏等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
戒烟、避免吸入粉尘与有害气体，流感季节接种疫苗，注意保暖、避免受凉，勤洗手、保持室内通风，规律运动增强体质。

## 就医指引
如出现疑似慢性支气管炎与肺气肿的相关症状，建议及时到呼吸内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对慢性支气管炎与肺气肿相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
