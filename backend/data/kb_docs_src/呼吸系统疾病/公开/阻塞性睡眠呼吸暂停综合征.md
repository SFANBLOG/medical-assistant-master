# 阻塞性睡眠呼吸暂停综合征

阻塞性睡眠呼吸暂停综合征（简称 OSA）是一种以睡眠期间反复发生上气道塌陷、导致呼吸暂停和低通气为特征的疾病，可引起间歇性缺氧和睡眠结构紊乱。

## 病因
多与上气道解剖结构狭窄有关，如肥胖、扁桃体肥大、舌根后坠、下颌后缩等；此外，鼻部阻塞、甲状腺功能减退、饮酒及使用镇静药物等也可诱发或加重。

## 主要症状
夜间表现有打鼾声音响亮、呼吸暂停（常被同床者发现）、憋醒、夜尿增多；白天表现有嗜睡、晨起头痛、口干、注意力不集中、记忆力下降、情绪易激惹。长期未治疗可增加高血压、冠心病、脑卒中和糖脂代谢紊乱的风险。

## 处理建议
控制体重、规律运动、侧卧位睡眠、戒酒、避免使用镇静催眠药均有助于减轻症状。中重度患者常使用持续气道正压通气（无创呼吸机）治疗，疗效确切。伴鼻塞者应积极治疗鼻炎，下颌后缩者可考虑口腔矫治器。

## 就医提醒
若打鼾伴呼吸暂停、白天明显嗜睡，或已出现血压血糖异常、心律失常等并发症，应到睡眠医学相关科室就诊，行睡眠监测以明确诊断和指导治疗。

## 预防与日常保健
戒烟、避免吸入粉尘与有害气体，流感季节接种疫苗，注意保暖、避免受凉，勤洗手、保持室内通风，规律运动增强体质。

## 就医指引
如出现疑似阻塞性睡眠呼吸暂停综合征的相关症状，建议及时到呼吸内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
