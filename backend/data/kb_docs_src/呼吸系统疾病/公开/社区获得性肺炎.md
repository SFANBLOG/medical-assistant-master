# 社区获得性肺炎

社区获得性肺炎是指在医院外罹患的肺实质感染性炎症，是常见的呼吸系统疾病，老年人、儿童及有基础疾病者患病风险更高，需及时识别和处理。

## 病因
主要由细菌（如肺炎链球菌、流感嗜血杆菌、支原体、衣原体）和病毒（如流感病毒、呼吸道合胞病毒）等引起。受凉、劳累、免疫力低下、吸烟及慢性心肺疾病均会增加患病风险。

## 主要症状
起病可急可缓，常见发热、咳嗽、咳痰（可为脓痰或痰中带血）、胸痛、呼吸急促，可伴乏力、头痛、食欲减退等全身症状。老年患者症状可不典型，仅表现为精神萎靡或意识改变。

## 处理建议
轻症患者可居家治疗，注意休息、多饮水、补充营养。抗菌药物应在医生指导下选用，不可自行随意服用或停药；咳嗽有利于排痰，不要一味强忍，可遵医嘱使用化痰药物。发热可物理降温并遵医嘱使用退热药，密切观察体温和呼吸情况。

## 就医提醒
出现高热不退、呼吸急促、胸痛明显、咳血、精神萎靡或意识改变，或老年人、孕妇、婴幼儿及有基础疾病者患病，应尽快就医，必要时住院治疗。
