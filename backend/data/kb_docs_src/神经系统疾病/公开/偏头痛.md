# 偏头痛

偏头痛是一种反复发作的原发性头痛，表现为中重度、搏动样头痛，常累及一侧，可持续数小时至数天，是临床最常见的致残性疾病之一。

## 病因
病因尚未完全明确，与遗传、神经血管功能异常有关。发作常由诱因触发，常见诱因包括睡眠不足或睡眠过多、精神紧张与压力、月经周期、某些食物（如奶酪、巧克力、红酒、含亚硝酸盐食品）、饥饿、强光、噪声以及天气变化等。

## 主要症状
发作前部分患者出现前驱症状，如打哈欠、疲劳、情绪变化；约四分之一患者在头痛前有先兆，最常见为视觉先兆（闪光、暗点、视物变形），持续约 5-60 分钟。随后出现单侧或双侧搏动样头痛，伴恶心、呕吐、畏光、畏声，活动后加重。

## 处理建议
发作期应尽快在安静、避光的房间休息，冷敷额部，规律作息、避免诱因。缓解期可进行头痛日记，帮助识别并规避个人诱因；急性发作可遵医嘱使用非甾体抗炎药或曲普坦类药物，频繁发作或严重影响生活者可由医生评估是否采用预防性用药。

## 就医提醒
出现"雷击样"突发剧烈头痛、伴发热、颈项强直、肢体无力、言语障碍、视物不清或意识改变，或头痛性质与既往明显不同，或每周头痛超过两次、常规止痛无效时，应及时就医排除其他器质性疾病。

## 检查与诊断
偏头痛的确诊需要结合临床表现与辅助检查。常用检查包括：神经系统查体、头颅CT/MRI、脑电图、肌电图、脑脊液检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、避免过度劳累与熬夜，控制高血压、糖尿病、高血脂等基础病，保持心情舒畅，适量运动。

## 就医指引
如出现疑似偏头痛的相关症状，建议及时到神经内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
