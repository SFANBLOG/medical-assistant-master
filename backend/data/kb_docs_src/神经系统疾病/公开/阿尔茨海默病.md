# 阿尔茨海默病

阿尔茨海默病是老年人最常见的神经退行性疾病，以进行性记忆减退和认知功能下降为主要特征，是痴呆最常见的病因之一，病程通常持续数年至十余年。

## 病因
确切病因未明，与年龄、遗传（如载脂蛋白 E ε4 等位基因）、脑内 β-淀粉样蛋白沉积和 tau 蛋白异常磷酸化、脑血管病变及生活因素等相关。不可干预的危险因素为年龄与遗传，可干预的包括高血压、糖尿病、吸烟、缺乏运动、社会孤立等。

## 主要症状
早期表现为近记忆力减退（刚做过的事很快忘记）、健忘、重复提问、时间地点定向力下降；随病情进展出现语言障碍、计算力下降、判断力受损、性格情绪改变、行为异常，晚期生活不能自理、大小便失禁，需长期照护。

## 处理建议
一旦怀疑应尽早就诊记忆门诊或神经内科，进行认知评估与影像检查，早诊断早干预可延缓进展。确诊后可遵医嘱使用改善认知的药物（如胆碱酯酶抑制剂等），同时注重认知训练、规律运动、健康饮食、控制心脑血管危险因素、保持社交活动。家庭照护者应学习照护技巧，保证患者安全，防止走失与跌倒。

## 就医提醒
老年人出现明显健忘、迷路、性格明显改变或行为异常，影响日常生活时，应及时就医评估，排除甲状腺功能减退、维生素缺乏、药物副作用等可逆性病因。
