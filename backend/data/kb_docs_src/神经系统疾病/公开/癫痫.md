# 癫痫

癫痫是由大脑神经元异常、过度同步放电引起的一组慢性脑部疾病，以反复发作的短暂性神经系统功能异常为特征，俗称"羊癫疯"。

## 病因
病因多样，可分为结构性（脑外伤、脑肿瘤、脑血管病、脑发育畸形）、遗传性、代谢性、感染性（脑炎、脑囊虫病）及病因不明等类型。高热惊厥、脑缺氧等也可诱发。

## 主要症状
发作形式多样：全面性发作表现为突然意识丧失、四肢强直抽搐、口吐白沫、牙关紧闭，数分钟可自行缓解；局灶性发作可表现为一侧肢体抽动、感觉异常、愣神或自动症（如咂嘴、摸索）；还有部分发作仅表现为短暂的失神。

## 处理建议
发作时保护患者安全，移开周围危险物品，让其侧卧、解开领口，不要强行按压肢体或往口中塞任何物品。记录发作时间与表现。大多数患者经规范抗癫痫药物治疗可良好控制，需规律服药、勿自行停药或减量，避免熬夜、饮酒、闪光刺激等诱因。

## 就医提醒
发作持续超过 5 分钟，或一次发作后意识未恢复又再次发作，或出现呼吸困难、外伤，均应立即呼叫急救。初次发作或怀疑癫痫者应到神经内科就诊，完善脑电图、头颅影像等检查明确诊断和分型。

## 检查与诊断
癫痫的确诊需要结合临床表现与辅助检查。常用检查包括：神经系统查体、头颅CT/MRI、脑电图、肌电图、脑脊液检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、避免过度劳累与熬夜，控制高血压、糖尿病、高血脂等基础病，保持心情舒畅，适量运动。

## 就医指引
如出现疑似癫痫的相关症状，建议及时到神经内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对癫痫相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
