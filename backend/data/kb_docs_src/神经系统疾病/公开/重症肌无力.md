# 重症肌无力

重症肌无力是一种自身免疫性神经-肌肉接头传递障碍性疾病，特征为骨骼肌易疲劳、活动后加重、休息后减轻（"晨轻暮重"），可累及眼肌、咽喉肌及四肢肌。

## 病因
由自身抗体（最常为乙酰胆碱受体抗体）攻击神经-肌肉接头处的乙酰胆碱受体等结构，导致肌肉无法正常接收神经信号。部分患者伴胸腺异常（胸腺增生或胸腺瘤），感染、劳累、精神应激、某些药物（如部分抗生素）可诱发或加重病情。

## 主要症状
最常见为眼外肌受累：上睑下垂、复视，晨起较轻、午后加重；累及咽喉肌时出现吞咽困难、饮水呛咳、构音不清；累及四肢近端肌时上楼、举臂困难；严重时累及呼吸肌，出现呼吸困难、无力，称为肌无力危象，危及生命。

## 处理建议
确诊后由神经科医生制定个体化治疗方案，常用胆碱酯酶抑制剂改善症状，以及糖皮质激素、免疫抑制剂等调节免疫，伴胸腺瘤者考虑胸腺切除。患者应规律服药、避免劳累与感染，保证充足睡眠，注意防跌倒；吞咽困难者宜进食软食、细嚼慢咽，防止误吸。

## 就医提醒
出现突发的呼吸困难、发绀、痰多无力咳出，提示肌无力危象，需立即急诊抢救。出现不明原因的眼睑下垂、复视、咀嚼或吞咽费力，或肢体活动后明显无力，应及时到神经内科就诊，勿延误。

## 检查与诊断
重症肌无力的确诊需要结合临床表现与辅助检查。常用检查包括：神经系统查体、头颅CT/MRI、脑电图、肌电图、脑脊液检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、避免过度劳累与熬夜，控制高血压、糖尿病、高血脂等基础病，保持心情舒畅，适量运动。

## 就医指引
如出现疑似重症肌无力的相关症状，建议及时到神经内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
