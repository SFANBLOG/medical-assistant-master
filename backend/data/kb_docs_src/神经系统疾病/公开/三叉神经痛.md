# 三叉神经痛

三叉神经痛是发生在面部三叉神经分布区内的阵发性剧烈疼痛，被形容为"天下第一痛"，多见于中老年人，右侧多于左侧。

## 病因
原发性三叉神经痛多因血管压迫三叉神经根所致，少数继发于肿瘤、多发性硬化、颅底病变等。疼痛常由洗脸、刷牙、说话、咀嚼、冷风刺激等"扳机点"动作诱发。

## 主要症状
突发的、电击样、刀割样或烧灼样剧烈疼痛，局限于一侧三叉神经分布区（眼支、上颌支、下颌支），每次持续数秒至一至两分钟，可突然停止，间歇期完全正常。疼痛剧烈时患者不敢洗脸、刷牙、进食，影响生活质量。

## 处理建议
确诊后首选药物治疗，常用卡马西平、奥卡西平等抗惊厥药物，需从小剂量开始，在医生指导下调整并监测不良反应。药物无效或无法耐受时，可考虑微血管减压术、球囊压迫、射频热凝等外科或介入治疗，由神经专科评估选择。日常生活中注意避免触碰扳机点，轻柔洗漱、温和进食。

## 就医提醒
面部剧痛不应自行长期服用止痛药，以免延误诊治。若疼痛持续不缓解、伴面部感觉减退、复视、听力下降或青年起病，应进一步检查排除继发性病因。用药期间如出现皮疹、头晕、白细胞减少等应及时复诊。

## 检查与诊断
三叉神经痛的确诊需要结合临床表现与辅助检查。常用检查包括：神经系统查体、头颅CT/MRI、脑电图、肌电图、脑脊液检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、避免过度劳累与熬夜，控制高血压、糖尿病、高血脂等基础病，保持心情舒畅，适量运动。

## 就医指引
如出现疑似三叉神经痛的相关症状，建议及时到神经内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对三叉神经痛相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
