# 面神经炎（面瘫）

面神经炎又称特发性面神经麻痹，俗称"面瘫"，是指面神经非特异性炎症导致的一侧面部表情肌群运动功能障碍，多为急性起病，多数患者预后良好。

## 病因
确切病因尚不明确，多认为与病毒感染（如单纯疱疹病毒）后的免疫反应、受凉、劳累、精神紧张等因素导致面神经水肿受压有关，常在数小时至数天内达到高峰。

## 主要症状
一侧额纹消失、不能皱眉，眼裂增大、眼睑闭合不全，鼻唇沟变浅，口角下垂并向对侧歪斜，鼓腮漏气，进食时食物易滞留于患侧齿颊间，可有流泪、味觉减退、耳后或耳内疼痛。注意闭眼不全时眼白外露。

## 处理建议
发病后应尽早到神经内科就诊，药物治疗以皮质类固醇抗炎为主，起效越早越好；部分患者加用抗病毒药物及神经营养药物。同时注意眼部保护，白天佩戴太阳镜、夜间用眼膏并遮盖，防止角膜炎。急性期后可配合针灸、面部肌肉按摩、主动功能锻炼等康复治疗，多数患者在数周至数月内恢复。

## 就医提醒
突发口眼歪斜并不都是面瘫，脑卒中也可表现为"中枢性面瘫"（仅下半面部受累、伴肢体无力或言语异常）。出现面瘫伴其他神经系统症状，或眼睑不能闭合、耳部疱疹疼痛明显者，应及时就医明确诊断。

## 检查与诊断
面神经炎（面瘫）的确诊需要结合临床表现与辅助检查。常用检查包括：神经系统查体、头颅CT/MRI、脑电图、肌电图、脑脊液检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、避免过度劳累与熬夜，控制高血压、糖尿病、高血脂等基础病，保持心情舒畅，适量运动。

## 就医指引
如出现疑似面神经炎（面瘫）的相关症状，建议及时到神经内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
