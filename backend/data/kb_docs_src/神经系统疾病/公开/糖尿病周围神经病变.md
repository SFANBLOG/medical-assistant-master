# 糖尿病周围神经病变

糖尿病周围神经病变是糖尿病最常见的慢性并发症之一，以对称性远端肢体麻木、疼痛、感觉异常为特征，是糖尿病患者足部溃疡和截肢的重要危险因素。

## 病因
长期高血糖引起神经纤维损伤和微血管病变、代谢紊乱（多元醇通路异常、氧化应激、炎症）等共同导致。病程长、血糖控制不佳、肥胖、高血压、血脂异常及吸烟均增加发病风险。

## 主要症状
典型表现为对称性"手套-袜套样"分布的感觉异常：肢体远端麻木、针刺感、蚁走感、烧灼样或电击样疼痛，夜间加重；可有痛觉过敏（轻触即痛）或感觉减退（踩棉花感、受伤而不自知）；部分患者伴下肢无力、足部肌肉萎缩、皮肤干燥脱屑，后期可出现足部畸形和溃疡。

## 处理建议
核心是严格控制血糖、血压、血脂，戒烟并规律运动，这是延缓神经病变进展的基础。症状明显者可在医生指导下使用神经营养修复药物、改善神经微循环药物及针对神经病理性疼痛的止痛药物。每日检查双脚有无破损、水疱、红肿，保持足部清洁干燥，穿合脚软底鞋，避免烫伤，修剪趾甲时防止剪伤皮肤。

## 就医提醒
出现肢体麻木、疼痛或足部损伤久不愈合，应及时到内分泌科或神经内科评估，进行神经传导速度等检查。糖尿病足高危者应定期专科随访；足部出现发黑、坏疽、感染扩散时须立即就医。
