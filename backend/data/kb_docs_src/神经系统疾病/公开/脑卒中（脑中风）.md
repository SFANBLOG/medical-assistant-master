# 脑卒中（脑中风）

脑卒中俗称"脑中风"，是指脑血管突然破裂出血或阻塞导致脑组织缺血坏死的急性脑血管疾病，分为缺血性脑卒中（脑梗死）和出血性脑卒中（脑出血）两大类，其中缺血性卒中约占七至八成。

## 病因
主要危险因素包括高血压、糖尿病、血脂异常、心房颤动等心脏疾病、动脉粥样硬化、吸烟、酗酒、肥胖及缺乏运动。长期血压控制不佳是脑出血和脑梗死共同的、最重要的可干预因素。

## 主要症状
突然出现的一侧面部、手臂或腿部无力或麻木，口角歪斜，言语含糊不清或听不懂他人说话，单眼或双眼视力模糊、视物成双，行走不稳、眩晕，或不明原因的剧烈头痛伴恶心呕吐、意识障碍。症状常在几分钟到几小时内达高峰。

## 处理建议
一旦怀疑卒中，应让患者平卧休息，保持呼吸道通畅，切勿喂水喂药，立即拨打急救电话。发病后的黄金救治时间窗很短，溶栓治疗通常要求在发病 4.5 小时内进行，越早到达医院，救治效果越好。日常预防重点是控制血压、血糖、血脂，规律服用抗血小板或抗凝等药物，戒烟限酒、低盐低脂饮食、适度运动。

## 就医提醒
出现上述任一卒中症状，务必第一时间就医，切勿等待症状自行缓解。既往有高血压、糖尿病、房颤等基础疾病者，一旦出现头晕、肢体麻木、言语异常等早期信号，也应尽快就诊评估。

## 检查与诊断
脑卒中（脑中风）的确诊需要结合临床表现与辅助检查。常用检查包括：神经系统查体、头颅CT/MRI、脑电图、肌电图、脑脊液检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、避免过度劳累与熬夜，控制高血压、糖尿病、高血脂等基础病，保持心情舒畅，适量运动。

## 就医指引
如出现疑似脑卒中（脑中风）的相关症状，建议及时到神经内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
