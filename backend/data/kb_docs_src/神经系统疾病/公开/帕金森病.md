# 帕金森病

帕金森病是一种常见的中老年神经系统退行性疾病，以静止性震颤、运动迟缓、肌强直和姿势平衡障碍为主要表现，由脑内黑质多巴胺能神经元变性缺失所致。

## 病因
确切病因尚不明确，一般认为与遗传易感、环境因素（如农药、重金属接触）、年龄老化及氧化应激等多因素共同作用有关。少数为家族性病例。

## 主要症状
典型表现包括：静止性震颤（手部"搓丸样"抖动，静止时明显，活动时减轻）、运动迟缓（动作变慢、起步困难、走路时上肢摆动减少）、肌强直（肢体僵硬、"铅管样"或"齿轮样"强直）、姿势步态异常（小碎步、转身困难、易跌倒）。非运动症状也常见，如嗅觉减退、便秘、睡眠障碍、抑郁、淡漠等。

## 处理建议
诊断明确后应在专科医生指导下长期规范用药，常用多巴胺替代药物及多巴胺受体激动剂等，用药需个体化、小剂量起步，不可自行增减。坚持康复锻炼（如太极、行走训练）有助于维持运动功能；注意防跌倒，居家环境做好防滑处理；合理安排饮食，保证营养，避免高蛋白食物与部分药物同服影响吸收。

## 就医提醒
出现手抖、动作变慢、走路不稳等症状应尽早就诊神经内科。若药物治疗效果下降、出现"开关现象"、异动症或明显幻觉、认知障碍等并发症，应及时复诊调整方案。

## 预防与日常保健
