# 卒中患者的康复护理

## 临床要点
卒中康复应尽早介入（病情稳定后 24-48 小时即可开始床旁康复），遵循"早、勤、个体化、多学科"原则，涵盖运动、语言、吞咽、认知、心理与社会参与等多个维度，目标是最大程度恢复功能、提高生活质量、预防并发症。

## 处理与观察重点
护理重点是体位管理与良肢位摆放，定时翻身预防压疮，进行关节被动活动与早期床上训练；吞咽障碍患者需评估后选择合适的食物性状与进食体位，必要时鼻饲，防止误吸；言语障碍者配合语言治疗师进行训练；心理护理关注卒中后抑郁与情绪变化。评估日常生活活动能力（如 Barthel 指数），制定分阶段康复计划，家属照护与出院后社区康复衔接同样重要。

## 注意事项
康复训练强度应循序渐进，监测血压、心率与疲劳程度，避免过度训练诱发跌倒与二次损伤；注意识别偏瘫侧肢体肿胀、肩手综合征、肩关节半脱位并予针对性处理；做好跌倒与误吸风险防范，正确使用辅助器具。康复是长期过程，应避免"重药物治疗、轻功能训练"，家属参与与心理支持对预后有重要影响。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）
