# 脑血管病的二级预防

## 临床要点
二级预防针对已发生脑卒中或短暂性脑缺血发作（TIA）的患者，目标是预防复发与降低死亡致残率。核心是病因管理与危险因素干预双管齐下，不同病因分型的防治策略不同。

## 处理与观察重点
抗血小板治疗是缺血性卒中的基础（阿司匹林、氯吡格雷等），心源性栓塞（尤其房颤）患者需评估抗凝治疗指征（新型口服抗凝药或华法林），并定期复查监测；强化降压、控制血糖血脂（他汀类）是重点，戒烟限酒、减重、规律运动、健康饮食同步进行。应完善病因检查（影像、心电监测、血管超声、血液检查）明确卒中分型，针对大动脉粥样硬化、小动脉闭塞、心源性栓塞等制定个体化二级预防方案。

## 注意事项
关注治疗依从性与药物不良反应（出血风险），定期随访监测血压、血脂、肾功能与出血事件；房颤患者的卒中风险评分指导抗凝决策。对症状性颈动脉严重狭窄者评估血运重建指征。二级预防需长期坚持，不可因症状稳定而自行停药。

## 检查与诊断
脑血管病的二级预防的确诊需要结合临床表现与辅助检查。常用检查包括：神经系统查体、头颅CT/MRI、脑电图、肌电图、脑脊液检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、避免过度劳累与熬夜，控制高血压、糖尿病、高血脂等基础病，保持心情舒畅，适量运动。

## 就医指引
如出现疑似脑血管病的二级预防的相关症状，建议及时到神经内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
