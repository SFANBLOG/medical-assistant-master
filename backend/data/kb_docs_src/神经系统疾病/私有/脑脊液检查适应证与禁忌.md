# 脑脊液检查适应证与禁忌

## 临床要点
腰椎穿刺留取脑脊液用于诊断中枢神经系统感染（脑膜炎、脑炎）、蛛网膜下腔出血（CT 阴性时）、免疫性中枢神经系统疾病（多发性硬化、自身免疫性脑炎）、脑膜癌病及部分代谢性疾病，并可测定颅内压。

## 处理与观察重点
术前核对适应证，评估有无禁忌；操作时测量初压与末压，注意患者体位、无菌操作与缓慢引流，避免过度放液。留取标本分装送常规、生化、病原学（细菌、真菌、结核、病毒）及细胞学检查。术后嘱患者平卧 4-6 小时，多饮水，观察有无头痛、出血、感染及神经根刺激等并发症，穿刺部位保持清洁干燥。

## 注意事项
明确禁忌包括颅内压显著升高伴占位效应、后颅窝占位（有脑疝风险）、穿刺部位感染、严重血小板减少或凝血功能障碍、正在使用抗凝药物等。高度怀疑颅内高压者应先完善头颅影像再决定穿刺时机。操作应尽量轻柔，避免反复穿刺；对躁动不能配合或存在脊柱畸形者应评估替代方案。脑脊液结果需结合临床与影像综合判读，细胞数与蛋白糖变化各有临床意义。

## 检查与诊断
脑脊液检查适应证与禁忌的确诊需要结合临床表现与辅助检查。常用检查包括：神经系统查体、头颅CT/MRI、脑电图、肌电图、脑脊液检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、避免过度劳累与熬夜，控制高血压、糖尿病、高血脂等基础病，保持心情舒畅，适量运动。

## 就医指引
如出现疑似脑脊液检查适应证与禁忌的相关症状，建议及时到神经内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对脑脊液检查适应证与禁忌相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
