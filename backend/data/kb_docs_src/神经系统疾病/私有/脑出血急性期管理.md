# 脑出血急性期管理

## 临床要点
脑出血病情凶险，急性期管理核心是稳定生命体征、控制血压与颅内压、防治再出血和并发症。常见病因包括高血压、脑血管畸形、动脉瘤、淀粉样血管病及抗凝药使用。应尽快行头颅 CT 明确出血部位、量与是否破入脑室，评估是否需要外科干预。

## 处理与观察重点
严密监测意识、瞳孔、肢体活动及生命体征，警惕脑疝与神经功能恶化。血压管理遵循个体化目标，避免急剧降压导致脑灌注不足；甘露醇等脱水降颅压药物仅在颅内压升高明显时按指征使用。血糖控制在合理范围，防治感染、深静脉血栓、压疮与应激性溃疡，维持水电解质平衡。病情平稳后应尽早开始康复评估与早期康复干预。

## 注意事项
怀疑动脉瘤或血管畸形破裂者应尽快行血管影像检查以明确病因。抗凝相关脑出血需按相关指南处理并逆转抗凝作用；急性期应避免剧烈搬动、保持呼吸道通畅。需动态复查 CT，结合影像与临床决定保守或手术治疗，并与家属充分沟通预后。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
脑出血急性期管理的确诊需要结合临床表现与辅助检查。常用检查包括：神经系统查体、头颅CT/MRI、脑电图、肌电图、脑脊液检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、避免过度劳累与熬夜，控制高血压、糖尿病、高血脂等基础病，保持心情舒畅，适量运动。

## 就医指引
如出现疑似脑出血急性期管理的相关症状，建议及时到神经内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
