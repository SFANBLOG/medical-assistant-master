# 神经重症监护要点

## 临床要点
神经重症患者（重症卒中、重型颅脑损伤、颅内感染、癫痫持续状态、重症肌无力危象等）监护核心是防治继发性脑损伤，维持脑灌注与氧供，动态评估神经功能。

## 处理与观察重点
密切监测意识水平（GCS 评分）、瞳孔、肌力、生命体征及神经功能恶化的早期征象；保持气道通畅、合理氧疗与通气管理，避免低氧与二氧化碳潴留；循环管理中维持适度血压以保障脑灌注压，监测并处理颅内压升高（体位、镇痛镇静、渗透性脱水、必要时手术减压等）；控制体温、血糖，防治感染、深静脉血栓、压疮、应激性溃疡与营养不良。重症肌无力危象者重点监测呼吸肌力与通气功能，必要时机械通气并警惕肌无力危象诱因。

## 注意事项
多学科协作，动态复查影像与检验，及时识别"颅内压升高三联征"（意识下降、瞳孔改变、生命体征异常）及脑疝征象；镇痛镇静药物应尽量选择对神经系统影响小者，并定期行神经系统唤醒评估。家属沟通应充分、持续，告知预后不确定性。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
神经重症监护要点的确诊需要结合临床表现与辅助检查。常用检查包括：神经系统查体、头颅CT/MRI、脑电图、肌电图、脑脊液检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、避免过度劳累与熬夜，控制高血压、糖尿病、高血脂等基础病，保持心情舒畅，适量运动。

## 就医指引
如出现疑似神经重症监护要点的相关症状，建议及时到神经内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
