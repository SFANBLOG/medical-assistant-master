# 肌电图检查结果解读

## 临床要点
肌电图包括神经传导速度（NCV）与针极肌电图，用于评估周围神经、神经肌肉接头和肌肉疾病，协助鉴别神经源性与肌源性损害、确定神经病变的分布与类型（轴索型还是脱髓鞘型）。

## 处理与观察重点
解读需结合临床：运动与感觉神经传导速度减慢、末端潜伏期延长、波形离散提示脱髓鞘病变（如吉兰-巴雷综合征、慢性炎性脱髓鞘性多神经病）；复合肌肉动作电位波幅降低提示轴索损害（如糖尿病周围神经病变）。针极肌电图见自发电位（纤颤波、正锐波）与募集相改变提示失神经；重复神经电刺激波幅递减提示重症肌无力、递增提示肉毒中毒或肌无力综合征。结果应结合受累分布（对称、不对称、远端、节段性）判断病变水平。

## 注意事项
检查结果受温度、年龄、身高影响，需在温暖环境进行并校正参考值；重症肌无力患者应停用胆碱酯酶抑制剂一定时间后再做重复电刺激，以免假阴性；有出血倾向、体内植入起搏器或正在抗凝者慎做针极肌电图。肌电图正常不能完全排除轻微神经肌肉疾病，需结合临床与病理综合判断，与神经超声、影像互补。
