# 帕金森病药物调整原则

## 临床要点
帕金森病治疗以药物为主，原则为个体化、小剂量起始、缓慢滴定、症状控制与不良反应平衡，长期管理应兼顾运动与非运动症状。常用药物包括左旋多巴类、多巴胺受体激动剂、单胺氧化酶 B 抑制剂、儿茶酚-氧位-甲基转移酶抑制剂及抗胆碱能药等，依据患者年龄、病程、症状与职业需求选择。

## 处理与观察重点
调整药物时需评估运动症状（震颤、强直、运动迟缓、异动症）与非运动症状（体位性低血压、便秘、睡眠障碍、精神症状），警惕"开-关"现象、剂末现象、异动症等运动并发症。左旋多巴宜在餐前服用以避免与蛋白质竞争转运；更换或增减药物应循序渐进，单次仅调整一个环节，密切观察疗效与不良反应。

## 注意事项
多巴胺受体激动剂可致嗜睡、冲动控制障碍，需提前告知；老年患者慎用抗胆碱能药以防认知损害；体位性低血压、恶心等不良反应可通过调整服药时间、饮食等措施改善。不可骤然停药以免发生恶性综合征。出现明显幻觉、认知障碍或难治性运动波动时，应及时评估并考虑药物方案调整或手术治疗指征。
