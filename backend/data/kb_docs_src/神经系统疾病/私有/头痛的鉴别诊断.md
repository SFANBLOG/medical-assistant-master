# 头痛的鉴别诊断

## 临床要点
头痛分为原发性头痛（偏头痛、紧张型头痛、丛集性头痛）与继发性头痛（颅内感染、脑血管病、颅内占位、颞动脉炎、药物过度使用性头痛等）。鉴别重点是识别提示严重疾病的"红旗征象"。

## 处理与观察重点
问诊关注起病方式（突发"雷击样"头痛提示蛛网膜下腔出血可能）、头痛性质、部位、持续时间、伴随症状（发热、呕吐、神经系统体征、视乳头水肿）、诱因与缓解因素、年龄及既往史。查体需完成完整的神经系统检查与眼底检查；对突发剧烈头痛、伴局灶体征、发热、意识障碍或免疫抑制、肿瘤、妊娠等特殊人群，应及时行头颅影像学检查，必要时腰穿查脑脊液。

## 注意事项
对首次剧烈头痛、进行性加重、晨起头痛伴呕吐、头痛性质较以往明显改变或慢性头痛患者，均应警惕继发性病因，勿轻易按偏头痛处理。注意药物过度使用性头痛（每月止痛药使用频繁导致头痛迁延）的识别与宣教；丛集性头痛多有明显的周期性与昼夜节律，治疗与偏头痛不同，需正确区分。

## 检查与诊断
头痛的鉴别诊断的确诊需要结合临床表现与辅助检查。常用检查包括：神经系统查体、头颅CT/MRI、脑电图、肌电图、脑脊液检查等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
规律作息、避免过度劳累与熬夜，控制高血压、糖尿病、高血脂等基础病，保持心情舒畅，适量运动。

## 就医指引
如出现疑似头痛的鉴别诊断的相关症状，建议及时到神经内科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对头痛的鉴别诊断相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
