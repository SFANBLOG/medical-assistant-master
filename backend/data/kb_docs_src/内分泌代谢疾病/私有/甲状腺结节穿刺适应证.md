# 甲状腺结节穿刺适应证

## 临床要点
- 依据超声风险分层（如TI-RADS分级）决定是否需要细针穿刺活检。
- 直径≥1cm的中高危结节，或直径较大、伴可疑超声特征（低回声、边缘不规则、微钙化、纵横比大于1）者应考虑穿刺。
- 直径≥1.5-2cm、超声特征不明确的低危结节，可结合临床决定是否穿刺。

## 处理与观察重点
- 穿刺前评估凝血功能，必要时停用抗凝药物。
- 应在超声引导下操作，取材部位准确，保证细胞学标本质量。
- 结果按细胞学报告系统分类，结合超声特征和临床风险制定后续方案。

## 注意事项
- 注意操作并发症，如出血、血肿、穿刺部位疼痛及罕见的喉返神经损伤。
- 细胞学意义不明确的结节，需结合超声和临床决定观察或手术。
- 良性结果仍需定期超声随访，若结节持续增大或特征变化应重新评估。

## 检查与诊断
甲状腺结节穿刺适应证的确诊需要结合临床表现与辅助检查。常用检查包括：血糖、糖化血红蛋白、甲状腺功能、血脂、尿酸、骨密度、相关激素水平及功能试验等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
均衡饮食、控制总热量、规律运动、保持健康体重，定期体检监测血糖、血脂、尿酸等指标。

## 就医指引
如出现疑似甲状腺结节穿刺适应证的相关症状，建议及时到内分泌科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对甲状腺结节穿刺适应证相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
