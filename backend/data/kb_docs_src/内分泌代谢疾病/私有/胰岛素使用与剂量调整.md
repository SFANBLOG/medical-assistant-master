# 胰岛素使用与剂量调整

## 临床要点
- 胰岛素适用于1型糖尿病、口服降糖药控制不佳的2型糖尿病、糖尿病急性并发症、围手术期及妊娠期等。
- 常用方案包括基础胰岛素联合餐时胰岛素，需根据血糖谱制定个体化剂量。

## 处理与观察重点
- 调整剂量遵循小步原则，依据空腹血糖调整基础胰岛素、依据餐后血糖调整餐时胰岛素。
- 详细记录饮食、运动与血糖变化，评估剂量与生活方式是否匹配。
- 规范注射技术，注意注射部位轮换，避免皮下脂肪增生。

## 注意事项
- 高度警惕低血糖，尤其是夜间低血糖；教育患者识别早期症状并随身携带糖类食物。
- 胰岛素应规范储存在适宜温度下，注意有效期，避免失效。
- 剂量调整需结合饮食与运动，避免剂量骤变；发生急性疾病时不可擅自停用胰岛素。

## 检查与诊断
胰岛素使用与剂量调整的确诊需要结合临床表现与辅助检查。常用检查包括：血糖、糖化血红蛋白、甲状腺功能、血脂、尿酸、骨密度、相关激素水平及功能试验等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
均衡饮食、控制总热量、规律运动、保持健康体重，定期体检监测血糖、血脂、尿酸等指标。

## 就医指引
如出现疑似胰岛素使用与剂量调整的相关症状，建议及时到内分泌科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对胰岛素使用与剂量调整相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
