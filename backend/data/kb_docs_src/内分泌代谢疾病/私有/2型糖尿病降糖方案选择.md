# 2型糖尿病降糖方案选择

## 临床要点
- 所有患者均应以生活方式干预为基础，贯穿治疗全程。
- 二甲双胍通常作为首选口服药；血糖控制不佳时需及时联合治疗。
- 药物选择应个体化，综合考虑糖化血红蛋白水平、体重、低血糖风险及合并症，如合并动脉粥样硬化性心血管疾病或慢性肾脏病者优先选用SGLT2抑制剂或GLP-1受体激动剂类。

## 处理与观察重点
- 起始和调整用药后应监测空腹及餐后血糖谱，每3个月复查糖化血红蛋白评估疗效。
- 关注肾功能、肝功能、体重变化及药物不良反应。
- 联合磺脲类或胰岛素促泌剂时警惕低血糖风险，需加强血糖监测。

## 注意事项
- 避免降糖过强导致低血糖和体重增加。
- 老年人、肾功能不全者慎用经肾排泄的促泌剂，并注意剂量调整。
- 出现感染、手术、急性并发症等应激情况时，及时评估并改用胰岛素治疗。

## 检查与诊断
2型糖尿病降糖方案选择的确诊需要结合临床表现与辅助检查。常用检查包括：血糖、糖化血红蛋白、甲状腺功能、血脂、尿酸、骨密度、相关激素水平及功能试验等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
均衡饮食、控制总热量、规律运动、保持健康体重，定期体检监测血糖、血脂、尿酸等指标。

## 就医指引
如出现疑似2型糖尿病降糖方案选择的相关症状，建议及时到内分泌科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对2型糖尿病降糖方案选择相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
