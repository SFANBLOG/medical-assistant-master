# 痛风急性发作期治疗

## 临床要点
- 急性发作时应尽早（最好在24小时内）开始抗炎治疗，越早用药疗效越好。
- 治疗药物包括秋水仙碱、非甾体抗炎药，病情严重或上述药物禁忌时可短期使用糖皮质激素。
- 受累关节应制动、抬高，局部冷敷，不宜热敷。

## 处理与观察重点
- 密切观察关节红肿热痛的缓解情况和药物不良反应。
- 评估是否启动或调整降尿酸治疗：急性期一般不开始降尿酸治疗，已规律使用者则不宜中断。
- 监测血尿酸及肝肾功能，指导后续缓解期的降尿酸方案。

## 注意事项
- 秋水仙碱注意胃肠道反应，需按规定剂量使用并警惕毒性。
- 肾功能不全、消化道溃疡患者慎用非甾体抗炎药。
- 避免在急性期过度快速改变血尿酸水平，以免加重或延长发作。

## 检查与诊断
痛风急性发作期治疗的确诊需要结合临床表现与辅助检查。常用检查包括：血糖、糖化血红蛋白、甲状腺功能、血脂、尿酸、骨密度、相关激素水平及功能试验等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
均衡饮食、控制总热量、规律运动、保持健康体重，定期体检监测血糖、血脂、尿酸等指标。

## 就医指引
如出现疑似痛风急性发作期治疗的相关症状，建议及时到内分泌科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对痛风急性发作期治疗相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
