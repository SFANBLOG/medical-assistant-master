# 内分泌功能试验规范

## 临床要点
- 常见试验包括口服葡萄糖耐量试验（OGTT）、地塞米松抑制试验、促肾上腺皮质激素（ACTH）兴奋试验、生长激素抑制试验及甲状腺相关动态试验等。
- 试验前需按规范停用可能影响结果的药物，并告知患者注意事项。

## 处理与观察重点
- 严格按规定时间点留取血、尿标本，记录采血时间与特殊情况。
- 关注应激、饮食、睡眠、运动等因素对激素水平及试验结果的干扰。
- 掌握各试验的判读标准，识别假阳性与假阴性情况。

## 注意事项
- 部分试验（如胰岛素低血糖试验、OGTT）可能诱发低血糖，需备好糖源并加强监护。
- 疑有肾上腺皮质功能不全者慎用激发试验，以免诱发危象。
- 试验结果应结合临床表现综合判断，必要时重复试验或行影像学定位。
