# 妊娠期糖尿病的管理

## 临床要点
- 通常在孕24-28周行口服葡萄糖耐量试验（OGTT）进行筛查与诊断。
- 妊娠期血糖控制目标是空腹及餐后血糖均达标，以减少母儿不良结局。
- 治疗首选医学营养治疗与适度运动，血糖不达标时需启用胰岛素治疗。

## 处理与观察重点
- 指导合理饮食结构，保证足够能量摄入的同时控制餐后血糖。
- 规律监测血糖、体重增长、血压及尿酮体，评估治疗效果。
- 关注胎儿生长发育，按产检规范进行超声监测与胎心监护。

## 注意事项
- 口服降糖药物在妊娠期的使用存在争议，应由专科医师充分评估后决定。
- 避免过度限制热量引起饥饿性酮症，注意血糖过低与过高的风险。
- 产后6-12周复查糖代谢状况，并对远期发生2型糖尿病的风险进行健康宣教。

## 检查与诊断
妊娠期糖尿病的管理的确诊需要结合临床表现与辅助检查。常用检查包括：血糖、糖化血红蛋白、甲状腺功能、血脂、尿酸、骨密度、相关激素水平及功能试验等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
均衡饮食、控制总热量、规律运动、保持健康体重，定期体检监测血糖、血脂、尿酸等指标。

## 就医指引
如出现疑似妊娠期糖尿病的管理的相关症状，建议及时到内分泌科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对妊娠期糖尿病的管理相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
