# 痛风与高尿酸血症

高尿酸血症是血尿酸水平升高的代谢异常，长期高尿酸血症可使尿酸盐结晶沉积于关节、软组织及肾脏，引发痛风发作和肾损害。

## 病因
主要与嘌呤代谢紊乱导致尿酸生成过多和（或）肾脏排泄减少有关。诱因包括高嘌呤饮食（动物内脏、海鲜、浓肉汤）、饮酒（尤其啤酒）、含果糖饮料、肥胖、遗传因素，以及某些药物如利尿剂等。

## 主要症状
- 痛风急性发作：常在夜间突发单个关节（以足大趾最常见）红肿、灼热、剧痛，数日内可自行缓解。
- 反复发作可形成皮下痛风石，并可累及踝、膝、腕等关节。
- 尿酸盐沉积于肾脏可引起肾结石、血尿、腰痛，长期可致肾功能损害。

## 处理建议
- 急性发作期减少活动、抬高患肢、局部冷敷，按医嘱使用抗炎止痛药物。
- 缓解期在医生指导下进行降尿酸治疗，并长期随访血尿酸。
- 日常多饮水（每日2000毫升以上）、限制高嘌呤食物和酒精、控制体重、规律运动。

## 就医提醒
关节剧痛持续不缓解、伴发热，或出现腰部绞痛、血尿、少尿等肾脏表现时，应及时就医。

## 检查与诊断
痛风与高尿酸血症的确诊需要结合临床表现与辅助检查。常用检查包括：血糖、糖化血红蛋白、甲状腺功能、血脂、尿酸、骨密度、相关激素水平及功能试验等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
均衡饮食、控制总热量、规律运动、保持健康体重，定期体检监测血糖、血脂、尿酸等指标。

## 就医指引
如出现疑似痛风与高尿酸血症的相关症状，建议及时到内分泌科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对痛风与高尿酸血症相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
