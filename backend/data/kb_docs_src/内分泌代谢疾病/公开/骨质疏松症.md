# 骨质疏松症

骨质疏松症是以骨量减少、骨组织微结构破坏、骨脆性增加和易发生骨折为特征的全身性骨骼疾病。

## 病因
与增龄、绝经后雌激素水平下降、钙和维生素D摄入不足、缺乏运动、吸烟酗酒等有关；也可见于长期使用糖皮质激素、甲状腺功能亢进等继发性原因。

## 主要症状
- 早期多无明显症状，常在发生骨折或体检时发现。
- 可出现腰背酸痛、乏力、身高变矮、驼背。
- 轻微外力甚至日常活动即可发生骨折，常见于椎体、髋部、桡骨远端。

## 处理建议
- 保证充足钙和维生素D摄入，多食奶制品、豆制品、绿叶蔬菜，适当晒太阳。
- 坚持负重运动和肌肉力量训练，避免跌倒。
- 已确诊者遵医嘱使用抗骨质疏松药物，并定期复查骨密度。

## 就医提醒
中老年人群出现无明显外伤的骨痛、身高明显缩短、驼背，或轻微碰撞即骨折，应尽早行骨密度检查并在医生指导下治疗。

## 检查与诊断
骨质疏松症的确诊需要结合临床表现与辅助检查。常用检查包括：血糖、糖化血红蛋白、甲状腺功能、血脂、尿酸、骨密度、相关激素水平及功能试验等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
均衡饮食、控制总热量、规律运动、保持健康体重，定期体检监测血糖、血脂、尿酸等指标。

## 就医指引
如出现疑似骨质疏松症的相关症状，建议及时到内分泌科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对骨质疏松症相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
