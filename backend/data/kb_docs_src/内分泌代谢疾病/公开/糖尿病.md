# 糖尿病

糖尿病是一组以慢性高血糖为特征的代谢性疾病，因胰岛素分泌缺陷和（或）胰岛素作用障碍引起糖、脂肪、蛋白质代谢紊乱。

## 病因
1型糖尿病由自身免疫破坏胰岛β细胞所致，需终身依赖胰岛素；2型糖尿病与遗传、超重或肥胖、久坐少动、高热量饮食等引起的胰岛素抵抗和分泌不足有关；妊娠期糖尿病发生于孕期，此外还有继发于胰腺疾病或药物的特殊类型。

## 主要症状
- 典型症状：多饮、多尿、多食、体重下降，即“三多一少”。
- 其他表现：乏力、视物模糊、皮肤瘙痒、伤口愈合缓慢、反复感染。
- 相当一部分2型糖尿病患者早期无明显症状，仅在体检时发现血糖升高。

## 处理建议
- 坚持健康生活方式：均衡饮食、控制总热量、规律运动、戒烟限酒。
- 遵医嘱使用降糖药物或胰岛素，不自行停药或调整剂量。
- 定期监测血糖，每3个月左右复查糖化血红蛋白，并筛查眼底、肾脏、足部等并发症。

## 就医提醒
出现恶心、呕吐、腹痛、呼吸深快，或血糖明显升高并伴意识改变时，可能提示糖尿病酮症酸中毒等急性并发症，应立即就医。

## 检查与诊断
糖尿病的确诊需要结合临床表现与辅助检查。常用检查包括：血糖、糖化血红蛋白、甲状腺功能、血脂、尿酸、骨密度、相关激素水平及功能试验等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
均衡饮食、控制总热量、规律运动、保持健康体重，定期体检监测血糖、血脂、尿酸等指标。

## 就医指引
如出现疑似糖尿病的相关症状，建议及时到内分泌科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对糖尿病相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
