# 肥胖症

肥胖症是一种因能量摄入长期超过消耗，导致体内脂肪过度堆积和（或）分布异常的慢性代谢性疾病。

## 病因
由遗传、环境与行为因素共同作用所致，包括高热量高脂肪饮食、久坐少动、作息紊乱、心理压力等；少数与甲状腺功能减退、皮质醇增多等内分泌疾病及某些药物有关。

## 主要症状
- 体重和体质指数（BMI）明显超标，腰围增粗。
- 可伴乏力、活动后气喘、关节疼痛、出汗增多。
- 常合并糖尿病、高血压、血脂异常、脂肪肝、睡眠呼吸暂停等代谢相关疾病。

## 处理建议
- 以合理膳食和规律运动为核心的医学营养治疗与行为干预是基础。
- 设定科学减重目标，避免过度节食和快速减重，防止反弹。
- 经评估必要时，可在医生指导下使用减重药物或接受代谢减重手术。

## 就医提醒
明显超重或肥胖并伴糖尿病、高血压、睡眠呼吸暂停、月经紊乱等症状者，建议至内分泌科或营养科进行系统评估和个体化管理。

## 检查与诊断
肥胖症的确诊需要结合临床表现与辅助检查。常用检查包括：血糖、糖化血红蛋白、甲状腺功能、血脂、尿酸、骨密度、相关激素水平及功能试验等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
均衡饮食、控制总热量、规律运动、保持健康体重，定期体检监测血糖、血脂、尿酸等指标。

## 就医指引
如出现疑似肥胖症的相关症状，建议及时到内分泌科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对肥胖症相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
