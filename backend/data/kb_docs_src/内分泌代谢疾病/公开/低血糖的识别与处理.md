# 低血糖的识别与处理

低血糖是指血糖浓度低于正常水平（通常指血糖低于3.9mmol/L）并出现相应症状，多见于接受降糖治疗的人群。

## 病因
最常见于糖尿病患者因进食延迟或不足、降糖药物或胰岛素过量、运动量突然增加、饮酒等引起；也可见于长时间饥饿、肝功能异常、胰岛素瘤等非糖尿病情况。

## 主要症状
- 交感神经兴奋表现：心慌、手抖、出汗、饥饿感、面色苍白。
- 中枢神经低血糖表现：头晕、乏力、注意力不集中、视物模糊。
- 严重时出现意识模糊、行为异常、抽搐甚至昏迷。

## 处理建议
- 意识清醒者立即进食约15克含糖食物，如糖水、糖果、果汁、蜂蜜，15分钟后复测血糖。
- 若血糖仍低于正常或症状未缓解，可再进食一次。
- 症状缓解后适量进食主食，防止再次发生；意识不清者切勿强行喂食，应立即呼叫急救。

## 就医提醒
反复发生低血糖、夜间低血糖或出现过严重意识障碍者，应尽早就医调整治疗方案并查明原因。
