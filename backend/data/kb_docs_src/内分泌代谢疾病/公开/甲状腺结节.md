# 甲状腺结节

甲状腺结节是甲状腺内出现的一个或多个结构异常的团块，可通过触诊或超声发现，绝大多数为良性。

## 病因
与碘摄入不当、自身免疫性甲状腺疾病、遗传因素、放射性暴露有关。常见类型包括增生性结节、甲状腺囊肿、甲状腺炎性结节、良性腺瘤，少数为甲状腺癌。

## 主要症状
- 多数结节无明显症状，多在体检或超声检查时偶然发现。
- 结节较大时可出现颈部压迫感、吞咽不适、异物感。
- 若结节压迫喉返神经可引起声音嘶哑，或伴颈部淋巴结肿大。

## 处理建议
- 良性结节通常定期超声随访即可，无需特殊处理。
- 根据结节大小、超声特征和危险分层，必要时行细针穿刺细胞学检查。
- 可疑恶性或已确诊恶性者，由专科医生评估手术等治疗方案。

## 就医提醒
结节短期内迅速增大、质地硬、固定、活动度差，或出现声音嘶哑、吞咽困难、呼吸不畅、颈部淋巴结肿大时，应及时就医。

## 检查与诊断
甲状腺结节的确诊需要结合临床表现与辅助检查。常用检查包括：血糖、糖化血红蛋白、甲状腺功能、血脂、尿酸、骨密度、相关激素水平及功能试验等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
均衡饮食、控制总热量、规律运动、保持健康体重，定期体检监测血糖、血脂、尿酸等指标。

## 就医指引
如出现疑似甲状腺结节的相关症状，建议及时到内分泌科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对甲状腺结节相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
