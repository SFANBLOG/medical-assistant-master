# 甲状腺功能亢进症

甲状腺功能亢进症简称甲亢，是甲状腺合成和分泌过多甲状腺激素，导致机体代谢亢进和交感神经兴奋的一组临床综合征。

## 病因
最常见的是毒性弥漫性甲状腺肿（Graves病），为自身免疫性疾病；其他原因包括毒性多结节性甲状腺肿、甲状腺自主高功能腺瘤、亚急性甲状腺炎的一过性甲状腺毒症，以及过量服用甲状腺激素等。

## 主要症状
- 怕热多汗、皮肤潮湿、多食易饥但体重下降。
- 心悸、心动过速、手抖、急躁易怒、失眠、注意力不集中。
- 大便次数增多、月经紊乱；Graves病可伴突眼、胫前黏液性水肿。

## 处理建议
- 遵医嘱使用抗甲状腺药物（如甲巯咪唑、丙硫氧嘧啶），不随意停药。
- 采用低碘饮食，避免海带、紫菜等富碘食物和含碘造影剂。
- 注意休息、避免劳累和精神紧张；心率明显加快者按医嘱加用控制心率的药物。

## 就医提醒
若出现高热、大汗、心率显著增快、烦躁不安、恶心呕吐、腹泻甚至意识模糊，应警惕甲状腺危象，须立即急诊就医。

## 检查与诊断
甲状腺功能亢进症的确诊需要结合临床表现与辅助检查。常用检查包括：血糖、糖化血红蛋白、甲状腺功能、血脂、尿酸、骨密度、相关激素水平及功能试验等。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
均衡饮食、控制总热量、规律运动、保持健康体重，定期体检监测血糖、血脂、尿酸等指标。

## 就医指引
如出现疑似甲状腺功能亢进症的相关症状，建议及时到内分泌科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
