# 儿童生长发育评估

儿童生长发育评估是通过连续测量和观察，评价儿童体格、神经心理及行为发育状况，是早期发现发育异常的重要方法。

## 临床要点
- 评估维度：体格生长（身高、体重、头围）、神经心理发育（大运动、精细动作、语言、社会适应）及青春期发育。
- 常用工具：生长曲线图（参考标准）、发育筛查量表及专科评估量表。

## 处理与观察重点
- 按年龄定期测量并绘制生长曲线，动态评估生长速度与体型匀称度。
- 关注发育里程碑：如 3 个月抬头、6 个月独坐、12 个月独走、2 岁说简单句子等，发现落后及时复评。
- 对生长迟缓、营养不良、肥胖、发育迟缓者查找原因（喂养、内分泌、遗传等），转诊专科并制定干预方案。

## 注意事项
- 测量应规范、工具统一，纵向连续评估比单次测量更有价值。
- 结合遗传因素（父母身高）、出生体重及疾病史综合判断，避免过度诊断。
- 重视家长主诉与家庭环境因素，做好健康教育与随访管理。

## 检查与诊断
儿童生长发育评估的确诊需要结合临床表现与辅助检查。常用检查包括：儿科/妇产科专科查体、血常规等基础检查，必要时按专科指南进一步检查。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
科学喂养、按时接种疫苗、注意手卫生与居家通风，孕期定期产检，儿童发热等症状持续不缓解及时就医。

## 就医指引
如出现疑似儿童生长发育评估的相关症状，建议及时到儿科、妇产科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对儿童生长发育评估相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
