# 妇科炎症的规范治疗

妇科炎症包括外阴阴道炎、宫颈炎、盆腔炎性疾病等，规范化诊疗应以病原学为依据，避免经验性滥用药物与反复发作。

## 临床要点
- 常见类型：细菌性阴道病、外阴阴道假丝酵母菌病、滴虫性阴道炎、支原体衣原体感染、盆腔炎性疾病。
- 诊断应结合病史、妇科检查、白带常规及病原学培养或核酸检测，明确致病菌及药敏。

## 处理与观察重点
- 根据病原体选择敏感药物，注意局部用药与全身用药的合理选择，足量足疗程治疗。
- 对性传播相关病原体感染（如滴虫、衣原体）应性伴侣同治，治疗期间避免性生活。
- 盆腔炎性疾病需评估严重程度，必要时住院给予静脉抗感染治疗，警惕脓肿形成。
- 随访复查评估疗效，防止复发与并发症（如盆腔粘连、不孕）。

## 注意事项
- 避免盲目长期使用广谱抗菌药物及含激素类阴道制剂，防止菌群失调。
- 指导注意外阴清洁、合理选择内衣物，避免不必要阴道冲洗。
- 对反复发作者全面评估血糖、免疫状态及伴侣情况，进行综合管理。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
妇科炎症的规范治疗的确诊需要结合临床表现与辅助检查。常用检查包括：儿科/妇产科专科查体、血常规等基础检查，必要时按专科指南进一步检查。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
科学喂养、按时接种疫苗、注意手卫生与居家通风，孕期定期产检，儿童发热等症状持续不缓解及时就医。

## 就医指引
如出现疑似妇科炎症的规范治疗的相关症状，建议及时到儿科、妇产科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
