# 高危妊娠的识别

高危妊娠指妊娠期存在危及孕产妇及胎儿健康风险的妊娠，早期识别和分层管理是降低母婴不良结局的关键。

## 临床要点
- 母体因素：高龄（≥35 岁）、未成年、慢性疾病（高血压、糖尿病、心脏病、肾病）、多次流产史、既往妊娠并发症史。
- 胎儿因素：多胎、胎儿生长受限、羊水异常、胎儿畸形、染色体异常风险。
- 妊娠期新发疾病：妊娠期高血压疾病、妊娠期糖尿病、前置胎盘、胎盘早剥等。

## 处理与观察重点
- 建立高危妊娠档案，制定个性化产检计划，适当增加产检频次。
- 动态评估妊娠风险分级，组织产科、内科、营养科等多学科协作管理。
- 监测母体生命体征、胎儿宫内状况（胎动、胎心监护、超声），及时处理异常。

## 注意事项
- 重视健康教育，指导孕妇识别异常征象并及时就诊。
- 对极高危孕妇建议在有救治条件的医疗机构分娩。
- 做好病情记录与转诊衔接，避免漏诊延误。

## 检查与诊断
高危妊娠的识别的确诊需要结合临床表现与辅助检查。常用检查包括：儿科/妇产科专科查体、血常规等基础检查，必要时按专科指南进一步检查。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
科学喂养、按时接种疫苗、注意手卫生与居家通风，孕期定期产检，儿童发热等症状持续不缓解及时就医。

## 就医指引
如出现疑似高危妊娠的识别的相关症状，建议及时到儿科、妇产科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对高危妊娠的识别相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
