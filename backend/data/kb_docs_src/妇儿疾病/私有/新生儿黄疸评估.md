# 新生儿黄疸评估

新生儿黄疸是新生儿期最常见的临床问题之一，多数为生理性，但需及时识别病理性黄疸，防止胆红素脑病等严重并发症。

## 临床要点
- 生理性黄疸：足月儿多于生后 2-3 天出现，4-5 天达高峰，一般 2 周内消退，血清胆红素在正常范围。
- 病理性黄疸警示：出现过早（24 小时内）、程度重、进展快、持续时间长、直接胆红素升高或伴贫血、大便颜色异常等。
- 病因包括溶血（ABO、Rh 血型不合）、感染、母乳相关、肝胆疾病、代谢异常等。

## 处理与观察重点
- 动态监测经皮胆红素并结合日龄评估，必要时查血清胆红素及血型、溶血相关检查。
- 观察皮肤黄染程度、范围及进展速度，评估精神、吃奶、大小便情况。
- 符合光疗指征者及时行蓝光治疗，严重溶血或高胆红素血症考虑换血疗法，同时处理原发病。

## 注意事项
- 慎用可能导致胆红素升高的药物，避免饥饿、低体温、缺氧等加重因素。
- 对早产儿、低出生体重儿及合并高危因素者提高警惕。
- 出院后随访黄疸消退情况，指导家长观察并及时复诊。

新生儿黄疸评估的确诊需要结合临床表现与辅助检查。常用检查包括：儿科/妇产科专科查体、血常规等基础检查，必要时按专科指南进一步检查。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
科学喂养、按时接种疫苗、注意手卫生与居家通风，孕期定期产检，儿童发热等症状持续不缓解及时就医。

## 就医指引
如出现疑似新生儿黄疸评估的相关症状，建议及时到儿科、妇产科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
