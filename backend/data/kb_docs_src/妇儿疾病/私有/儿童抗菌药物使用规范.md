# 儿童抗菌药物使用规范

合理使用抗菌药物是儿童感染性疾病治疗的关键，应严格掌握适应证，防止滥用导致的耐药、不良反应及肠道菌群紊乱。

## 临床要点
- 明确细菌感染证据或高度怀疑细菌感染时方可使用；病毒感染（如普通感冒、多数上呼吸道感染）不应常规使用抗菌药物。
- 根据感染部位、病原学结果、药敏及儿童年龄、体重、肝肾功能选择药物与剂量。
- 常见病原菌如肺炎链球菌、流感嗜血杆菌、金黄色葡萄球菌等，注意地区耐药情况。

## 处理与观察重点
- 用药前尽可能留取病原学标本，使用后 48-72 小时评估疗效，及时调整方案。
- 观察过敏反应（皮疹、喉头水肿等）、胃肠道反应及二重感染（如鹅口疮、抗生素相关性腹泻）。
- 严格按疗程用药，避免频繁更换、随意停药或联用不必要的抗菌药物。

## 注意事项
- 儿童禁用或慎用部分抗菌药物（如喹诺酮类、四环素类需谨慎，氨基糖苷类注意耳肾毒性）。
- 避免无指征情况下预防性使用抗菌药物。
- 加强家长教育，纠正自行购药、随意加减剂量等不良行为。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
儿童抗菌药物使用规范的确诊需要结合临床表现与辅助检查。常用检查包括：儿科/妇产科专科查体、血常规等基础检查，必要时按专科指南进一步检查。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
科学喂养、按时接种疫苗、注意手卫生与居家通风，孕期定期产检，儿童发热等症状持续不缓解及时就医。

## 就医指引
如出现疑似儿童抗菌药物使用规范的相关症状，建议及时到儿科、妇产科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
