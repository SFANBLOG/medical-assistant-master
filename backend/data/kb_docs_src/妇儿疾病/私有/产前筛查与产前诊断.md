# 产前筛查与产前诊断

产前筛查与产前诊断是出生缺陷三级预防的重要环节，旨在及早发现胎儿结构异常与染色体异常，为遗传咨询和妊娠管理提供依据。

## 临床要点
- 产前筛查：血清学筛查、无创产前检测（NIPT）及超声软指标筛查，针对常见染色体异常（唐氏综合征、爱德华兹综合征等）及神经管缺陷。
- 产前诊断：绒毛穿刺、羊膜腔穿刺、脐血穿刺及超声产前诊断，适用于高龄、筛查高风险、超声结构异常、家族遗传病史等高危人群。

## 处理与观察重点
- 严格把握筛查与诊断的适应证和时机，向孕妇充分告知利弊、风险及假阴性假阳性可能，签署知情同意。
- 筛查高风险者及时转诊进行产前诊断，结果异常者组织多学科会诊与遗传咨询。
- 动态超声随访胎儿生长发育与结构，评估预后并制定分娩与出生后管理计划。

## 注意事项
- 介入性产前诊断需在有资质机构进行，严格无菌操作，警惕流产、感染等并发症。
- 尊重孕妇自主选择权，规范记录与报告，做好随访与信息管理。
- 避免筛查结果误读导致不必要的终止妊娠或漏诊，重视质量控制。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
产前筛查与产前诊断的确诊需要结合临床表现与辅助检查。常用检查包括：儿科/妇产科专科查体、血常规等基础检查，必要时按专科指南进一步检查。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
科学喂养、按时接种疫苗、注意手卫生与居家通风，孕期定期产检，儿童发热等症状持续不缓解及时就医。

## 就医指引
如出现疑似产前筛查与产前诊断的相关症状，建议及时到儿科、妇产科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
