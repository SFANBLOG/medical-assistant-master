# 母乳喂养并发症处理

母乳喂养相关并发症常见于产后哺乳初期，正确识别与处理有助于提高母乳喂养成功率，保障母婴健康。

## 临床要点
- 常见问题：乳头皲裂、乳头疼痛、乳汁淤积、急性乳腺炎、乳房脓肿及乳腺导管堵塞。
- 诱因多为含接姿势不良、哺乳次数不足、排乳不畅、乳头损伤继发感染等。

## 处理与观察重点
- 纠正含接姿势与哺乳体位，强调按需哺乳、充分排空乳房，先哺乳患侧。
- 乳汁淤积时温热敷后轻柔按摩并增加哺乳频次；疼痛明显者可遵医嘱使用镇痛药物。
- 急性乳腺炎伴发热等全身症状者合理使用退热镇痛药，必要时选用哺乳期安全的抗菌药物。
- 脓肿形成时应由专科处理（穿刺或切开引流），期间指导维持健侧哺乳与患侧排空。

## 注意事项
- 多数乳腺炎经积极排空与支持治疗可缓解，应避免因疼痛中断哺乳。
- 指导产妇认识乳腺炎早期征象，及时处理，防止进展为脓肿。
- 关注产妇情绪与休息，必要时由专业哺乳指导人员介入支持。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）
