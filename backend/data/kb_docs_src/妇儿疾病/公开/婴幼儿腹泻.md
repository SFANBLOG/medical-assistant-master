# 婴幼儿腹泻

婴幼儿腹泻是指排便次数增多、粪便性状改变（稀便、水样便）的一组症候，常由感染或喂养不当引起，需警惕脱水等并发症。

## 病因
病毒（如轮状病毒、诺如病毒）、细菌感染、肠道外感染、乳糖不耐受、受凉或喂养不当等均可引起。婴幼儿肠道发育不成熟、免疫功能较弱，易受侵袭。

## 主要症状
- 大便次数增多，呈稀便或水样便，可伴呕吐、发热。
- 可出现食欲下降、尿量减少、哭时泪少、口唇干燥等脱水表现。

## 处理建议
- 口服补液盐是预防和纠正轻度脱水的关键，按说明书分次喂服。
- 继续合理喂养，母乳喂养者可继续母乳；配方奶喂养者可根据情况咨询医生。
- 注意臀部护理，勤换尿布，便后温水清洗并涂抹护臀霜。
- 不随意使用止泻药和抗生素，需在医生指导下用药。

## 就医提醒
出现持续高热、明显口渴、眼窝凹陷、精神差、尿量显著减少、大便带血或反复呕吐不能进食等情况，应及时就医。
