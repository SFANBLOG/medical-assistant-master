# 儿童发热的家庭护理

发热是儿童最常见的症状之一，多数由病毒感染引起，是机体免疫系统对抗病原体的正常反应。科学规范的家庭护理有助于减轻不适、避免并发症。

## 病因
常见病因包括呼吸道感染、消化道感染、幼儿急疹、出牙期等。少数由细菌感染、疫苗反应或环境过热等引起。

## 主要症状
- 体温升高，可伴寒战、脸红、手脚发凉。
- 部分儿童出现食欲减退、烦躁、哭闹或精神倦怠。

## 处理建议
- 注意补充水分，少量多次喂水，防止脱水。
- 保持室内通风、穿着宽松透气，避免过度包裹。
- 体温超过 38.5℃ 且明显不适时，可遵医嘱使用布洛芬或对乙酰氨基酚等退热药（按体重给药，两次用药至少间隔 4-6 小时）。
- 可用温水擦拭身体辅助降温，不建议用酒精擦浴或冰水灌肠。

## 就医提醒
3 个月以下婴儿发热、持续高热超过 3 天、出现抽搐、精神萎靡、呼吸急促、皮疹或反复呕吐等情况，应立即就医。

## 预防与日常保健
科学喂养、按时接种疫苗、注意手卫生与居家通风，孕期定期产检，儿童发热等症状持续不缓解及时就医。

## 就医指引
如出现疑似儿童发热的家庭护理的相关症状，建议及时到儿科、妇产科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对儿童发热的家庭护理相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
