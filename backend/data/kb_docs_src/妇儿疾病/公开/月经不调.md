# 月经不调

月经不调是育龄女性常见的妇科问题，指月经周期、经期或经量出现异常，如周期不规律、经期过长过短、经量过多过少等。

## 病因
精神压力大、作息紊乱、过度节食或肥胖、内分泌紊乱（如多囊卵巢综合征）、子宫及卵巢疾病、药物影响等均可导致月经不调。

## 主要症状
- 月经周期长短不一、闭经、经期延长或缩短。
- 经量过多、过少，或伴痛经、经间期出血。

## 处理建议
- 保持规律作息、情绪稳定，避免过度劳累与压力。
- 合理饮食、适度运动，保持健康体重，避免过度节食或暴饮暴食。
- 做好月经记录（周期、经期、经量），便于就诊时提供信息。
- 在医生指导下针对病因治疗，如药物调整周期、处理相关妇科疾病，不自行滥用激素类药物。

## 就医提醒
出现连续多次月经不规律、经量明显增多伴贫血、闭经超过 3 个月，或伴剧烈腹痛、异常出血等情况，应及时到妇科就诊。

## 检查与诊断
月经不调的确诊需要结合临床表现与辅助检查。常用检查包括：儿科/妇产科专科查体、血常规等基础检查，必要时按专科指南进一步检查。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
科学喂养、按时接种疫苗、注意手卫生与居家通风，孕期定期产检，儿童发热等症状持续不缓解及时就医。

## 就医指引
如出现疑似月经不调的相关症状，建议及时到儿科、妇产科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对月经不调相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
