# 正常妊娠与产检

正常妊娠指胎儿在母体内发育并最终分娩的生理过程，全程约 280 天（40 周）。规律产检是保障母婴安全、早期发现问题的重要手段。

## 病因
妊娠是正常的生理现象，但受母体健康状况、营养状态及环境等多因素影响，需要通过产检进行动态监测。

## 主要症状
- 早孕期：停经、恶心呕吐、乳房胀痛、尿频。
- 中晚孕期：胎动出现、腹部增大，可伴腰酸、水肿、宫缩等生理变化。

## 处理建议
- 发现停经后尽早确认妊娠，并在孕早期建立产检档案。
- 按时完成各阶段产检，包括血尿常规、超声、唐氏筛查或产前诊断等。
- 合理补充叶酸、钙、铁等营养素，均衡饮食、适度运动。
- 学会自我监测胎动，孕 28 周后每日计数。

## 就医提醒
出现阴道出血、腹痛、胎动异常、破水、规律宫缩、头痛头晕、视力模糊等情况，应及时就医。

## 检查与诊断
正常妊娠与产检的确诊需要结合临床表现与辅助检查。常用检查包括：儿科/妇产科专科查体、血常规等基础检查，必要时按专科指南进一步检查。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
科学喂养、按时接种疫苗、注意手卫生与居家通风，孕期定期产检，儿童发热等症状持续不缓解及时就医。

## 就医指引
如出现疑似正常妊娠与产检的相关症状，建议及时到儿科、妇产科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对正常妊娠与产检相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
