# 儿童营养与喂养

合理营养是儿童生长发育的基础。不同年龄段儿童的喂养方式与营养需求不同，科学喂养有助于预防营养不良和肥胖等健康问题。

## 病因
喂养不当、偏食挑食、疾病消耗、辅食添加时机不当等均可导致儿童营养问题，如缺铁性贫血、维生素 D 缺乏、消瘦或超重。

## 主要症状
- 食欲减退、生长发育迟缓、体重不增或增长缓慢。
- 面色苍白、精神不佳、头发稀疏、免疫力下降等。

## 处理建议
- 0-6 个月提倡纯母乳喂养；6 个月起逐步添加富铁辅食，如强化铁米粉、肉泥、蛋黄等。
- 辅食从单一到多样、由稀到稠、由少到多，注意食物多样化与合理搭配。
- 培养良好进餐习惯，定时定点进餐，避免追喂和强迫进食。
- 保证户外活动与日照，按需补充维生素 D，定期进行生长发育监测。

## 就医提醒
出现明显消瘦、生长迟缓、贫血、反复感染或喂养困难等情况，应及时到儿童保健或营养门诊就诊。

## 检查与诊断
儿童营养与喂养的确诊需要结合临床表现与辅助检查。常用检查包括：儿科/妇产科专科查体、血常规等基础检查，必要时按专科指南进一步检查。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
科学喂养、按时接种疫苗、注意手卫生与居家通风，孕期定期产检，儿童发热等症状持续不缓解及时就医。

## 就医指引
如出现疑似儿童营养与喂养的相关症状，建议及时到儿科、妇产科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对儿童营养与喂养相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
