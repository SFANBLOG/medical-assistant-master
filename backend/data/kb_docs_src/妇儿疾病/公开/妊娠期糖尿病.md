# 妊娠期糖尿病

妊娠期糖尿病是指妊娠期首次发生或发现的糖代谢异常，通常在孕中期通过口服葡萄糖耐量试验筛查发现，多数产妇产后血糖可恢复正常。

## 病因
孕期胎盘分泌的激素具有拮抗胰岛素的作用，加上体重增加、活动减少等因素，使机体对胰岛素的敏感性下降。有糖尿病家族史、肥胖、高龄、既往巨大儿分娩史等是常见高危因素。

## 主要症状
多数妊娠期糖尿病孕妇无明显症状，常在产检筛查时发现。部分孕妇可能出现多饮、多食、多尿、体重增长过快等表现。

## 处理建议
- 通过饮食控制、适当运动控制血糖，遵循少食多餐原则，均衡营养。
- 定期监测血糖并按时产检，按医嘱评估是否需要胰岛素治疗。
- 控制孕期体重合理增长，避免高糖高脂饮食。

## 就医提醒
确诊后应按产科与营养科共同指导管理。出现血糖控制不佳、胎动异常、血压升高或胎膜早破等表现时应及时就医。产后应在医生指导下复查血糖。
