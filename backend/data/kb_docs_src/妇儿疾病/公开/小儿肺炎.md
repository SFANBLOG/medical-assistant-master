# 小儿肺炎

小儿肺炎是婴幼儿时期常见的呼吸系统感染性疾病，可由病毒、细菌或肺炎支原体等病原体引起，是导致儿童住院的常见原因之一。

## 病因
病毒（如呼吸道合胞病毒、流感病毒）、细菌（如肺炎链球菌）及肺炎支原体等均可引起小儿肺炎。婴幼儿免疫系统发育不完善、呼吸道解剖结构相对狭小，感染后易累及下呼吸道，病情进展较快。

## 主要症状
- 发热、咳嗽、气促，呼吸频率增快。
- 可出现鼻翼扇动、口唇发绀、吸气性凹陷等呼吸困难表现。
- 婴幼儿常表现为精神萎靡、拒奶、呛奶、口吐泡沫等非典型表现。

## 处理建议
- 一旦怀疑肺炎，应及时就医，由医生评估病情并决定抗感染、雾化、吸氧等治疗方案。
- 居家护理注意保证液体摄入、保持呼吸道通畅，监测体温与精神状态。
- 按时完成疫苗接种，坚持母乳喂养、避免被动吸烟可降低患病风险。

## 就医提醒
出现呼吸急促、呼吸困难、精神差、持续高热不退或进食明显减少时，应立即就医。3 个月以下婴儿出现发热或疑似肺炎表现，更应及时就诊。

## 检查与诊断
小儿肺炎的确诊需要结合临床表现与辅助检查。常用检查包括：儿科/妇产科专科查体、血常规等基础检查，必要时按专科指南进一步检查。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
科学喂养、按时接种疫苗、注意手卫生与居家通风，孕期定期产检，儿童发热等症状持续不缓解及时就医。

## 就医指引
如出现疑似小儿肺炎的相关症状，建议及时到儿科、妇产科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对小儿肺炎相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
