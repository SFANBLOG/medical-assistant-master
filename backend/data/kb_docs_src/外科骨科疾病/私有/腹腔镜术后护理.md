# 腹腔镜术后护理

## 临床要点
腹腔镜手术创伤小、恢复快，但术后仍有气腹相关反应和特定并发症风险。护理重点是密切观察生命体征、腹壁切口、引流管及有无内出血、内脏损伤等早期并发症。应了解手术类型（如胆囊切除、阑尾切除、疝修补等）对护理要求的影响。

## 处理与观察重点
术后早期常见肩部及肋部酸痛，为二氧化碳气体残留刺激膈肌所致，可鼓励患者早期下床活动以促进气体吸收，症状多可自行缓解。观察穿刺孔有无出血、血肿或渗液，保持敷料干燥。持续监测心率、血压、腹部有无胀痛和肌紧张，警惕腹腔内出血与胆漏、肠漏等。恶心呕吐可用止吐药物对症处理。指导患者术后6小时左右可少量进水，逐步过渡饮食。

## 注意事项
腹胀持续不缓解或出现剧烈腹痛、发热、黄疸、呼吸困难等异常时，应及时报告医生，排查并发症。老年及合并心肺疾病患者对气腹耐受性差，需加强氧饱和度和循环监测。出院后交代切口护理、饮食与活动注意事项及复诊时间。
