# 深静脉血栓的预防

## 临床要点
深静脉血栓（DVT）是外科术后常见且可预防的并发症，主要危险因素包括手术时间长、卧床制动、恶性肿瘤、肥胖、高龄、既往血栓史、妊娠及某些易栓症。应依据患者危险分层（低、中、高危）制定个体化预防方案，并在病历中记录。预防措施包括基础预防、机械预防和药物预防三大类。

## 处理与观察重点
基础预防包括早期下床活动、下肢主动活动、充分补液；机械预防包括梯度压力袜和间歇性气压装置；药物预防常用低分子肝素等抗凝药物，应在医生评估出血风险后使用。每日观察双下肢有无不对称肿胀、疼痛、皮温升高和浅静脉扩张，可疑DVT时及时行加压超声检查。警惕突发胸痛、呼吸困难、咯血等肺栓塞表现。

## 注意事项
药物与机械预防的联合应用应权衡血栓与出血风险，尤其是硬膜外置管及手术部位出血高危者。抗凝药物的使用时机、剂量和停药应遵循规范并个体化调整。围手术期血栓风险评估应动态更新，出院后仍需进行健康教育，高危人群可适当延长预防。

## 检查与诊断
深静脉血栓的预防的确诊需要结合临床表现与辅助检查。常用检查包括：X线、CT、MRI等影像学检查、血常规及凝血功能等，必要时专科查体评估。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
合理运动、运动前充分热身、注意劳动与运动防护，控制体重、加强肌肉力量训练，预防跌倒。

## 就医指引
如出现疑似深静脉血栓的预防的相关症状，建议及时到骨科、普外科等相应专科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
