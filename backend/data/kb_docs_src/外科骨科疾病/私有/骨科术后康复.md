# 骨科术后康复

## 临床要点
骨科术后康复是功能恢复的核心环节，应尽早启动，遵循个体化、循序渐进的原则，由医生、康复师和护士协作实施。康复目标包括减轻疼痛与肿胀、预防关节僵硬与肌肉萎缩、恢复关节活动度和肌力、重建行走与日常生活能力。康复方案应结合手术方式、内固定稳定性和患者基础状况制定。

## 处理与观察重点
术后早期以消肿止痛和被动、主动辅助活动为主，如患肢抬高、冰敷、踝泵运动；中期逐步增加关节活动度训练和等长肌力练习；后期进行负重训练、平衡与协调训练。观察切口愈合情况、患肢血运、神经功能及内固定有无松动，防止训练过度导致二次损伤。指导患者正确使用助行器具和支具。

## 注意事项
不同手术（如关节置换、脊柱融合、骨折内固定）的康复时机和负重政策差异较大，应严格遵医嘱执行，避免过早负重。合并骨质疏松、糖尿病者需同步治疗基础病。康复训练中疼痛加重或关节异常肿胀时应暂停并复诊。康复需要长期坚持，做好出院后的家庭康复指导与随访。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
骨科术后康复的确诊需要结合临床表现与辅助检查。常用检查包括：X线、CT、MRI等影像学检查、血常规及凝血功能等，必要时专科查体评估。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
合理运动、运动前充分热身、注意劳动与运动防护，控制体重、加强肌肉力量训练，预防跌倒。

## 就医指引
如出现疑似骨科术后康复的相关症状，建议及时到骨科、普外科等相应专科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
