# 围手术期预防性抗菌药物使用

## 临床要点
预防性使用抗菌药物旨在减少手术部位感染，适用于清洁污染手术或感染风险较高的手术，应遵循"有效、安全、短程"原则，避免无指征滥用。药物选择应覆盖手术部位最常见的致病菌，常用头孢菌素类等抗菌药物。给药时机一般在切开皮肤前0.5-1小时（或麻醉诱导时）静脉滴注，使手术期间组织内达到有效药物浓度。

## 处理与观察重点
单次给药即可覆盖绝大多数手术，长时间手术（超过药物半衰期2倍）或术中出血量大者需术中追加。术后预防性用药时间一般不超过24小时，清洁手术原则上不预防用药。应观察用药后的过敏反应和手术部位感染情况，出现感染征象时及时留取标本送检并针对性治疗。

## 注意事项
抗菌药物品种、剂量应根据患者体重、肾功能和药物过敏史个体化调整。对β-内酰胺类过敏者需选择替代药物。必须与治疗性用药相区分，禁止以预防为名长期用药。合理用药是降低耐药菌产生和医疗费用的关键。

## 检查与诊断
围手术期预防性抗菌药物使用的确诊需要结合临床表现与辅助检查。常用检查包括：X线、CT、MRI等影像学检查、血常规及凝血功能等，必要时专科查体评估。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
合理运动、运动前充分热身、注意劳动与运动防护，控制体重、加强肌肉力量训练，预防跌倒。

## 就医指引
如出现疑似围手术期预防性抗菌药物使用的相关症状，建议及时到骨科、普外科等相应专科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
