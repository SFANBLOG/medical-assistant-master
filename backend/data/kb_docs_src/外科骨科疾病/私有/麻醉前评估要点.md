# 麻醉前评估要点

## 临床要点
麻醉前评估是保障围手术期安全的第一步，应在手术前完成，主要目的是识别风险、制定个体化麻醉方案。评估内容包括病史与体格检查、气道评估（如张口度、颈部活动度）、心血管与呼吸系统功能、肝肾功能、凝血功能及用药情况。常用工具包括ASA分级和必要的实验室与辅助检查。

## 处理与观察重点
重点关注可能影响麻醉安全的因素：高血压、冠心病、慢性阻塞性肺疾病、糖尿病、肥胖、睡眠呼吸暂停、困难气道及老年衰弱等。了解患者长期用药，特别是抗凝药、抗血小板药、降糖药和镇静催眠药，评估停药与调整方案。麻醉前应确认禁食禁水时间是否达标，排除急性呼吸道感染等临时禁忌情况。

## 注意事项
急诊手术应权衡紧急病情与风险，采取相应简化流程。对药物过敏史和既往麻醉史（如恶性高热家族史）应详细询问并记录。麻醉前评估结果、风险告知和麻醉方案应与患者充分沟通并记录在病历中。必要时请心内科、呼吸科等专科会诊。

（本文为临床业务参考，不构成对具体病例的诊疗意见。）

## 检查与诊断
麻醉前评估要点的确诊需要结合临床表现与辅助检查。常用检查包括：X线、CT、MRI等影像学检查、血常规及凝血功能等，必要时专科查体评估。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
合理运动、运动前充分热身、注意劳动与运动防护，控制体重、加强肌肉力量训练，预防跌倒。

## 就医指引
如出现疑似麻醉前评估要点的相关症状，建议及时到骨科、普外科等相应专科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对麻醉前评估要点相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
