# 颈椎病

颈椎病是颈椎退行性改变及其继发病变刺激或压迫邻近组织（神经根、脊髓、椎动脉、交感神经）引起的一系列症状，在中老年及长期伏案工作者中常见。

## 病因
长期低头伏案、睡姿不当、颈部外伤、颈椎发育异常等加速颈椎间盘退变，骨赘形成、椎间盘突出、韧带肥厚导致椎管或椎间孔狭窄，从而压迫神经、脊髓或血管。

## 主要症状
根据受累结构不同表现各异：颈型以颈肩酸痛为主；神经根型表现为上肢放射性疼痛、麻木；脊髓型出现双下肢无力、行走不稳、手部精细动作困难；椎动脉型可有头晕、恶心；交感型则有心慌、出汗异常等。

## 处理建议
- 调整工作和生活习惯，避免长时间低头，定时起身活动颈部。
- 选择合适的枕头，保持颈椎自然曲度；注意颈部保暖。
- 在医生指导下进行颈部功能锻炼和物理治疗；症状明显者可短期佩戴颈托。
- 药物方面可使用非甾体抗炎药、神经营养药等；保守治疗无效且脊髓受压明显者需考虑手术。

## 就医提醒
出现四肢无力、行走不稳、踩棉感、大小便异常等脊髓受压症状时，应尽早就诊，避免延误手术时机。

## 检查与诊断
颈椎病的确诊需要结合临床表现与辅助检查。常用检查包括：X线、CT、MRI等影像学检查、血常规及凝血功能等，必要时专科查体评估。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
合理运动、运动前充分热身、注意劳动与运动防护，控制体重、加强肌肉力量训练，预防跌倒。

## 就医指引
如出现疑似颈椎病的相关症状，建议及时到骨科、普外科等相应专科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对颈椎病相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
