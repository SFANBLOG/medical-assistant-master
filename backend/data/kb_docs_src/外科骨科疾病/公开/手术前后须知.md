# 手术前后须知

手术是治疗多种外科疾病的重要手段。充分的术前准备和正确的术后护理，是保证手术安全、减少并发症、促进康复的关键。

## 病因
需要手术的常见原因包括：外伤性骨折、急性阑尾炎、胆囊结石伴胆囊炎、腹股沟疝嵌顿、肿瘤性疾病，以及某些经保守治疗无效的骨科、肛肠疾病等。此外，急诊大出血、内脏穿孔等危急情况也需要紧急手术。

## 主要症状
术前应如实向医生反映既往病史、过敏史、长期用药情况及术前的不适症状。术后需警惕以下表现：伤口持续渗血、红肿热痛加重、发热不退、腹部胀痛、恶心呕吐、活动后呼吸困难或下肢肿痛等，这些可能是术后并发症的信号。

## 处理建议
- 术前遵医嘱禁食禁水、戒烟、完善检查，停用可能影响凝血的药物（需遵医嘱）。
- 保持心态平和，充分了解手术方案、风险和预期，签署知情同意书。
- 术后按医嘱在病情允许时早期下床活动，配合翻身、咳嗽排痰，进行下肢活动以预防血栓。
- 注意伤口护理，保持敷料清洁干燥；遵医嘱合理饮食，逐渐由流食过渡到正常饮食。
- 有疼痛及时告知医护人员，按医嘱使用镇痛药物，不必强忍。

## 就医提醒
术后出现高热寒战、呼吸困难、胸痛、伤口大量渗血或裂开、剧烈腹痛、意识异常等情况，应及时通知医护人员或到医院急诊就诊。

## 检查与诊断
手术前后须知的确诊需要结合临床表现与辅助检查。常用检查包括：X线、CT、MRI等影像学检查、血常规及凝血功能等，必要时专科查体评估。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
合理运动、运动前充分热身、注意劳动与运动防护，控制体重、加强肌肉力量训练，预防跌倒。

## 就医指引
如出现疑似手术前后须知的相关症状，建议及时到骨科、普外科等相应专科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
