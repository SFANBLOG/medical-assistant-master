# 腰椎间盘突出症

腰椎间盘突出症是引起腰腿痛的常见原因，多见于青壮年，病变多发生在腰4-5和腰5-骶1节段。

## 病因
椎间盘退变是根本原因。长期弯腰负重、久坐、姿势不良、外伤等使椎间盘承受压力增大，纤维环破裂，髓核向后突出，压迫神经根或马尾神经，从而出现症状。

## 主要症状
腰痛伴一侧下肢放射性疼痛、麻木，疼痛沿臀部向大腿后侧、小腿外侧放射至足部，咳嗽、打喷嚏、弯腰时加重。严重者可出现下肢无力、感觉减退，甚至大小便功能障碍。

## 处理建议
- 急性期注意休息，选择硬板床，避免久坐、弯腰和负重。
- 在医生指导下使用非甾体抗炎药、肌肉松弛剂等缓解症状，配合物理治疗。
- 多数患者经保守治疗可缓解；症状反复或神经压迫明显者，可考虑微创或手术治疗。
- 平时加强腰背肌锻炼，保持正确坐姿，避免搬运重物时突然用力。

## 就医提醒
出现大小便失禁或困难、会阴部麻木、双下肢进行性无力等马尾综合征表现时，属于急症，需立即就医，以免造成不可逆的神经损伤。

## 检查与诊断
腰椎间盘突出症的确诊需要结合临床表现与辅助检查。常用检查包括：X线、CT、MRI等影像学检查、血常规及凝血功能等，必要时专科查体评估。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
合理运动、运动前充分热身、注意劳动与运动防护，控制体重、加强肌肉力量训练，预防跌倒。

## 就医指引
如出现疑似腰椎间盘突出症的相关症状，建议及时到骨科、普外科等相应专科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对腰椎间盘突出症相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
