# 骨折的院前处置

骨折是指骨结构的连续性完全或部分断裂，多由外伤引起。正确及时的院前处置，可以减轻疼痛、防止损伤加重、避免继发血管神经损伤，为后续治疗争取时间。

## 病因
骨折常见于跌倒、交通意外、运动损伤及高处坠落等直接或间接暴力作用。老年人因骨质疏松、骨强度下降，轻微外力即可导致骨折。

## 主要症状
受伤部位出现剧烈疼痛、肿胀、瘀斑，肢体畸形（缩短、旋转或成角），异常活动，以及患肢活动受限。开放性骨折可见伤口出血甚至骨端外露。

## 处理建议
- 保持伤员安静，不要随意搬动或强行复位，以免加重损伤。
- 有出血时先用干净敷料加压包扎止血；怀疑脊柱骨折时，应让伤员平卧，避免扭曲或坐立搬动。
- 就地取材（木板、杂志、硬纸板等）对骨折肢体进行临时固定，固定范围包括骨折部位上下的关节。
- 冷敷可减轻肿胀，但不要让冰袋直接接触皮肤。
- 尽快拨打急救电话，由专业人员转运。

## 就医提醒
出现意识改变、呼吸困难、开放性骨折、大出血，或受伤部位远端麻木、苍白、发凉等血管神经受压表现时，应立即送医。任何可疑骨折都应到医院拍片确诊。

## 检查与诊断
骨折的院前处置的确诊需要结合临床表现与辅助检查。常用检查包括：X线、CT、MRI等影像学检查、血常规及凝血功能等，必要时专科查体评估。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
合理运动、运动前充分热身、注意劳动与运动防护，控制体重、加强肌肉力量训练，预防跌倒。

## 就医指引
如出现疑似骨折的院前处置的相关症状，建议及时到骨科、普外科等相应专科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对骨折的院前处置相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
