# 急性阑尾炎

急性阑尾炎是外科最常见的急腹症之一，多因阑尾管腔阻塞继发细菌感染所致。及早识别并及时手术，预后一般良好。

## 病因
阑尾腔细长，粪石、淋巴滤泡增生、异物或肿瘤等可造成管腔阻塞，使腔内压力升高、血运障碍，继发细菌感染，进而导致炎症、坏疽甚至穿孔。

## 主要症状
典型表现为转移性右下腹痛：疼痛先位于上腹部或脐周，数小时至十余小时后转移并固定在右下腹。常伴恶心、呕吐、发热、食欲下降。右下腹有固定压痛，严重时可有反跳痛和肌紧张。

## 处理建议
- 一旦怀疑急性阑尾炎，应立即禁食、禁水，不要自行服用止痛药，以免掩盖病情。
- 及时到医院就诊，配合医生完成血常规、腹部超声或腹部CT等检查。
- 绝大多数急性阑尾炎需要手术治疗，可根据病情选择腹腔镜或开腹阑尾切除术；部分轻症或已形成脓肿者可在医生评估下保守治疗。

## 就医提醒
右下腹痛持续不缓解、发热加重、出现全腹剧痛，或儿童、老年人、孕妇出现疑似阑尾炎症状时，应尽快就医，警惕穿孔、腹膜炎等并发症。

## 检查与诊断
急性阑尾炎的确诊需要结合临床表现与辅助检查。常用检查包括：X线、CT、MRI等影像学检查、血常规及凝血功能等，必要时专科查体评估。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
合理运动、运动前充分热身、注意劳动与运动防护，控制体重、加强肌肉力量训练，预防跌倒。

## 就医指引
如出现疑似急性阑尾炎的相关症状，建议及时到骨科、普外科等相应专科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对急性阑尾炎相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
