# 胆囊结石与胆囊炎

胆囊结石是胆道系统的常见疾病，结石可刺激胆囊壁或造成胆囊管梗阻，进而诱发急性胆囊炎。

## 病因
胆囊结石的形成与胆汁成分失衡、胆汁淤积、胆囊收缩功能下降有关，多见于肥胖、高脂饮食、多次妊娠、快速减重及糖尿病等人群。结石嵌顿于胆囊管可导致胆汁引流受阻、胆囊内压升高、继发细菌感染，形成急性胆囊炎。

## 主要症状
胆囊结石可长期无症状。急性胆囊炎发作时，表现为右上腹持续性绞痛或胀痛，可向右肩背部放射，常发生于进食油腻食物后，伴恶心、呕吐、发热，墨菲氏征阳性。

## 处理建议
- 无症状的胆囊结石可定期随访，注意低脂清淡饮食、规律进餐。
- 急性发作期应禁食，由医生根据情况予以补液、解痉镇痛及抗感染等治疗。
- 反复发作或并发症风险高的患者，可在医生评估下行腹腔镜胆囊切除术，这是目前治疗有症状胆囊结石的常用手术方式。

## 就医提醒
出现右上腹剧烈疼痛、高热寒战、皮肤巩膜黄染（黄疸）时，可能提示急性胆囊炎、胆总管结石或急性胆管炎，应尽快就医。

## 检查与诊断
胆囊结石与胆囊炎的确诊需要结合临床表现与辅助检查。常用检查包括：X线、CT、MRI等影像学检查、血常规及凝血功能等，必要时专科查体评估。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
合理运动、运动前充分热身、注意劳动与运动防护，控制体重、加强肌肉力量训练，预防跌倒。

## 就医指引
如出现疑似胆囊结石与胆囊炎的相关症状，建议及时到骨科、普外科等相应专科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。

## 日常管理建议
针对胆囊结石与胆囊炎相关的健康问题，日常应注意规律作息、均衡饮食与适度运动，尽量避免已知诱因（如劳累、受凉、辛辣或高盐高脂饮食、吸烟饮酒等）。请严格遵医嘱用药并定期复诊复查，切勿自行增减或停用药物。
建议日常记录症状变化、用药情况与相关检查指标，便于就诊时提供给医生参考。若出现症状持续不缓解、反复发作或明显加重（如高热不退、呼吸困难、剧烈疼痛、意识改变、出血等），应及时前往正规医院相应科室就诊，由专业医师评估并制定个体化诊疗方案。
