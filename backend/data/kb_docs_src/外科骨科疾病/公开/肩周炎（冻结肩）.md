# 肩周炎（冻结肩）

肩周炎又称"冻结肩""五十肩"，是肩关节周围软组织的无菌性炎症，导致关节囊粘连，引起肩部疼痛和活动受限。

## 病因
确切病因尚不完全清楚，可能与肩关节外伤、劳损、长时间固定不动有关，糖尿病、甲状腺疾病等内分泌因素也是诱因。好发于40-60岁人群。

## 主要症状
起病多隐袭，表现为肩部逐渐加重的疼痛，夜间明显，可放射至肩胛部或上臂。肩关节各方向活动均受限，以外展、外旋、上举受限为主，梳头、穿衣、反手摸背等动作困难。病程常呈自限性，但恢复缓慢。

## 处理建议
- 急性疼痛期注意休息，肩部保暖，可在医生指导下使用非甾体抗炎药缓解疼痛。
- 坚持循序渐进的功能锻炼，如爬墙、钟摆运动、外旋拉伸等，是恢复关节功能的关键。
- 配合物理治疗、局部封闭等可减轻炎症和粘连。
- 注意与颈椎病、肩袖损伤等其他引起肩痛的疾病相鉴别。

## 就医提醒
肩痛持续不缓解、夜间痛明显影响睡眠，或外伤后突发肩部剧痛、完全抬不起肩时，应及时就医明确诊断。

## 检查与诊断
肩周炎（冻结肩）的确诊需要结合临床表现与辅助检查。常用检查包括：X线、CT、MRI等影像学检查、血常规及凝血功能等，必要时专科查体评估。具体检查项目应由接诊医生根据病情决定。

## 预防与日常保健
合理运动、运动前充分热身、注意劳动与运动防护，控制体重、加强肌肉力量训练，预防跌倒。

## 就医指引
如出现疑似肩周炎（冻结肩）的相关症状，建议及时到骨科、普外科等相应专科就诊；症状较重或持续不缓解、进行性加重时，应立即就医，切勿拖延。就诊时请如实告知医生症状持续时间、既往病史与用药情况。
