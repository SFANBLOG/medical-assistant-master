# 高血压急症处理

> 以下为科普与就医参考信息，不构成诊断、处方或治疗建议；具体病情请咨询专业医生。

## 疾病概述
高血压急症指血压急剧升高（常 >180/120 mmHg）伴急性靶器官损害（脑、心、肾、眼底、主动脉），需静脉用药在数分钟至数小时内谨慎降压，避免降幅过大致灌注不足。

## 常见症状
- 剧烈头痛、视物模糊、恶心呕吐
- 胸痛、呼吸困难（心衰/主动脉夹层）
- 抽搐、偏瘫（高血压脑病/脑血管病）
- 少尿、血尿（肾损害）
- 意识障碍

## 常见病因（诱因与危险因素）
- 未规律服药、自行停药
- 继发高血压（嗜铬危象、子痫）
- 诱因：情绪激动、疼痛、应激
- 危险因素：老年、基础高血压控制差

## 诊断要点
- 血压骤升 + 靶器官损害证据
- 脑：影像排除出血/梗死
- 心：心电图、心肌酶、心超（夹层）
- 肾：肌酐、尿
- 眼底：出血渗出视乳头水肿
- 区分急症（有损害）与亚急症（无损害）

## 一般处理与就医建议
居家不可自行处理：立即呼叫急救、静卧、勿剧烈活动。
红旗信号：上述任一靶器官症状伴血压骤升——急诊抢救。
院内：静脉降压药（硝普钠/尼卡地平/乌拉地尔等）逐步降 10–25%（首小时），按病因定目标；由急诊/ICU 严密监测。

## 注意事项
- 切忌舌下含服硝苯地平普通片（血压骤降风险）
- 降压勿过快过低，防脑肾缺血
- 忌患者自行驾车前往
- 明确并治疗诱因与继发原因

## 预防与日常管理
- 长期规范服药、不擅自停
- 家庭监测、控制盐重
- 慢病（肾/内分泌）协同管理
- 识别预警症状尽早就医
