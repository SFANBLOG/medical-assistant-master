# 慢阻肺急性加重管理

> 以下为科普与就医参考信息，不构成诊断、处方或治疗建议；具体病情请咨询专业医生。

## 疾病概述

慢性阻塞性肺疾病（简称慢阻肺，COPD）是一种以持续气流受限为特征的慢性气道炎症性疾病。慢阻肺急性加重（AECOPD）指患者在短期内出现呼吸困难、咳嗽和/或咳痰加重，需要调整常规治疗方案的急性事件。急性加重可加速肺功能下降，增加住院和死亡风险，是慢阻肺病程中的关键事件。感染是最常见诱因，但空气污染、治疗中断等也可诱发。识别早期信号、规范治疗和加强预防，是改善预后的核心。

## 常见症状

急性加重的典型表现是在日常水平上出现以下变化：

- **呼吸困难加重**：活动后气短较平时明显，严重时静息亦感气促，甚至出现端坐呼吸
- **咳嗽加重**：咳嗽频率和强度增加，夜间或晨起尤为明显
- **痰量增多**：痰液较平时增多，可由白色黏液转为黄色或脓性
- **痰液黏稠度增加**：排痰困难，部分患者需用力咳痰
- **全身症状**：可有乏力、发热、食欲下降、精神萎靡等

需注意，老年或衰弱患者可能仅表现为意识模糊、反应迟钝、嗜睡，而无典型气促加重，易被忽视。

## 常见病因（诱因与危险因素）

- **呼吸道感染**：是最主要诱因，包括病毒（鼻病毒、流感病毒、呼吸道合胞病毒等）和细菌（肺炎链球菌、流感嗜血杆菌、卡他莫拉菌等）
- **空气污染与环境因素**：PM2.5、二氧化硫、氮氧化物及冷空气刺激可诱发气道炎症急性加重
- **治疗依从性差**：规律吸入药物中断、氧疗不规范或减量过早
- **合并症影响**：心力衰竭、肺栓塞、气胸、心律失常等疾病可模拟或诱发急性加重
- **个体危险因素**：高龄、长期吸烟、肺功能基础差、频繁急性加重史、营养不良、免疫功能低下

## 诊断要点

急性加重的诊断主要依据典型症状在短期内加重，并需评估严重程度、排除其他疾病。核心检查项目包括：

- **动脉血气分析（ABG）**：判断是否存在低氧血症和二氧化碳潴留。常用阈值：PaO₂ < 60 mmHg（呼吸衰竭）；PaCO₂ > 50 mmHg 且 pH < 7.35 提示急性呼吸性酸中毒，属于危重情况
- **胸部影像学（X线或CT）**：用于排除气胸、肺炎、肺栓塞、胸腔积液等与急性加重表现相似的疾病；可发现新发浸润影提示肺炎
- **血常规与炎症指标**：白细胞、中性粒细胞比例升高提示细菌感染；C反应蛋白（CRP）和降钙素原（PCT）可辅助判断感染类型及指导抗菌药物使用
- **心电图（ECG）**：排除急性冠脉综合征、心律失常等心源性因素
- **肺功能**：急性期不推荐常规进行，因患者难以配合，且结果不能准确反映急性期状态

## 一般处理与就医建议

### 居家/床旁可做的处理

- **氧疗**：若家中有制氧机，维持血氧饱和度（SpO₂）在 88%-92%；吸氧浓度不宜过高，避免二氧化碳潴留加重
- **支气管扩张剂**：按医嘱增加短效β₂受体激动剂（如沙丁胺醇气雾剂）和/或短效抗胆碱能药物（如异丙托溴铵）的吸入频次；注意观察心悸、震颤等不良反应
- **糖皮质激素**：若医生已备有口服激素（如泼尼松），可按既定方案短期使用（常规剂量每天30-40 mg，一般3-5天），但必须在医师指导下调整
- **抗菌药物**：仅在以下情况遵医嘱使用——脓性痰且伴发热，或影像学提示肺炎；不可自行随意服用
- **排痰与气道廓清**：适量饮水（心功能不全者需控制），主动咳嗽，使用振动排痰器或胸部叩击辅助排痰
- **休息与监测**：减少活动，监测体温、呼吸频率、心率和SpO₂变化；记录痰量、颜色和症状变化

### 必须立即就医的红旗信号

- 出现意识模糊、嗜睡、胡言乱语或昏迷
- 静息状态下呼吸困难严重，不能平卧，话不成句
- 呼吸频率 > 30次/分钟，或使用辅助呼吸肌、出现三凹征
- 吸氧后SpO₂仍 < 88%，或血气pH < 7.35
- 血压明显下降（收缩压 < 90 mmHg）或心动过速（心率 > 130次/分钟）
- 新出现胸痛、发绀、四肢湿冷
- 居家处理后症状无缓解甚至加重

出现以上任何一条，需立即拨打急救电话或前往急诊，不可继续观察。

## 注意事项

- **切勿自行减量或停药**：尤其在症状初步缓解后，支气管扩张剂和激素需按疗程完成，突然停药易导致病情反复
- **抗菌药物使用**：仅凭痰色变黄不一定是细菌感染，需结合发热、CRP、PCT等判断；避免滥用广谱抗菌药物，防止耐药
- **镇静与安眠药**：急性加重期避免使用地西泮等镇静催眠药，以免抑制呼吸中枢、加重二氧化碳潴留
- **液体与电解质**：大汗、发热时需适当补液，但心功能不全者避免过量饮水诱发心衰；注意监测电解质
- **氧疗目标**：不主张将SpO₂升至100%，过高氧分压可能削弱呼吸驱动力，导致PaCO₂升高
- **戒烟与远离刺激**：急性期严禁吸烟，避免接触油烟、粉尘、二手烟

**易踩误区**：

- 认为“气短没事，忍一忍就过去”——延迟就医是导致重度急性加重病死率升高的重要原因
- 自行将口服激素长期服用，不做减量——可致血糖升高、骨质疏松、免疫抑制等严重副作用
- 将“雾化”代替规范吸入装置——雾化前后需漱口，使用面罩时注意避免药物沉积眼部

## 预防与日常管理

- **规范吸入治疗**：稳定期坚持使用长效支气管扩张剂（LAMA/LABA）或吸入性糖皮质激素联合制剂（ICS/LABA/LAMA），每日定时吸入，不可因症状轻便随意停用
- **肺康复训练**：在病情稳定期进行缩唇呼吸、腹式呼吸、渐进式耐力训练（如步行），每周至少3次，每次20-30分钟，量力而行
- **疫苗接种**：每年接种流感疫苗；根据年龄和基础健康状况接种肺炎球菌疫苗（23价多糖疫苗或13价结合疫苗）及新冠疫苗
- **戒烟**：持续吸烟是急性加重的最强可干预危险因素；可借助尼古丁替代治疗或戒烟门诊
- **规避诱因**：空气污染严重时减少外出，佩戴防护口罩；寒冷天气注意保暖，避免冷空气直接刺激气道
- **营养支持**：少食多餐，保证优质蛋白摄入（鸡蛋、鱼肉、瘦肉），适当增加膳食纤维；消瘦患者可咨询营养师补充营养剂
- **定期随访计划**：稳定期每3-6个月复诊一次，复查肺功能、症状评分（CAT问卷）和急性加重史；每年至少监测一次血气或SpO₂，评估是否需要长期家庭氧疗
- **制定书面行动计划**：与医生共同制定急性加重识别卡，写明“何时需加用应急药物、何时需就诊、何时需呼叫急救”，并告知家人，以最大限度减少延误。

通过上述综合管理，可显著降低急性加重频率，延缓肺功能下降，改善生活质量。
