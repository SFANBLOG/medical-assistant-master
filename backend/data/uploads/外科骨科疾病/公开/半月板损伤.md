# 半月板损伤

> 以下为科普与就医参考信息，不构成诊断、处方或治疗建议；具体病情请咨询专业医生。

## 疾病概述

半月板是膝关节内股骨髁与胫骨平台之间的半月形纤维软骨，分为内侧半月板和外侧半月板，主要起缓冲减震、分散负荷、稳定关节、润滑与本体感觉作用。半月板损伤（meniscus injury）包括撕裂、变性、部分或完全断裂，是膝痛和膝关节功能障碍的常见原因。损伤类型可按形态分为纵裂、水平裂、放射裂、桶柄状撕裂、瓣状裂等，不同形态影响手术策略和康复进程。

## 常见症状

- 膝关节局限性疼痛，尤其在下蹲、扭转、上下楼时明显
- 关节肿胀，常在伤后数小时至24小时内出现，提示关节腔积液或积血
- 弹响、卡感或关节交锁：膝关节伸屈时突然“卡住”，需活动后才能解锁，常提示桶柄状撕裂
- 打软腿（膝关节突然无力感），伴关节不稳或活动受限
- 部分患者仅在特定角度或动作时出现疼痛，走平路可无明显不适

## 常见病因（诱因与危险因素）

- 运动损伤：膝关节在半屈曲位受到旋转、挤压或突然变向时易损伤，如篮球、足球、滑雪、羽毛球等
- 创伤：跌倒、车祸、重物撞击导致膝关节过屈、过伸或内外翻暴力
- 退行性改变：中老年人半月板质地变脆、强度下降，轻微蹲起或扭伤即可引起退变性撕裂
- 危险因素：肥胖、肌肉力量不足、关节松弛、既往膝部手术史、职业或运动负荷过大、长期深蹲或跪姿工作

## 诊断要点

- 病史与体格检查：关节间隙压痛是最常见的体征；McMurray试验、Apley研磨试验、蹲走试验可辅助判断，但任何单项试验均不能确诊
- 积液与活动度评估：患膝常伴关节积液、伸直或屈曲受限
- MRI是首选的影像学检查，敏感度约90%、特异度约80%；MRI显示半月板内III级高信号并延伸至关节面，通常提示撕裂
- X线主要用于排除骨折、骨关节炎等病变，不能直接显示半月板
- 超声可作为初筛工具，但对深部撕裂敏感性有限；关节镜是诊断金标准，但一般用于计划手术时

## 一般处理与就医建议

居家/床旁可做的处理：

- 急性期（伤后48～72小时）采用RICE原则：休息、冰敷（每次15～20分钟，每日3～4次）、加压包扎、抬高患肢
- 避免下蹲、深蹲、跳跃、急转急停等加重动作；必要时使用拐杖减轻负重
- 疼痛明显时可短期口服非甾体抗炎药（如布洛芬、塞来昔布等，需遵医嘱），外用消炎镇痛贴剂或凝胶
- 无交锁的轻度撕裂可先保守治疗：佩戴支具或护膝、逐步恢复关节活动度，并进行股四头肌等长收缩训练

必须立即就医的红旗信号：

- 膝关节出现明显畸形、无法主动伸直或屈曲
- 关节交锁持续不缓解，手法后仍无法解锁
- 伤后膝关节迅速严重肿胀，伴剧痛或无法负重
- 患肢出现麻木、苍白、发凉或足背动脉搏动减弱，需警惕神经血管损伤
- 外伤后合并明显韧带断裂、关节脱位或开放性伤口

保守治疗6～8周无效、症状反复或存在桶柄状撕裂、大范围移位撕裂时，医生可能建议关节镜下半月板缝合、部分切除或移植，具体方案需结合年龄、撕裂位置、血供区、关节稳定性等因素综合判断。

## 注意事项

- 药物方面：非甾体抗炎药不宜长期服用，应餐后服用；避免同时使用两种非甾体抗炎药，有胃溃疡、肾功能不全或心血管疾病者需咨询医生
- 膳食方面：适当补充优质蛋白、钙和维生素D，超重者控制体重，减轻膝关节负荷
- 监测方面：记录每天疼痛程度、肿胀范围、关节活动度；若休息后肿胀仍进行性加重，需复诊
- 复诊计划：保守治疗患儿建议4～6周复查一次；术后患者按医生要求定期拆线、评估关节活动度，一般术后2周、1个月、3个月、6个月复诊
- 易踩误区：
  - “不痛就不管”：半月板血供差，浅层撕裂可能自行愈合，深层撕裂或较大撕裂若长期不处理，会继发关节软骨磨损，加速骨关节炎
  - “只休息不康复”：长时间制动会导致股四头肌萎缩，反而增加关节不稳
  - “外用止痛贴不痛就恢复运动”：止痛不等于组织愈合，过早恢复急转、急停动作易再损伤
  - “核磁多做几次没有关系”：没有新症状或治疗方案变化时，频繁复查MRI并不增加获益，应遵循医生建议

## 预防与日常管理

- 加强股四头肌、腘绳肌、臀肌和小腿肌肉力量训练，推荐直抬腿、靠墙静蹲、腘绳肌离心训练等
- 运动前充分热身，进行灵敏性训练和平衡训练，跳跃落地时膝关节保持轻度屈曲、避免膝内扣
- 避免突然增加运动强度、时间和频率；篮球、足球、滑雪等高危运动可佩戴运动护膝
- 控制体重，BMI尽量保持在18.5～23.9 kg/m²之间，超重者减重可显著降低膝关节负荷
- 穿合脚、缓冲良好的运动鞋，避免在过硬或不平整地面长时间运动
- 如已有半月板损伤，日常管理以“症状导向”为主：剧烈运动以不引起疼痛和肿胀为度；运动员或体育爱好者应在症状消失、双下肢肌力及平衡对称后，逐步恢复专项训练，通常需要6～12周，具体以康复评估为准
- 有高危因素的中老年人应避免频繁下蹲、跪姿擦地、长时间爬楼，必要时使用手杖或扶手分担负荷
