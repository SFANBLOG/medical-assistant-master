# 批量伤救援

> 以下为科普与就医参考信息，不构成诊断、处方或治疗建议；具体病情请咨询专业医生。

## 疾病概述
批量伤（MCI）指短时间内出现大量伤亡超出常规资源的事件（事故、灾害、暴恐）。救援核心是检伤分类、优先救治与资源调配，常用 START 法区分轻重缓急。

## 常见症状
（按检伤标签）
- 红（危）：危及生命可救（气道/大出血/休克）
- 黄（重）：可延迟处置
- 绿（轻）：步行轻伤
- 黑（濒死/死亡）：资源有限时不优先

## 常见病因（诱因与危险因素）
- 车祸、坍塌、火灾、爆炸
- 自然灾害、公共事件
- 危险因素：密集人群、应急缺失

## 诊断要点
- 现场检伤分类（START/JumpSTART）
- 快速 ABC 与可救治性判断
- 统一标签与流向（收容量）
- 指挥与分区（红黄绿黑）
- 与 120/医院对接分流

## 一般处理与就医建议
现场：先控制危险源、自我保护；大批伤员先分类后救治，先救可救的重者。
红旗信号：持续威胁（火、塌、毒）——先撤离再救援。
流程：指挥-分类-抢救-转运-接收闭环；由现场指挥与急救系统协同。

## 注意事项
- 资源有限时"先救可救"而非先到先救
- 保护救援者安全
- 信息上报准确、避免重复调度
- 标签清晰防错分

## 预防与日常管理
- 应急预案与演练
- 公众急救与止血培训
- 应急物资预置
- 多部门联动机制
